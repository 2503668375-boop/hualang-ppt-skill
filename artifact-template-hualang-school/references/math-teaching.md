# 中学数学题与题库课件

适用于初高中数学、复习课及高考题讲解。先区分教师教案、课堂讲解与练习，按[教学设计](teaching-design.md)选择容量。国际数学另读[国际课程](international-subjects.md)。题目原文、图、符号、参数范围和设问是排版输入。先解题并核对条件，再划分页面。

## 输入的三种情况

- **用户给题**：保留原编号、来源、全部条件、图和设问。扫描件先识别，再对原图逐项核对上下标、根号、区间和正负号；无法判定的关键符号才追问。
- **用户给章节**：沿用已知学段、教材、课时和难度；信息足够时直接拟题。明确标“原创例题/原创变式”，不能冠以真实年份、卷别或高考真题。题目要解得通并与本次教学目标对应。
- **用户给题库**：先按知识点、方法、前置条件、难度与易错点整理，保留题库ID。选择诊断、示范、变式、检测所需题目；不擅自删改用户指定题。每题保留解答和页码对应，题库原答案也要校核。

有数学争议时保留原题并说明，不能静默改题以迁就答案。外部真题须核验来源；无需为了排版任务主动联网找替代题。

## 每题的私有结构

至少记录：`id / 来源性质 / 学段章节 / 完整题干 / 已知条件 / 设问 / 解题步骤 / 答案 / 易错点 / 所需图形 / 揭示顺序`。这是制作者的工作数据，不把JSON、模型过程或源路径放进课件。

## 页面划分由题目决定

| 材料 | 推荐分区 | 保留与拆分条件 |
|---|---|---|
| 两道短题，方法相同且需对比 | 左右并列或上下分题，每题有独立题干、留白与答案区 | 比较需同屏时并排；只有真实题长、图形或推理负载导致同屏不可读时才拆页，不能仅按步骤数量拆 |
| 单道多问综合题 | 完整题干带＋下方推导区；有图时在推导旁固定图形区 | 一页保留当前设问和必要公共条件，长推理按设问/关键转化续页，不任意截断证明 |
| 函数、导数、解析几何 | 代数与数值坐标/几何相邻，同一变量就近对应 | 函数曲线来自公式，点/切线/极值一致；关键推理不由图形直觉代替 |
| 立体几何、向量 | 图形保留大面积，已知/待证与辅助线分层 | 空间遮挡和虚实线清楚；辅助线随推理出现，原始图形不跳动 |
| 概率统计 | 随机事件定义＋树图/表格/分布＋计算 | 样本空间、独立性、条件概率、总概率与分母完整 |
| 题目过长、扫描质量差 | 题干页＋推导页，或原图＋可读转录 | 不能缩成无法投影的小字；原图与转录不一致时暂停有关推导 |

1280×720页面按用途起排：教师教案正文约19—22px；课堂题干与推导约24—28px；练习约23—26px。普通公式不必放到40px。一道常规例题可同页保留完整解答、方法与短变式；条件和符号同等可读。先排末态，调整题域和行距，确实超量再按逻辑续页。具体值以[视觉规范](design.md)和实际视距为准。

## 数学对象

- 简单公式可用原生文本和规范上下标；分式、根式、矩阵、分段函数使用原生公式对象。当前制作工具无原生公式时，用可编辑的分子、横线、分母组合处理简单分式；复杂公式可用清晰矢量公式并保留公式源，交付说明其编辑限制。
- 变量用数学字体和一致字形，运算符与变量分清；省略号不能代替证明中的必要条件。
- 函数用XY数值坐标；范围、刻度、截距与极值重新计算。曲线只是辅助解释，必须给解析证明。
- 原生公式块、函数图和几何图分别为可编辑对象，不能整页截图。

## 点击揭示

先设计状态，后写动画：初始态呈现题干、必要图/知识线索与适量作答空间；每次点击显示一个完整推理单元。公式与其解释同时出现，独立步骤按顺序出现，答案最后出现。

典型导数题可按“求导与分类→极值条件→参数范围→边界检验”揭示。具体顺序服从解法，不要求每道题固定四步。两题同屏时可先揭示第一题，再揭示第二题；明确其顺序。

制作入口 `addMathPage` 返回题干、推导、图形或双题区域；`registerReveal` 按对象登记步骤。导出后运行 `apply_reveals.py` 写入PowerPoint原生点击出现动画。对象名必须唯一，脚本拒绝无对象、重复登记与覆盖已有动画，防止静默丢失。

用出现/短淡入即可。禁用逐字飞入、无意义旋转、长路径和自动循环。学生思考时间由教师掌握，不用固定自动倒计时代替教学节奏。

## 验证与交付

1. 独立计算关键结果与参数边界。数值抽查辅助检错，不能替代证明。对答案、图点、极值、单位至少做一组针对性核对。
2. 从最终PPTX检查每一步对象与点击顺序；输出初始态、关键中间态、末态进行视觉核对。
3. 能用PowerPoint时实际放映验证。只有结构验证或其他软件测试时如实写明，不能说“PowerPoint放映已通过”。
4. 静态预览必须说明显示的是答案全显状态；需要静态授课时另生成同位置逐步状态页。未实现动画的文件不能宣传为动画课件。

介绍PPT中的数学例题用于说明能力，不把介绍扩成完整课程。用户真正要课件时，才按目标、课时与题库展开课程。

讲截距或原点时，显式设置数值轴的交叉位置（例如crossesAt=0），并让范围包含需要显示的零值。嵌入数据后再次回读图像，核对坐标轴、图例和数值关系，不能只检查图表仍然存在。
