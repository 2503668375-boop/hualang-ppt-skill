# 固定封面与封尾

华朗封面使用原校园图、原校徽和紫金斜切底形。主题、汇报人、汇报时间是三个必须存在的独立字段，不把日期当装饰，不用听众名称代替汇报人。

## 固定位置与层级

以下坐标以原模板1280×720画布为准，均为制作坐标，不写进观众页面。位置在 [style-contract.json](../assets/style-contract.json) 统一维护，制作库和检查程序读取同一份数据。

| 字段 | 位置与范围（x / y / 宽 / 高） | 字号 | 内容 |
|---|---|---|---|
| 主题 | 左下紫色区，64 / 488 / 1050 / 74.4 | 45 px，粗体白字 | 本次正式题名 |
| 副题（默认不设） | 主题下方，64 / 568 / 1100 / 50 | 31 px，白字 | 仅用户明确要求或有独立范围时使用；介绍、演示、版本不自动成为副题 |
| 汇报人 | 左下同组，64 / 610 / 680 / 30 | 20 px，白字 | `汇报人：已确认姓名或团队` |
| 汇报时间 | 汇报人下方，64 / 650 / 680 / 30 | 20 px，白字，左对齐 | `汇报时间：约定日期` |

主题、署名左边缘统一。汇报人和时间同组左对齐，分两行；远离右侧金色斜切接缝。普通封面不添加第二个学校标识，不改变品牌背景和斜切几何。长题名需要在固定标题区内重新组织并实际查看，不能覆盖金边、照片、署名或日期，也不能擅自删专名。

正式题名、真实署名及日期来自用户要求或材料。署名不能用“面向校长”替代；日期不能拿资料统计期、文件创建时间或旧例稿日期顶替。信息缺失时完成可做的主体，并核实关键字段；草稿可明确显示待补项，但不能标作正式可用稿。

## 制作与检查

`createDeck` 要求提供 `presenter` 与 `date`，缺项直接报错；字段带明确标签，位置由同一配置生成。正文排完后从实际PPT读回并核对：

```text
python3 scripts/check_style_contract.py 成品.pptx --title 本次题名 --presenter 本次署名 --date 本次日期
```

程序检查字段、位置和正文题名规则；肉眼仍需查看字形、换行、与金边的关系及主副层级。它不证明署名真实，也不替代内容与审美审稿。原始模板保留不动。

用户明确给定的正式正文题名需要保留时，可用检查参数 `--allow-title` 列出该题名，在底稿对照用户原要求。此例外不适用于制作者自行生成的长标题。


## 固定封尾

保留原始模板 `assets/source-original.pptx` 第5页的整页底图、比例、颜色和图形。按用户2026-11-05要求，在原底图的中心安全区加入两层可编辑文字：

- 主句：**华夏俊采，朗若星辰**。写“俊采”，不写“俊彩”。官方定义为培养目标；无须在封底再加类别标签。
- 结束语：按用途选用，例如内部汇报“汇报完毕，敬请指导”、家长/对外“感谢聆听，期待同行”、课堂“勤学善思，学有所成”。允许本次内容决定具体表述，不强制所有稿件同一句。

主句建议白色42—48px，居中单行，置于原底图中央紫色安全区；结束语26—30px，低一层。避开下方校园照片、弧形边界和原有装饰。不加页码、版本、下载说明、维护日志或另一枚校徽。

`createDeck` 默认添加培养目标与结束语，可通过 `closingText` 传入场合用语；`closingMotto` 用于用户明确修改品牌文案的情形。封尾保留到最后，新增内容插在其前。原始资产不覆盖。

检查程序同时核对原图摘要、允许的两个文字对象、准确文字和安全区。不能再把“没有任何文字”当作品牌保真要求。

文字核实：深圳政府在线《深圳市华朗学校》，培养目标“华夏俊采，朗若星辰”，校训“春华秋实，弘朗日新”。
https://www.sz.gov.cn/school/psxqxx/senygz/content/post_9480696.html

用户明确指定单页或局部片段时按指定范围输出，不擅自增加首尾。
