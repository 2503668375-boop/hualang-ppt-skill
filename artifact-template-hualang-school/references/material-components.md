# 让小组件承载材料

用于原文、作品、比较与教学图形需要精读的页面。先确定主对象及读者要看出的差异，再选局部组合。纯照片、完整数据表或课堂作答区可以直接成为主体，不必附加组件。Python 生产入口、字段和分页见[页面规格](deck-spec.md)，底层调用见[Python 通道](python-production.md)。

| 材料与读者动作 | 可用组合 | 局部应承载的信息 | 不应这样用 |
|---|---|---|---|
| 从记录中判断哪里支持结论 | 较宽原文＋指向具体段落的旁批 | 保留原句，批注说明依据、缺项或具体改法 | 左边概论、右边另一段概论，连接线没有指向 |
| 看见同一作品改了什么 | 修改前后逐段对齐＋修改理由 | 对应片段、真正变化与仍待解决之处 | 编造另一份“优秀稿”；用初稿/修订/评价充作三份作品 |
| 选择有条件的方案 | 共轴成本条＋适用对象、隐性代价、成立条件 | 数量同单位，文字保留不同负载，建议贴近比较 | 所有选项等宽卡片；只比较钱，把时间与资源成本藏掉 |
| 跟随数学推理 | 同尺度分数条＋单位细分＋范围括线 | 完整单位不变，细格与算式一致，一份范围可见 | 仅写“画图说明”；分子分母改变而图形任意缩放 |
| 解释图中一处异常 | 真实位置锚点＋短引线＋开放批注 | 具体数据或局部、解释条件与下一步核对 | 箭头穿过正文；指着整页却没有对应对象 |

## 同一组件怎样换构图

旁批可用于原文证据、学生错答或费用异常；主材料长时占较宽区域，说明长时改为上方原文、下方批注。前后对照既可做纵向修改轨迹，也可作为一张完整作品旁的局部细节。方案页按真正差异配置空间，比较字段保持一致、长度无须相等。

局部块按文字长度和作用分配高度，主材料与补充条件分清层级。组内间距短、组间距离更大；连接线只连接实际对应位置。某页同屏所需内容超出可读容量时，按完整修改单元、段落或选项续页，保留口径和共同尺度。不得静默丢项，也不靠全局缩字挤入。

## 原生教学图形

`hualang_teaching_objects.py` 提供可单独组合的 `fraction_strip`、`brace_label`、`anchored_note`。全部是 PowerPoint 原生形状和文字，可用于学生页、教师反馈和图表批注。分数条限制一条表示一个完整单位；假分数按同尺度画多条，细分线保留原单位边界。

```python
from hualang_teaching_objects import fraction_strip, brace_label, anchored_note
# 一米保持720宽；3/4细分成6/8，其中一半为3/8。
r = fraction_strip(p, 48, 300, 720, 72, 3, 4,
                   split=2, highlight=[0, 1, 2])
brace_label(p, 48, 48 + 720 * 3/8, 382, '每份 3/8 米')
anchored_note(p, '每个四分之一再分成两小格，完整的一米仍是同一长度。',
              (588, 300), 848, 280, 350, label='分数单位改变')
```

先画完整末态，再决定是否有理解收益的分步揭示；没有原生播放验证时，不声称动画效果已经检验。独立作答时，任务与答案可靠分态、分页或分教师/学生文件，题目要求、答案和判据相互对应；教师对照或课后讲评可同屏。

## 看实际成品

能否指向一个具体句子、范围、差值或变化；拿掉装饰后，关系是否仍清楚；当前字号下是否能读完整材料。再看连续页面的主对象与阅读动作。条目数量、组件名称、文字框数量和颜色变化都不回答这些问题。
