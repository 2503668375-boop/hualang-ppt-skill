# 成品验收

验收对象是最后一次保存的实际 PPTX，以及从该版本导出的页面。需要同时判断内容是否有用、场景是否适配、视觉是否统一、文件是否可用。导出成功、对象可编辑或自动检查无报错，只能证明相应技术条件；不能据此写“审美检查通过”。

输入材料也属于审查对象。来自用户、教材摘录、旧报告、公开文章或学校自述，均不自动证明其案例、知识和数字正确。按[内容正确性审查](content-accuracy.md)处理实际采用的内容，不能只检查自己新增的文字。

## 任务覆盖检查

回到本次原始要求，逐项在成品中定位实际答案。以“页码＋答案”记录在私有底稿，不能仅用某页标题表示覆盖。主题、产物、受众、使用方式和必须保留的事实全部对应。

合上底稿，仅读成品开头与结尾：读者能否说出这份材料要解决什么、看完可以判断或完成什么？若用户要工具介绍，却主要看到课程、经营方案或照片集，即使每张案例内部正确也应退回重写。

案例需要能说明它为本次哪一项回答提供解释。无法说明、连续展开成另一主题、或挤掉必答项的案例应缩短或移出主稿。用户明确要求的操作、下载、费用、实施等信息缺失时，不能交付。

先通过任务检查，再审文案、排版与美化。不能用颜色一致、数字正确、导出成功或独立审查者一句“通过”抵消主题不符。

## 读者任务

| 场景 | 实际试读动作 | 不能作为通过依据 |
|---|---|---|
| 内部经营与审议 | 找出差额、支持判断的具体数据、原因或假设、资源条件及下一步安排 | 有很多字、有一张大表、标题看起来正式 |
| 课堂与教研示范 | 在答案揭示前明确自己要做什么；用图解释关系；完成一个对应练习 | 有学习目标、有公式、有“互动”字样 |
| 家长说明 | 说出适用对象、可比较条件、学校支持与家庭下一步动作 | 只有理念、课程名称和温馨口号 |
| 对外演讲 | 在短暂观看后找到本页主句或图像，跟随相邻页理解案例与证据 | 每页信息量很多，或每页都只有一句无依据口号 |

内部阅读页保留判断所需的完整证据。舞台演讲页允许一句主张加一幅图、纯观点大字页、单个作品或一个关键数字；判断其是否完成，要结合本讲述单元及前后证据，不套用内部阅读页的密度要求。课堂页按教学时序检查，不能为了单页“完整”而提前露出答案。

## 推理与有效密度

从成品抽取一条核心判断，沿“原始材料或学习对象—依据—解释—条件—结论/动作”反向核对。判断正确但缺少成立过程时补过程；有过程却没有回答原问题时重新收束。管理稿的原因、测算与建议各有依据；课堂的示范、练习与评价各能检验目标。

同页先检查需相互核对的内容是否齐全、就近、可读，再看有没有无信息增量的口号和重复结论。高密度可以是完整推导与变式、材料和证据批注、比较主表及原因解释；字多、框多和缩字均不能单独证明高密度。简短聚焦页结合完整讲述单元判断，不能以一张大字页代表整套课件。

逐页说明表格为何必要：读者确实需要跨行列查数、勾稽或核对多个对象的同一字段吗？若主要呈现方法、教案、流程、诊断、归纳或文本解释，改用有层级的小组件与实际对象，保留完整推理、比较和条件。删网格、换底色或把三列表等宽切成卡片不算解决。没有必要表格时直接不用，不设全稿配额；有真实查阅需要时也不为追求少表而删必要字段。

### 教学深度

以下按本次学科与课型选择，不要求每页都包含全部项目：

- 学生有具体可操作的完整对象：题目、语段、史料、模型、实验或作品。知识与条件可读，不能只剩“观察、讨论、总结”等指令。
- 关键推理能解释为什么成立；数学保留必要等价条件和参数范围，科学保留变量与证据，文本和史料解释能定位证据并说明限度。
- 概念存在易混点时，有可辨析的正反例或边界变化；方法比较说明何时适用，不能只把两个答案并列。
- 练习跨越模仿、条件变化和必要迁移；题量服从目标、难度与计划时间。完整课件不能全部停在定义回忆和代入计算；也不为显示复杂而超出学生基础与指定范围。
- 错误反馈指出错在哪一处、为什么、怎样改、用什么再检验；“加强训练”“注意审题”不能作为完整反馈。
- 教师材料能将目标、学情、活动、预期回应、观察证据与调整对上；课堂材料向学生呈现任务与学习证据，教师预案不挤进学生视野。
- 独立重做代表性例题和变式，检查解答、图像、公式及原文解释；题目没变只复制解法，不能证明迁移能力。

上述检查证明内容设计的完整性。实际学习效果、后排可读性和讲练时间须经真实授课检验，不能由生成页数或设计自评推定。

## 封面与题名核对

从本次任务确认正式题名、汇报人和汇报时间；核对三个固定字段实际可见、位置不漂移、署名与时间带明确标签。题名很长或字段缺失时不能以脚本成功作为完成。

列出全部页名，按[文案规范](writing.md)检查短题名、同层句法及禁用的口播标题；标题下的概论不得重复栏目名。用 `check_style_contract.py` 读回字段和题名，程序结果与逐页阅读配合。

## 第一遍：内容与事实

- 只读开篇和各页主信息，能否说出本次具体问题、为什么需要讨论、听众应得出什么判断或采取什么动作。方法介绍按用户要求解释使用、处理逻辑与适用方式；需要示例时展示具体输入、处理与输出，不能由例子替换主线。
- 每页对本次必答问题新增必要信息。标题、概论、正文和页底反复说同一个意思时删除重复；换一个项目名仍可成立的泛话，补具名事实或删掉。
- 内部判断能追到具体数据、比较、条件或对象。原因与差额复述分开；证据不足的解释保留为假设。建议明确对象、依据、资源与实施安排，未给出的职责和时点不虚构。
- 核对期间、单位、分母、范围和比较基准；分项与合计可勾稽；实际、目标、拟议、预测和模拟性质可辨。图片说明只描述图像能证明的事实。
- 声称展示实例或比较对象时，确认对象实际出现在本页或明确相邻页。只有“题干/解答/反馈”等标签的框不能作为具体示范验收。
- 教学题干、答案、步骤、图像、公式与成立条件一致。学生要完成的练习能检验目标，反馈指向具体作答，英文或双语不改变学科事实。
- 外部主张有相应案例或证据；单句页可以聚焦观点，不能把没有证据的效果包装成确定结论。正式课程、招生条件、日期、收费与业绩核对当期资料。
- 内部稿的原始出处、计算与制作记录留底稿；教学和公开学术材料保留确实需要的引用。公开示例保留模拟/示意性质。任何观众材料都不夹入本地路径、校验日志或排版自评。

## 第二遍：逐页查看实际页面

必须看渲染后的图像，不能只读取文本或检查坐标。先以预计阅读尺寸查看；投影页再缩小到能够模拟远距观察的尺寸。重点看观众第一眼的落点、阅读顺序和必须辨认的对象。

### 所有页面

1. **层级**：能指出一个清楚的视觉中心；标题、主信息、证据和图注的强弱明确。概论、正文及分组的层级须有区别；普通正文黑色，少量红色突出重点，按[视觉规范](design.md)分场景处理。
2. **排版**：检查缺字、异常字体、孤字、行首标点、单位拆分、换行突兀、错列、文字越界和重叠。标题换行后仍与校徽保持安全距离，不因长标题删除品牌。
3. **图像**：主体清晰，关键对象未裁掉，图文对应；双图观察尺度与条件可比较。作品批注指向准确部位，原文仍可辨；照片上的文字有稳定对比。
4. **必要表格**：先通过行列查阅的必要性判断，再看按列读数是否顺畅，数字右对齐、列宽合适、单位明确、网格克制，表头和最末行可读。投影若必须逐格读小字才能理解，改用图形或分步比较；不能用表格承载所有方法与解释。
5. **图表**：坐标、图例、标签、单位和关键数值都能辨认；重要差异不只靠颜色。注释贴近数据点，图形真实反映数值及关系。
6. **可编辑性**：文字、表格、图表与需修改的关系节点为原生对象。照片与标识可为图像；整页截图不算可编辑 PPT。

末次视觉检查还要核对标点不落行首，CO₂等化学式与单位不被拆开，批注线准确指向词句，人物照片保留头部及关键动作，表格真实行高没有压住后文。整稿、整页、分区、组件和字间细节依次观察，见[构图方法](composition.md)。

### 按场景加查

- **内部阅读**：读者能在同页或清楚的相邻页查到判断所需的目标/实际/差额、比较、投入和条件。只有普通大数字或氛围照却缺证据时补内容；只有文字和表格时检查是否遗漏应展示的对象、贡献关系或实施过程。
- **课堂投影**：观看顺序与教学顺序一致。提问页尚未露出答案，变量与标签位置稳定，教师能按步骤解释，学生知道如何作答。后排需要看的题干、公式和图上标签不能降成小字。
- **家长现场说明**：语言具体，路径有适用条件；家庭行动、办理日期与联系方式按真实材料明确。阅读版与投影版的详略差异不能改变事实。
- **对外演讲**：缩小观看仍能一眼辨认主句、主体图或关键关系。大字页的断句有节奏，主图有具体讲述作用；一张校园图不能重复充当全部主题的证据。需要完整条件时由相邻页或阅读材料承接。

## 特殊场景图表是否达到要求

只检查本次实际使用的图形，不要求每份材料凑齐图表类型。

| 图表或组件 | 实际检查动作 | 需要修复的情形 |
|---|---|---|
| 数学函数、科学关系图 | 用公式重算关键点；指出变量、单位、截距、范围和成立条件 | 分类轴冒充数值轴；图像与式子不符；关键条件被裁掉 |
| 趋势、分布与能力项 | 找到期间、样本、评价标准与分母；区分总体分布和可重叠能力项 | 只报均值掩盖结构；把可重叠项目相加；不同群体无说明直接比较 |
| 招生流程或漏斗 | 从每个转化率追到分子分母；确认同一群体及阶段关系 | 不同期间人次拼漏斗；累计阶段相加；人数与家庭数混用 |
| 课程路径与选择图 | 沿每条路径说出对象、条件和下一步 | 并列选择画成默认先后；省略适用条件；箭头暗示无依据的优劣 |
| 步骤、机制与因果图 | 逐条解释箭头代表的顺序、依赖或条件 | 并行事项串成必经步骤；相关关系画成已证实因果 |
| 作品、照片与图上批注 | 指出图中哪一处支持文字；核对对象、时点、尺度和真实性 | 建筑照片替代学习成效；局部批注指错；生成作品冒充真实记录 |
| 教学问答与反馈 | 按放映顺序完成一次作答，再看答案和修改 | 答案提前显示；题干不全；练习与目标无关；反馈不能执行 |
| 英文或双语数据页 | 对照语言、图表与数据，完成同一理解任务 | 翻译改变事实；两套口径；中英全文并排挤压图像 |

## 第三遍：联排看风格与节奏

在联排前按[内容深化](content-depth.md)逐页试读：结果是否接上比较与影响，建议是否接上问题、机制与代价，安排是否能查到完成物和检查。只有小图放大、两句释义、图表数字重述或跨页重复时，先补有效分析或合并相关页；不以增加字数和缩小字号视为修复。舞台、观察和作答页按本场景处理，不能照搬内部密度。

将全稿或同章页面并排看，确认以下问题；只逐页看可能漏掉整套材料的单调和漂移。

- **颜色是否稳定**：页标题采用品牌紫，正文、公式和普通数字以黑色为主，红色强调、深蓝分析、灰色基准分工清楚；紫色兼顾品牌、导航与教学组件，黑色承担正文；普通内容页不随意换底色。照片自身颜色不算主题漂移。
- **品牌是否稳定**：校徽原样、边距有序、字体一致；封面署名与时间同组且避开斜切接缝，最后一页沿用原模板封尾，不自拟结束页。英文页、长标题页没有临时丢失身份元素。
- **场景是否肉眼可辨**：遮住“内部/课堂/演讲”标签后，仍能从构图、字号、图像与教学时序辨认用途；不能只给同一张密表改标题。对照[场景版式](scene-layouts.md)指出具体对象与面积组织，不能把一页文字清单改底色就算完成场景演示。
- **组件是否服务内容**：表、图、照片、批注和留白各承担任务。连续页面若都由长概论与同样表格组成，查明哪些页应转为关系图、对象图、完整例题或删并。无需人为规定图率、固定页数或轮换所有版型。
- **方块是否掩盖关系**：按[内容与版式选择](report-layouts.md)看主对象、面积主次和阅读路径；三卡、四格、上指标下两框若都只是逐块读文本，视为同一骨架复核。`audit_sequence.py` 的近似重复和面板组仅为线索，清单改名、换色、镜像、去框或填写保留理由不能替代实看。需要同字段核对时保留稳定结构，并具体记录理由。
- **演讲是否有节奏**：开场、案例、解释、证据与收束有适当观看变化；主张页可简洁，证据页可更丰富，整体主线持续推进。
- **图像是否成组**：同组裁切比例、边界、图注和色彩处理一致；双图比较没有利用不同尺度制造效果。

美观的判断应落到具体页面：哪个元素抢走注意、哪一组对齐不稳、哪一页与同章冲突、哪张图片缺乏讲述价值。不要用自评打分、无依据的“高级感”“审美合格”代替这些发现。

## 记录、修复与交付

### 最终内容正确性关卡

在最后一次保存后，按成品实际采用的内容再审一次：

- **学科知识及题解**：定义、定理、适用条件、量词、单位、题干可解性、推理与答案；重算代表性题例及变化边界，图像、式子、表和结论相互一致。
- **案例与常识**：例子涉及的百科知识、历史事件、人物归属、文学或学术引文、实验原理与现象，是否有具体错误或过度简化；生动叙事不能改变成立条件。
- **数值及证据**：期间、样本、分母、合计、比率与百分点、比较范围、因果与相关、测算假设，引用是否支持该主张；模拟与真实状态不混用。
- **引用与时效**：引文原意和对象无误，实际课程/考试规则、学校当期信息、收费、日期及条件采用适用版本。已发现疑点时查实际来源；无法核实时保留不确定性，不能以流畅措辞替代证据。

发现问题要给独立说明，写清“位置/对象—问题—依据—建议—影响—状态”。已经能可靠修正的内容先修正，并告知用户实质改动；需保留原始意思但仍有疑点时，提供可选改法及核验建议。重要未解问题会影响授课、判断或正式采用时，明确该部分尚不可作为定稿使用，不以文件导出成功掩盖。轻微措辞与格式问题按实际风险处理，不制造无关阻塞。

审查结果留在独立底稿或交付说明，不能混入观众材料的正文、页脚、附页和备注。必要的学科/学术出处、真实教师提示与答案仍依场景保留；这些内容与制作审查记录分别处理。审查只声明实际检查过的范围，不承诺未核验的所有外部事实都正确。

验收记录留在制作底稿，可用“页码｜观察到的问题｜修改｜复查结果/仍未解决”记载实质发现。全稿性问题先修共用样式，再重看全稿；局部问题只复看受影响页与关联数据。没有问题的页面不需要编造缺陷或凑检查项。

最后回读保存文件，核对页数、顺序、日期、数字、图片、备注及隐藏页；确认导出预览来自这一版本。分步课堂的静态 PDF 保留需要的状态与答案；实际动画若未测试，不声称完成放映验证。只有实际打开并查看 Microsoft PowerPoint，才可声称完成 PowerPoint 验证。

交付说明实际改动、成品位置、已完成的内容与视觉检查，以及仍影响使用的限制。提供代表页面或可打开的整套预览，让用户直接判断结果。完成标准满足后停止，不用重复导出和重复自评增加“审查”次数。

题名修订须限定到标题对象，正文不做无差别词串替换。修改后的概论、分项和图注逐句回读，检查是否因替换破坏了句义。
