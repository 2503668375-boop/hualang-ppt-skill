# 汇报方法与入口

先确定现场读者的问题，再选证据和版式。相同品牌可以承载不同的信息密度。

| 实际任务 | 内容判断 | 参考 |
|---|---|---|
| 内部经营与教学质量审议 | 现状与目标差在哪里，原因有何依据，拟选方案有何代价，谁落实 | [内部汇报](internal-report.md) |
| 课堂示范与练习 | 学生观察什么，哪个关系难懂，怎样练习，如何反馈 | [场景规范](special-scenes.md#课堂教学) |
| 家长现场沟通与留阅 | 孩子如何学习，支持方式是什么，家长可以做什么 | [场景规范](special-scenes.md#家长沟通) |
| 对外演讲 | 听众此刻要记住哪一个观点，哪个图像或例子支持它 | [场景规范](special-scenes.md#对外演讲) |

视觉层级、图片、表格和字号只维护在[视觉规范](design.md)。文字去空话与事实状态见[文案](writing.md)，逐页与全稿检查见[验收](review.md)。理论与官方样例的适用边界见[研究依据](research-basis.md)。

介绍本技能优先让读者直接看到不同场景的成品，具体说清哪种材料适合哪种现场。当前示范围绕“用证据说明理由”展开内部方案、课堂、家长沟通与演讲；科学观察页与数值图页说明学科变化时的图像和数据规范。示范内容不构成学校的教学方案或成绩承诺。
