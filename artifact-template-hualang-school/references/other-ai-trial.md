# 交给其他 AI 的独立试用

把完整 `artifact-template-hualang-school` 目录交给具有文件读取和可编辑PPT制作能力的助手，先让其读取 `SKILL.md`，再按用途读取参考。不同工具的技能安装方式各异；不能只传入口文档或假定都能直接运行辅助库。`hualang-kit.mjs`是可选生产入口，需要环境已有的`@oai/artifact-tool`；该依赖不要求从公共npm安装。常规整稿优先使用 `scripts/hualang_build.py` 与其 Python 依赖；复杂对象再选底层精修通道。两者均不可用时，使用当前环境可用的原生PPT工具，按[样式契约](../assets/style-contract.json)及[跨工具最小实现](production.md#跨工具的最小实现)保留固定首尾、品牌、单位字号和可编辑对象。不要为了缺库退回只写提纲或整页截图。

## 可复制的测试请求

请使用附件中的华朗学校技能，制作给校务会留阅的可编辑PPT。署名“示例工作组”，日期“2026年11月7日”，保留固定品牌首尾。自行安排合理页数，先把材料中的问题、依据与安排讲完整，再决定版式。下面全部为模拟资料和拟议安排，不能写成学校实绩或已定承诺。

1. 学习变化：同一班50人、同一评价标准，前测32人达标，后测39人达标。现有资料不能判定哪项措施造成变化；未达标学生仍需支持。
2. 支持分工：拟由学科教师据匿名作答安排练习；导师跟进个人目标和执行；学生服务组协调参与障碍；家庭提供学习环境和观察反馈。都围绕同一学生，角色之间没有已知先后顺序。
3. 支持范围：全体学生参加基础学习；根据诊断，部分学生进入短期专项支持；其中仍有困难者再接受个别评估。人数未定，不能绘制比例或声称人人都须走完三层。
4. 三阶段安排：先完成诊断，留下错误类型与匿名作答；再实施练习，留下解释依据与新作答；最后做独立迁移，用新情境检验。进入下一阶段取决于证据，未定具体日期。
5. 具体材料：一道原创题“已知 y=2x+1，x 增加3，y 增加多少？”匿名初稿答“3”；修订答“Δy=2Δx=6”。保留题目和完整理由，说明同类新题如何检验理解，不能从一次修订推出长期能力改善。
6. 待讨论事项：如何统筹支持分工、阶段证据和下一次复核。没有费用报价或批准结果，不补造预算、日期或审批。

请交付可编辑PPT及可查看的最终预览，并单独说明内容正确性、实际页面、原生对象和仍未完成的验证。模拟属性标在数据图、题例或拟议安排近旁，单独截取主体时仍可辨认。不把制作日志和排版自评写进观众材料。

## 看结果时核对

- 材料、比较、推理与不确定性完整：64%到78%，提高14个百分点，仍有11人未达标；不暗示个人转变记录或措施因果。
- 支持分工、范围、递进和前后作答的关系可辨，组件有具体作用，主题一致。接受多种合理构图，不把样张版式当唯一答案。
- 留阅密度足够，必要内容不被缩成脚注；没有连续同款方框、线条或圆阵分装所有文字。
- 最终预览由交付PPTX在应用或兼容渲染器中打开/导入后导出，按[审查记录](review-record.md)登记`renderEvidence`。正文、关系节点与数据对象可编辑，首尾品牌正确。静态检查、软件内放映和真实投影分别说明。
- 只有结构镜像或无来源预览时，按[无实际渲染环境](production.md#无实际渲染环境时)交付候选及限制，视觉项保持待核，不称全稿已验收。
