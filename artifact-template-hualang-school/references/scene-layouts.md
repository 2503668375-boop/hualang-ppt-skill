# 场景版式与实际样例

先决定使用方式，再定位学段/学科。`assets/scene-examples.pptx` 为既有16页应用示例，供观察具体对象，不是本次页序或整页模板。旧示例未自动获得新版验收结论；全稿制作沿用固定品牌首尾。

管理汇报先看[内容深化连续示例](../assets/report-depth-example.pptx)及[联排](../assets/report-depth-preview.jpg)，理解[充分分析与容量](content-depth.md)和[主体构图](report-layouts.md)怎样同时实现。上一版[12页构图示例](../assets/report-layout-example.pptx)保留作对照。不能照抄模拟数据、页数或固定页序；教学与对外仍按本次真实用途选择。

| 类型 | 页面主体 | 与其他场景的区别 |
|---|---|---|
| 内部审议 | 正式概论、同口径表/图、原因与条件、落实 | 阅读密度较高，普通正文黑色、重点局部强调 |
| 教师教案 | 目标/学情、具体活动、预期回应、评价/调整 | 教师可据此实施，优先时间/材料/活动组件；真实任务不投影全部备课细节 |
| 初中课堂 | 概念、表征/原文、完整例题、短练习和反馈 | 语言支架与具体对象充分，保持必要推理 |
| 高中课堂 | 条件、模型/证据、完整推导、方法与变式 | 同屏完成关键论证，复杂分支才按逻辑续页 |
| 国际高中 | 实际课程/层级、材料、指令词、推理/论述与评价 | 授课语言与学科要求并重，体系与考试年准确 |
| 练习/检测 | 多道同目标短题或独立长题域，清楚作答要求 | 答案另态出现，题量随材料负载变化 |
| 家长成果 | 同口径数据、匿名作品、改进依据与支持 | 有可阅读内容，不能只放理念与照片 |
| 招生与开放活动 | 体验照片、课程比较、条件与办理路径 | 按沟通环节决定密度，关键选择条件清楚 |
| 对外交流 | 主图、关系图、数据与就近说明 | 保留华朗正文框架，完整讲述单元承接依据与条件 |

入口参数见[制作API](production-api.md)。教案容量与各学科细化见[教学设计](teaching-design.md)、[初中](junior-subjects.md)、[高中](senior-subjects.md)、[国际课程](international-subjects.md)。

起稿只需简记三个字段：读者要做什么，主体是哪个具体对象，局部组件表达什么关系。例如教案的时间轨迹旁放错答后的追问分支，家长反馈以匿名作答修订定位变化，招生用主次照片和条件路径说明体验与选择。不是给每段话添加图标、编号或外框。

混合场景使用`createDeck({sceneMode:'mixed',...})`，通用入口逐页显式传`purpose`。单一场景可在整稿指定`defaultPurpose`。用途参数只决定默认文字尺度，不生成场景构图；若全部页面仍是相同文字结构，参数齐全也不能验收。

遮住用途标签仍应能辨认读者要做什么。少量换色、左右对调、统一三栏或给所有内容加第二个大标题不能证明场景设计。
