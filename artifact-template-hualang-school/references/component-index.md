# 组件选用

现有工具提供原生线性图标、圆形编号、图标说明、图片色标、横向要点带，并可组成蜂窝关系、比较矩阵、活动图文、指标说明和曲线路径。详见[深大主题色样例研究](szu-reference.md)。家长与对外默认由 `addSchoolScene` 保留原华朗正文框架；正文大小按实际阅读/投影用途设置，入口名称不能代替场景验收。

先按用途和学科选组件：教师教案见[教学设计](teaching-design.md)，初中/高中/国际课程分别走对应参考。正文黑色，重点红色，分析图形深蓝；不得把所有组件文字统一染紫。

根据证据关系选择组件，按实际材料分配面积。多个组件组成一个清楚的整体，不把每个对象都装进独立卡片。丰富度看主体是否承载不同且必要的阅读任务：图表可比较数值，批注可定位证据，流程可追踪实际步骤。色块、图标和编号只组织层级；换色、换形或增加外框不能把同一组文字变成新的内容关系。

**先确定主对象，再选择局部组件。** 先判断读者在做解释、推理、观察、比较、选择还是查数，按[内容与版式选择](report-layouts.md)分配整页。主图、原文、推理或照片不必各自装框，也可以跨多个网格；说明靠近相应证据。需要行列交叉定位、多对象同字段逐项核对时使用原生表格。保留完整句义，不把等宽格子去框后当作新的结构。

| 内容关系 | 组件 | 必须有的内容 | 不宜使用 |
|---|---|---|---|
| 同口径分类比较 | 原生条形图＋直接标签 | 基准、单位、样本/期间 | 少量观点装成条形图 |
| 行列交叉查数/多字段核对 | 原生表格 | 真实对象×字段关系、单位、状态、合计 | 纯方法、过程、教案、文本解释统一列表格 |
| 趋势/数值关系 | 折线/XY散点曲线 | 数值轴、范围、公式或原数据 | 分类轴伪装函数坐标 |
| 两题对照 | 双题分区 | 完整题干、独立答案区 | 两题过长仍缩字挤入 |
| 解题推演 | 公式链＋步骤/旁注 | 条件、等式依据、结论 | 题目图片＋一段泛泛解释 |
| 概念辨析 | 正例/反例、条件对照与修正 | 成立边界、变化条件、解释理由 | 只列定义和术语；把错误标红便结束 |
| 方法比较 | 同一对象的不同解法或解释路径 | 共享条件、关键转化、适用范围与代价 | 无比较依据的“方法一/二/三”并排 |
| 文本理解 | 原文＋行号＋批注 | 完整语段、证据对应 | 缩小截图看不清原文 |
| 史料/观点论证 | 具体材料＋证据定位＋解释链 | 材料语境、主张、证据限度与其他解释 | 引文摘抄拼盘；把观点当作材料事实 |
| 几何/物理关系 | 可编辑图形与贴近标签 | 真实比例关系、方向、变量 | 装饰插画代替精确关系 |
| 实验与模型检验 | 装置/变量图＋记录表＋解释 | 可检验预测、控制条件、测量、异常与结论边界 | 流程图代替实际数据或科学推理 |
| 校园/学习体验 | 主次照片组＋近邻图注 | 各图不同叙事作用、真实性 | 同一建筑照反复填充 |
| 规模/成果 | 大数字＋单位/口径＋基准 | 期间、群体、来源与含义 | 无出处的升学率或装饰环 |
| 课程选择 | 路径/并行比较 | 适用对象、条件、下一步 | 把并行选择画成必经顺序 |
| 安排与落实 | 日程、泳道、责任接口与条件组件 | 日期、责任、资源、依赖；确需逐项查阅再用责任表 | 没有时间依据的等距时间轴；每项解释都塞入责任表 |

主制作库提供文字、图片、原生表、原生图表、箭头、简单可编辑分式、数学区域、照片区域及揭示登记。`apply_reveals.py` 写入原生出现动画。更复杂学科对象由制作者按题目补充，不能因库里没有组件便退回通用图文页。

开放数字 `metricInline`、同轴比较 `dotComparison`、真实日期节点 `milestoneTimeline` 与就近引注 `evidenceNote` 可直接组合在正文区，见[制作API](production-api.md)。它们不自动生成整页或卡片网格；`focusPanel`、`numberFlag`、`stepBands` 等色块接口仅在相应内容关系需要时使用。

教师教案可用课时活动链、材料旁注、例题旁注与评价证据组件；确需同时查阅多个课时的字段才使用活动表。课堂保留完整推理，练习按短题/长题负载成组。组件或表格数量不作为固定配额。

课堂的一页可以同时包含学习对象、关键推理、边界或短变式；通过留白、线条与稳定位置组织，按学习顺序揭示。先保证最后状态可对照，再决定隐藏步骤。若任务只需观察或独立作答，初始态可以简洁，不能用这种状态代表全稿的最终密度。

## 简短工具介绍

工具介绍的组成关系可用共同方法与场景分支、品牌及工具支撑；痛点说明用问题—处理—可观察结果；具体方法用同一输入与结果对照。各页分别回答组成、困难或处理结果，不能把同一案例换个标题反复展示。短介绍不要求把全部场景或组件轮流演示，参见[介绍与培训](workflow.md#工作说明与培训)。

介绍成品时可将实际成果中最能证明能力的局部放大展陈；介绍问题时用原文近邻批注指出缺口；解释教学处理时呈现完整题目、准确图形与关键推理；解释数值变化时用共同尺度或准确端点关系。预告截图与后文完整案例若证明同一件事，保留信息更完整、与说明更贴近的一处；复用需服务新增任务，按[案例使用](workflow.md#案例使用)判断。截图只用于说明已有成果，当前交付仍保留可编辑的正文与对象。不要把这些内容重新塞回同款色块，或仅用装饰图标代替主体。

## 对外紫色组件

开放活动与演讲增加色带、开放框架、重点色块、数字旗标、环形关系、阶段阶梯、证据带与折面，见[对外视觉语言](external-visual.md)。按主体关系组合，不把组件清单当作逐页模板轮换表。
