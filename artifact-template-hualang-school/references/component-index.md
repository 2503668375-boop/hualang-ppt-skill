# 按阅读任务选版式

品牌底稿只固定画布、封面与品牌位置。下面是可选构图，不是固定目录，也不是每份稿件必须全部出现的组件。

| 读者任务 | 可选主体 | 应当看清 | 常见错误 |
|---|---|---|---|
| 查数、对账 | 通栏原生表格，重点行就近说明 | 期间、目标/实际、差额、单位与合计 | 几段话也装进表格；缩字保全表 |
| 找差异和趋势 | 条形/折线＋少量注释＋必要明细 | 比较基准、变化位置及其含义 | 无同口径比较却画图；重复图例 |
| 比方案 | 同字段矩阵或同尺度对照 | 能做什么、代价、条件和取舍 | 只写优中差；假造备选项 |
| 看对象、空间和操作 | 一张主图＋就近批注，或全景与局部 | 图中具体位置、动作或变化 | 氛围照片代替证据；拉伸图片 |
| 理解过程 | 原生步骤、泳道或排程 | 真实先后、并行关系、责任及节点 | 无意义箭头；每步只剩抽象名词 |
| 学会方法 | 稳定的题干/图像＋分步示范＋独立练习 | 学生要做什么、为何这样做、如何检查 | 提前显示答案；知识条件缺失 |
| 比较两种表达 | 原文/结果或作品对照＋具体批注 | 改动的位置与理由 | 只说“更专业”；实例展开成另一份稿 |
| 跟随现场演讲 | 大字、单主图、单图表或短对照 | 当前一个观点及其必要证据 | 直接投影内部密表；每页任意换主题 |
| 使用工具 | 完整请求、输入材料、处理方法与结果局部 | 怎么开始、输入如何影响产物、怎样修改 | 只有流程口号；只有结果画廊 |

色值、字体、图片与表格细节统一读取[视觉规范](design.md)。本地原生对象操作用[制作API](production-api.md)。复制任何旧组件时检查其文字、图表数据、日期和备注，不能留下旧主题或示例判断。
