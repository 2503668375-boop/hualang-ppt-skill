# 模板组件索引

[当前模板](../assets/reference.pptx)是可选页面与组件库。15 页示例不构成每份材料的固定页数或提纲。第 02—08 页是内部汇报核心示例，第 09—14 页展示教育与外部场景的视觉转化。

| 页码 | 页面 | 可复用组件 | 使用时核对 |
|---|---|---|---|
| 01 | 封面 | 原校徽、校园与紫金构图；题名、署名、日期层级 | 替换为本次真实字段，不用受众称谓代替汇报人 |
| 02 | 月度经营总览 | 指标主表、完成差异、重点解释与经营安排 | 期间、学段、目标/实际、分项及下一步完整 |
| 03 | 招生转化分析 | 阶段流转、转化指标、原因与动作对应 | 同群体、去重、分母和阶段定义；不能仅用数量推因果 |
| 04 | 收支预算差异 | 财务主表、差额分解与措施 | 科目、预算/实际、合计和差异勾稽 |
| 05 | 招生方案比较 | 同维度比较、投入、推荐与条件 | 只比较真实可选项，不新增原案未有的审批门槛 |
| 06 | 招生跨期排程 | 节点轴、多工作线排程与责任 | 共用时间列、并行与先后、任务和交付完整 |
| 07 | 学情质量分析 | 分布图、能力项矩阵、问题与教学支持 | 测评标准、样本、缺考、可比性及措施依据 |
| 08 | 校园开放日安排 | 场所图像、活动环节、时间与承接 | 图片说明具体对象，批次/流程/责任与费用按原案 |
| 09 | 课堂概念图解 | 数值坐标、概念对应、条件与例子 | 变量、单位、范围与关系准确，图表确实承担解释 |
| 10 | 复习错因及变式 | 匿名错例、原因矩阵、修正步骤与迁移题 | 错因具体、题干完整，答案与练习分清 |
| 11 | 家长课程路径 | 路径图、条件分支与课程比较 | 正式名称、适用对象与当期选择条件，不暗示录取保证 |
| 12 | 家校学习反馈 | 学习进展、支持安排、家校职责与反馈路径 | 真实证据、匿名信息与可执行支持 |
| 13 | 英文数据论证课堂 | 数据图、论证任务、术语或句式支持 | 学科逻辑与英语表述准确，样例/真实数据区别清楚 |
| 14 | 对外教学实践演讲 | 方法图解、案例与证据组合 | 主张由实际材料支持，图片与所述对象对应 |
| 15 | 封底 | 华朗识别与收束文字 | 按场合改为答疑、行动或结束；短材料不强加致谢页 |

## 复制组件后

从最接近阅读任务的页复制组件，再按本次内容重组。完整更新文字、图表数据与内嵌数据表、表头、日期、样本、页码、图注及备注，检查隐藏页。正式汇报替换全部示例内容；刻意保留的教学虚构情境仍应可辨认，公开示例不得被误认为本校实绩。

内部稿按照[内部汇报](internal-report.md)填写短题名、概论、分析、比较和具体安排。不能只把一页中的数据改掉，却留下不匹配的判断和动作。组件不足时按[视觉规范](design.md)扩展原生表格、图表、流程、矩阵或实图批注，不被库中的示例主题限制。

英文和双语版本以相同事实为基础单独排字，复核术语与数字。对原生图表进行编辑后，检查数据标签、坐标、图例与所描述结论；仅更换屏幕上的数字文本不构成图表数据更新。
