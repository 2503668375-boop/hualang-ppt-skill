# 组件选用

V6先按用途和学科选组件：教师教案见[教学设计](teaching-design.md)，初中/高中/国际课程分别走对应参考。正文黑色，重点红色，分析图形深蓝；不得把所有组件文字统一染紫。

根据证据关系选择组件，按实际材料分配面积。多个组件组成一个清楚的整体，不把每个对象都装进独立卡片。

| 内容关系 | 组件 | 必须有的内容 | 不宜使用 |
|---|---|---|---|
| 同口径分类比较 | 原生条形图＋直接标签 | 基准、单位、样本/期间 | 少量观点装成条形图 |
| 多字段查阅 | 原生表格 | 字段、单位、状态、合计 | 纯方法解释强行列表格 |
| 趋势/数值关系 | 折线/XY散点曲线 | 数值轴、范围、公式或原数据 | 分类轴伪装函数坐标 |
| 两题对照 | 双题分区 | 完整题干、独立答案区 | 两题过长仍缩字挤入 |
| 解题推演 | 公式链＋步骤/旁注 | 条件、等式依据、结论 | 题目图片＋一段泛泛解释 |
| 文本理解 | 原文＋行号＋批注 | 完整语段、证据对应 | 缩小截图看不清原文 |
| 几何/物理关系 | 可编辑图形与贴近标签 | 真实比例关系、方向、变量 | 装饰插画代替精确关系 |
| 校园/学习体验 | 主次照片组＋近邻图注 | 各图不同叙事作用、真实性 | 同一建筑照反复填充 |
| 规模/成果 | 大数字＋单位/口径＋基准 | 期间、群体、来源与含义 | 无出处的升学率或装饰环 |
| 课程选择 | 路径/并行比较 | 适用对象、条件、下一步 | 把并行选择画成必经顺序 |
| 安排与落实 | 日程/泳道/责任表 | 日期、责任、资源、依赖 | 没有时间依据的等距时间轴 |

主制作库提供文字、图片、原生表、原生图表、箭头、简单可编辑分式、数学区域、照片区域及揭示登记。`apply_reveals.py` 写入原生出现动画。更复杂学科对象由制作者按题目补充，不能因库里没有组件便退回通用图文页。

教师教案可用课时活动表、材料旁注或例题旁注；课堂保留完整推理，练习按短题/长题负载成组。数量不作为固定配额。
