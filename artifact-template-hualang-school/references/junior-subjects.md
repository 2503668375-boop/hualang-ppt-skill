# 初中分学科设计

面向初中实际年级、教材与学生基础。以下是内容与排版的参考索引，不替代当前教材或课程标准，也不要求成品套用表格。默认以学科对象和小组件组织；表格仅在真实多字段查阅或同口径数值核对需要行列时使用，见[教学设计](teaching-design.md#学科对象与小组件优先)。教案共用[教学设计](teaching-design.md)中的目标—活动—评价对应要求。

| 学科/任务 | 教案要具体写什么 | 学生页的主体与组织 | 密度与揭示 |
|---|---|---|---|
| 数学：数与式、方程、不等式 | 运算意义、规则成立条件、典型错解、检查方法 | 一个完整示范计算＋同类练习；等号纵向对齐，符号/条件不缩小 | 常规例题可连同1—2题变式同屏；按变形/检验揭示 |
| 数学：函数 | 变量含义、表/图/式的联系、易混点 | 变量条件、数值坐标和解析式就近对应；必要的x/y取值表用于核对同一关系 | 一个关系对象＋1—2问题；图不能仅装饰 |
| 数学：几何 | 已知、结论、性质依据、辅助线意图 | 原图与证明相邻，已知条件先标，辅助线随推理出现 | 证明与对应图同屏，长证明按逻辑续页 |
| 语文：现代文/文言文 | 文本语境、重点语句、问题链、学生依据、表达迁移 | 原文/节选、行号、就近词句批注、阅读任务 | 可一段原文配2—3问；不把课文缩成图片或只给结论 |
| 语文：写作/口语 | 任务对象、表达目的、示范片段、评价标准、修改动作 | 示例片段与反馈对照，具体词句处标修改 | 1片段＋1轮修订；保留学生实际表达空间 |
| 英语：阅读/语法 | 语境、语言目标、预测回应、语言支架、迁移任务 | 原文与证据句，意群/指代/句式贴边标注；词汇嵌入语境 | 阅读单元配2—3任务，答案与证据同时揭示 |
| 英语：听说/写作 | 输入材料、交际任务、句式支架、成功标准 | 情境与任务、简短语言支架、示范/同伴反馈 | 不把双语全文重复铺满；音频长度按真实素材 |
| 物理 | 生活现象、研究对象、变量、测量、从现象到规律的证据 | 装置/受力/电路与测量数据、单位、解释相邻 | 1个实验或模型，先现象和条件，后规律与应用 |
| 化学 | 现象、条件、装置、宏微符号联系、操作安全 | 现象记录、粒子/反应式、变量与结论对应 | 图示准确，配平/状态/条件分层，必要安全说明不省 |
| 生物 | 结构与功能、过程、对照、观察依据 | 实物或准确结构图、局部标注、对照组/实验组数据 | 一次突出当前结构或变量，不以照片替代实验结论 |
| 历史 | 史实时序、材料来源/语境、证据与解释 | 史料节选＋时间轴/地图＋任务；观点贴近证据 | 同页2份短史料比较可行，保留作者/时点与范围 |
| 地理 | 地图读数、空间定位、要素联系、过程机制 | 地图/剖面/统计图为主体，比例尺、图例、方向保留 | 一组空间材料配2—3问题，图像不能为排版任意拉伸 |
| 道德与法治 | 具体情境、事实判断、适用概念、理由与行动 | 情境材料与概念依据对应，保留不同观点及边界 | 1情境＋若干递进问题，避免整页正确口号 |
| 信息科技/技术 | 实际问题、数据、算法/操作、测试与修正 | 输入—处理—输出、流程或代码片段、运行结果对照 | 一段能解释的过程，保留测试与失败修正证据 |
| 体育/艺术 | 动作/作品目标、观察要点、练习、反馈与安全 | 动作序列、谱例、作品局部与简短提示 | 观看任务决定图像大小，关键安全条件和评价可读 |

初中内容不等于幼儿化图文。概念形成需要具体表征与语言支持，核心知识、符号和推理仍完整。教师教案可较密，学生投影按实际视距调整。

## 用初中学习障碍细化任务

初中常见深度来自表征转换、规则理解和基于证据的解释，并不需要提前引入高中术语。先确定一个核心障碍，再让材料、示范与练习对应。

- **数学**：把图、式、表和实际意义对应起来，追问某个符号/点为何代表该关系。用一个边界或反例区分概念，再给撤去部分提示的独立题；诊断运算错误与概念错误时采用不同反馈。
- **语文/英语**：从原文语句找到依据，再解释措辞、指代、语序或结构如何影响意义。比较两份具体回应，示范如何补证据和解释；写作给完整片段及一轮有理由的修改，不只给结构名词。
- **物理/化学**：先确定研究对象与可观察现象，区分变化前后和控制条件，再连接模型/符号与解释。练习改变一个条件，判断结论是否仍成立；实验安全遵循现有规范和实际资源，不凭空编写危险操作。
- **生物**：结构标注需要回到功能或过程解释；实验对照须说明两组哪些条件相同、哪个变量不同。让学生用数据支持结论并指出数据不能回答什么。
- **历史/地理/道法**：史料来源、地图要素和情境事实先清楚，再完成比较、因果解释或有依据的判断。问题从定位/描述递进到解释/应用；概念或立场不能替代材料依据。
- **信息科技、技术和艺体**：示范一个能观察的作品/动作/运行结果，给具体评价点、练习和修订机会；保留一个失败样例及修正依据，避免只展示成功成品。

独立任务应检验目标，不能全部沿用刚示范的相同表述和数值。支架可为词句、图解、分步提示或操作卡；学会后逐步撤去。学生作答慢但推理正确时调整任务量，不以阅读速度代替理解判断。更完整示例见[教学深度与密度](teaching-depth.md)。
