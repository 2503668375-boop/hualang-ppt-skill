# 内容与版式选择

用于内部汇报、家长材料、对外介绍的主体设计和旧稿修订。正文左题、右徽、金线、近白底及固定首尾沿用；改变的是金线下的内容组织。教学仍优先服从材料、推理与稳定对象。

## 先有可读的主体

先按[内容深化与容量](content-depth.md)写完整本页证据与分析，再分配图与文字面积。主对象可以是图与近邻分析共同形成的整体；四个数据点或简单关系图无需占满主体。相邻页只分别呈现结果/解释、日期/责任时，检查能否在可读字号下合并，不固定保留一张图一页。

逐页底稿记录：本页问题与回答、读者动作、主证据对象、该对象需要的空间、解释及条件放哪里、与前后页的关系。先画主对象，再放说明。概论可以保留一两句，不能再在正文底部重复一次。没有独立分析的指标回到整体比较，不将每个数字扩成一页。

“三块卡片”“左右两栏”只是容器，不能回答为什么这样排。主对象可以跨多个网格；段落、就近批注、图注、距离或必要的线与色面按关系使用。负载不同的内容不必等宽等高。去框后逐段划线也可能保留原有文字分装；应改变主体尺度、材料对应或空间关系。可结合[版式图谱](layout-atlas.md)中的中心、包含、汇聚分流、递进和不对称图文选择。

## 按阅读动作选空间关系

下面是可调的起稿方案，依资料选择，不按页码轮流套用，也不要求每份稿凑齐。

| 读者动作与材料 | 主体及说明位置 | 保留的判断条件 |
|---|---|---|
| 看连续变化：月/季实绩 | 通栏趋势图，转折点旁放解释；较长分析沿图下方对齐时段 | 同期、尺度、单位；原因有证据，不能把相关写成因果 |
| 比较目标与实际：同单位多对象 | 共同数轴的点比较、子弹图或条形图，直接标差额；右边对齐说明异常项 | 分母、基准和期间；各组不同量纲时分图 |
| 拆解总额或差距 | 有起终点的贡献桥、分项条形与合计；说明贴近对应项 | 可加总且不重叠；不能用任意色块暗示面积比例 |
| 看规模与边界：少量关键数字 | 开放数字排印配单位与口径；主体下接有层级的连续说明 | 不同期间/群体不能混加；每个数字有具体含义 |
| 看成果证据：作品、作答或现场 | 一张主对象跨栏，细节放大与引线批注；次图只补不同证据 | 对象、时点、匿名与尺度，实景/示意属性 |
| 看过程与承接：活动纪实 | 不对称图片序列或证据时间线，图片与事实近邻 | 真实先后；只有过程描述不能证明成效 |
| 看资源如何协同：主体与接口 | 网络/泳道/中心辐射，中心对象明确，外围说明按主体贴近，连接标明提供什么 | 连线有实际关系；仅中心与外围关联时不加闭环；并列资源清单不用虚构箭头 |
| 看上下级与归属：组织、课程、支持体系 | 嵌套区域、树形分支或层级缩进，条件留在所属对象近旁 | 归属有依据；不借区域大小虚构比例；不同层级不排成等权节点 |
| 看输入与出口：资源形成结果、条件决定路线 | 汇聚或分流结构，输入、处理和出口沿阅读方向安排，较长分析在邻近区域展开 | 区分因果、依赖与选择；不能把名单连成流程；分流条件完整 |
| 看方案差异：同对象多维选择 | 同一基线逐项对照、必要原生表；推荐与代价贴近比较 | 共同维度、适用对象、资源条件；不杜撰待决事项 |
| 看依据怎样支持判断：政策或材料 | 原文摘录/具体材料占主体，证据定位与解释沿阅读顺序展开 | 引文语境、适用范围；事实、推断、建议分清 |
| 看计划落地：时间与责任 | 按真实日期定位的时间轴或甘特泳道，责任在任务近旁 | 日期、交付物、依赖与状态；只有季度标签时不伪造精确日期 |
| 查完整字段：收费、资源、责任台账 | 通栏原生表；需解释的差异在相关行就近说明 | 单位、期间、合计、状态与必要字段齐全 |
| 看结论及下一步 | 一个明确结论配开放的行动顺序/责任接口 | 结论指向前文证据；行动与真实授权一致 |

只有观点、没有数值时，用层级段落、材料旁注或真实逻辑关系。不能为了“多图表”编造数据、比例、阶段或因果；材料不足时仍可做清楚的阅读页。

中心、路径或图片可以承担整页主构图，也可只占局部，与证据、比较、条件共同组成一个阅读单元。先保留本页判断所需的完整信息，再按负载分配面积；不为装下环绕节点而删掉条件或缩成小字。固定页眉、校徽、紫金品牌及文字角色保持统一，形状与比例随内容变化。

## 卡片的使用边界

卡片适合相互独立、同层级、负载接近的选项或条目，例如三种课程选择。需要共用数轴、共享材料、解释前后变化或展示依赖时，优先构成一个整体。两栏、三卡、四宫格、上排四指标加下排两框，若主要都在逐块读文本，应归入同一“等分面板”家族；只改数量、填色、圆角、左右或标题不构成关系变化。

修改旧稿先保留完整信息，再按关系重组。例如：

- “四项指标＋两块说明” → 一组开放数值和连续说明；有共同单位时改为同轴比较。
- “四项成果四宫格” → 主成果的实际对象配局部证据，其他成果用次级条目；若仅有文字，按影响与证据写成有主次的段落，不硬塞照片。
- “三个学段三卡” → 口径可比时共用基线；成绩、升学与 offer 等异口径资料分别保留原含义，不强行绘一张图。
- “资源矩阵方块” → 有协作关系时画标注接口的网络；只有资源名单时用开放分层清单，不能凭空连线。
- “工作建议四格” → 按真实优先级和依赖展开行动链；并行事项用责任泳道。未定日期继续写未定。
- “结论三卡＋底条” → 合并重复结论，以一个主判断统领明确动作与条件。

## 联排验收

从最终保存文件渲染，先看完整页面，再看连续4—8页和整稿缩略图。比较的是主对象、面积主次、空间关系与阅读路径，不只看标题、颜色或版式名。反复面板、线条分区、ABAB轮换、同骨架隔页回访时，逐组判断是否确有比较需要；同字段续表、并行学段核对、同题推理可以保留稳定位置。独立议题却一直逐块读字，应重排主对象。方块、线条、圆与色面均按实际作用判断，不另设禁用清单。

`audit_sequence.py` 不传清单也能给出原生对象与几何提示；清单可补充本页任务和保留理由。机器发现不会被换标签或填写理由删除。脚本看不到所有视觉效果，去掉边框后的文字网格仍须实看；`ok` 仅表示结构与清单有效，不能当作版式验收通过。

每组重复记录观察、保留/修改理由和实际结果。不用“每页必须不同”、卡片比例或版型数量作为硬指标；让该页任务清楚、内容完整、连续观看有变化才算完成。
