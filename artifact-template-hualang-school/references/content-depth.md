# 内容深化与页面容量

用于内部留阅、校务管理、专项分析及需要完整阅读的家长材料。先展开本次问题的实质内容，再分配页面和选择构图。课堂推理、教师教案和舞台演讲仍服从相应场景；不将内部阅读密度套给远距演讲。

## 从结果继续追问

有标题、概论和一张图只是起点。按本页问题选择值得同屏回答的追问，不把下面各项做成每页固定栏目：

| 已有信息 | 可以继续展开的内容 | 需要的依据 |
|---|---|---|
| 一个结果或指标 | 相对什么基准、差额多大、由哪些部分形成、影响哪个目标 | 同口径目标/同期/结构和可复算关系 |
| 趋势或差异 | 变化发生在哪一段/哪一组、主要贡献、异常与可能解释 | 分项或过程记录；原因缺证据时只保留现象及待核实假设 |
| 一项成果 | 具体做了什么、对象与过程、实际作品/表现、适用边界 | 有内容的案例或材料，不能用活动参与量证明学习效果 |
| 一个问题 | 具体表现、证据、影响、原因判断依据及仍未排除的解释 | 原始任务/记录/数据；不同解释各自受什么证据支持 |
| 一项建议 | 针对谁和哪项问题、通过什么机制起作用、资源与代价、落实和检查 | 实际方案与条件；新增推演写为建议，不能冒充已执行 |
| 一个安排或机制 | 谁把什么交给谁、前后依赖、异常怎样处理、怎样知道完成 | 已给责任、材料、节点和条件；未确定的内容保持未定 |

写足对本次判断有用的解释。只有“提高质量、加强协同”等短标签时，回到具体对象和行为。允许有层次的完整段落，不为保持大字、卡片或极简外观将材料压成名词。每段应新增解释、证据或条件，不能将图里的数字再抄一遍充数。

## 深化到哪里停止

新增内容应帮助读者比较、解释、选择或操作，或避免关键误读。达到本次任务所需的依据与条件后停止扩写；删除后不影响这些动作的复述、同义释义、无关背景和规则自述，应删去。完整分析底稿可以长于观众材料，不能把所有思考过程搬上屏。

内部留阅的判断、比较和取舍仍需展开；课堂保留完整对象与必要推理，演讲按讲述单元保留证据，工具介绍以成果局部解释关键方法。以上范围各自成立，不能把本参考的追问表当作每页的填充清单。“完整、详尽”要求问题回答充分，不产生固定字数、页数或栏目配额。

## 四种可用的深化动作

1. **把材料展开**：保留影响判断的过程、案例细节、比较字段和例外；从输入直接定位，不只摘取每段第一句。资料丰富时先完成分析文本，再压缩重复表达。
2. **把关系算清**：补完成率、差额贡献、同比、结构、预算影响与可比变化；写明算式含义和边界。不把不可比人数、期间、offer份数、累计阶段或收支与到账混算。
3. **把判断解释清**：由事实推到含义，说明为什么这项差异值得关注，建议如何针对该问题；推断的成立条件、其他解释和证据限制按相关性表达。缺少原因资料时不编一个“主要原因”。
4. **把安排落具体**：沿原材料给定的对象、责任、交付物和节点说明衔接、资源代价与检查办法。可以提出有依据的建议，清楚标明建议；不能给既定活动补停办条件，或虚构审批、责任承诺和日期。

资料有限时仍可做可靠计算、解释指标含义、比较已有选项并合并短页。确实影响结论的缺口集中说明一次；核验记录留底稿，不用每页一段“资料不足”填空间。

定性材料也可充分展开具体过程、作品/原文、选择理由、接口和例外，不要求每页增加数字。任务确需补背景、政策或课程知识时，在本次授权范围内查可靠原始资料，区分公共背景与学校实际；通行做法不能写成本校已开展或已见效。

## 同一模拟材料的深化示例

这些示例用于说明推导边界，不构成所有报告的固定指标：

- 招生实际500、目标550、上年420：完成率90.9%，同比增长19.0%，仍差50人。国际高中差20人，占总缺口40%；还可比较各学段完成率，解释“规模增长”和“目标未完成”同时成立。没有渠道与家庭记录，不能据此认定原因。
- 四季实际80/105/145/170、目标100/120/150/180：下半年贡献315人、占全年63%；Q3缺口5人最小，Q4缺口10人，虽人数更高仍扩大5人。季度波动不直接等于渠道效果，不能仅凭单年季度分布推算下一年或认定稳定季节规律。
- 期末在籍1430：在完整勾稽旁解释新增/转入与毕业/退学的区别，净增230来自流入530减流出300。不能将招生目标差50混入离校，也不直接用期末在籍作全年收入分母。
- 收入9100、支出8320：收支差780，比预算1200少35%；收入缺口500被支出减少80部分抵消。可以展开结构和影响，不能将低支出直接认定效率提高，也不能把收支差当现金余额。
- 同一批200人达标120→150：比例60%→75%，净增30人，未达标人数80→50。没有个体转移记录，不能声称恰好30名原未达标学生改善；单份作答只支持具体错误分析，不能推断全体错误分布。
- 培训12万元覆盖26名新教师：可测算人均预算约4615元。共同备课直接新增预算0，但占用每组每周1小时；未给组数和持续周数，不估算全年总工时。比较应讨论适用问题、时间代价与检查证据，不能只写“免费优先”。
- 拟议支持机制：把“学科组—导师—学生服务”展开为任务与评价标准、个体反馈、面向家长的支持安排，并说明教务怎样统筹课时和复核评价。已有交付关系可具体写出；遗漏的异常流程可提出建议，须保留建议状态。参与记录与实际学习证据分别核对。

## 一页容纳完整的阅读单元

先把必要证据、解释、条件与安排写完整，再分配空间；让概论与主证据、相关分析能同屏核对。图表本身是信息，相关短分析也是主体，不默认留到后续页。参考[主体构图](report-layouts.md)选择主图、局部批注、连续段落、比较表或责任接口，保持开放排布。

- 只有少量点、四个节点或简单关系的小图，不默认占整页大半。缩到标签仍清楚的尺寸，把相关原因证据、比较或条件安排在近旁；不能把空图放大当作内容充实。
- 数字与文字有不同负载，开放排布允许不等宽分区。内部正文按现有14—16pt区间起排，必要表格保留可读字段；先组织、缩减重复标题/间距和图的冗余面积，再考虑续页，不能整体缩字塞满。
- 两页分别只有结果和解释、节点和责任、问题和对应动作，且在可读字号下可合并时，优先形成一页完整关系。若合并后需跨对象反复找信息或字号不足，再按独立问题拆页。
- 图、表和正文多次重复同组数值时，不将重复部分计为内容深化。需查完整字段时保留表，需看差异时保留图或将派生比例直接标在图上；结合本次用途安排，不为展示多种组件把总量、构成和同义释义拆薄。
- 单独成页应带来一个需要独立阅读的分析或对象；只把主图换成另一种形状、重复结论或增加一页摘要，不增加内容深度。

收束页只保留帮助本次判断的综合取舍、行动与条件；前文数字和同一日期链不整段抄一遍。若没有独立综合判断，把结论承接到最后一个相关内容页，不额外增加重复总结。

用户指定页数、范围与使用方式时优先遵守，不能以合并为由擅自减页；未指定时按材料负载决定，不沿用示例页数。字数不代替信息增量，合理观察、推理与作答空间保留。只有少量概念、一个数字或重复释义的阅读页，应先深化或在允许范围内合并。

## 交付前试读

逐页指出：本页新增什么证据或解释，读者能完成什么判断，条件是否完整，与相邻页是否重复。对结果页沿图表追到差异及其含义；对建议页追到问题、作用机制和代价；对安排页追到完成物与检查。缺失时回到材料补足或调整页序。

再看全尺寸页面与连续联排，确认新增内容可读，图文相互解释，版式变化仍成立。正文字符数、表图数据量与页数仅供比较本次改动的实际信息增量；不设全场景配额，也不把脚本计数当成内容审查。验证记录与计算留在独立底稿。
