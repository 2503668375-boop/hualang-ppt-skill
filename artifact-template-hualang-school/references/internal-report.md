# 内部经营、管理与专项汇报

本篇适用于华朗向学校决策者、校内管理层及业务团队提交的正式材料。教学质量、招生、课程、学生服务等教育议题同样按学校管理审议要求组织。议题涉及课堂，不代表它就是学生课件。

## 从读者职责确定内容

| 主读者 | 重点回答 | 适宜展开 |
|---|---|---|
| 学校决策者、实际最终决策者 | 经营结果与全局影响、推荐方向、真实需要决定的事项 | 关键事实、取舍、资源、现金或收益影响、重大条件及节点；按实际用途配置独立一页纸 |
| 高管、校内管理者 | 分管目标差在哪里、资源怎样安排、什么事项需要协调 | 目标与实际、偏差构成、原因证据、团队接口和完成标准 |
| 专业业务团队 | 采用什么口径、怎样分工执行、异常怎样交接 | 参数、操作、实际流程、岗位接口、责任及交付物 |
| 外部协调对象 | 已确认事实、履约、计划及对方需协助事项 | 与其职责有关的影响和双方动作，按披露范围选内容 |

按会议通知、原案、署名或用户确认判断实际岗位。不要从“校务会”等名称推定职级和审批权。多人参会先定主读者；共用版本只保留各方均可知悉的内容，内部取舍和不适宜对外的数字另稿。校内管理者需要阅读的正式报告，不能自动改成舞台演讲。

## 从议题起稿

1. 写清触发本次汇报的事实及其业务影响。方案需说明为什么现在值得做，不能只写目标和活动安排。
2. 先提炼核心判断。已有方案直接交代方向、对象及安排，后文说明依据和投入。仅在原案存在真实待选事项或用户要求提方案时比较选项。
3. 为判断选必要证据：同口径比较、构成、变化、原因、约束、资源与代价。原始材料不足时缩小结论，不虚构事实填充页面。
4. 按读者追问安排页序。每页底稿可记“业务问题与答案／新增依据／图表与配图／为何单独成页”。删掉某页不损失判断所需信息，应并入相邻页。

## 按议题组织论证

| 任务 | 开篇 | 支撑材料 | 会议结果 |
|---|---|---|---|
| 经营复盘 | 完成多少、差多少、影响是什么 | 目标/实际/同期、贡献与差距、原因证据、动作及预测 | 责任、完成物、日期与协调 |
| 招生推广 | 获客或转化卡在哪一环，为什么此时投入 | 受众与行为、现有渠道、拟办动作、资源和费用 | 总预算、实施安排、按本次任务可核实的结果 |
| 费用或资源申请 | 要解决什么问题、推荐采用什么安排 | 方案、服务范围、报价构成、可比投入、实施条件 | 真实待决事项及生效时间 |
| 教学质量审议 | 哪类学习表现出现差异，影响哪个目标 | 同标准分布、能力项、样本、匿名作答、原因假设与证据 | 具体教学支持、负责人及复测 |
| 课程或产品审议 | 当前设置有什么问题、拟调整什么 | 原方案与新方案同字段比较、对象适配、资源及成本影响 | 方案、深化要求与接口 |
| 进度协调 | 哪一节点影响后续工作 | 已办/计划、依赖、责任、例外处理 | 完成物、日期与协作安排 |
| 工作交接、岗位培训 | 谁需要接手或学会什么 | 现场步骤、示范、职责和常见例外 | 可以执行的操作与交接信息 |

这些问题可以在一页中共同回答，也可以按独立业务问题展开。背景、学校介绍和荣誉只在帮助本次判断时使用。附件可放长明细、完整测算和细流程，决定判断的核心比较与条件应留在正文。

## 招生与营销的因果关系

拿掉活动名称、嘉宾和合作品牌，仍应说得清学校面临哪项招生任务。把目标家庭数量与同期间去重咨询、预约、到访、测评、录取和缴费记录相对，辨明问题发生在哪一步。咨询不足查触达对象与渠道，到访不足查家庭顾虑和到校理由，到访充足但缴费不足查适配、费用、沟通及决策过程。只凭相关变化不直接认定原因。

活动目的与投入必要性分开说明。校园开放日、课程体验、咨询会各自说明对象、能帮助家庭解决的选择和后续承接方式；场地、档期、合作机会与报价属于可行性。报道篇数和参与人次用于核对执行，去重家庭的后续行为用于核对招生目标，不能把两者混用。

对既定多场活动逐场保留原案目的、安排和预算。日期未定只影响排期，不据此推断是否举办。不得从报价或资料缺口擅自新增停办条件、试点、成本门槛或审批事项。预计参与、预约回执和实际到访保留各自状态。

## 普通页的完整回答

左上用具体业务短题名，标题下用一两句正式概论交代本页结果、判断或安排。下方按事实、差异或条件分项，主体以表格、图表、图纸、照片或流程支撑。仅解释一个差额、位置或日期时，就近标注，不另设一个重复结论区。

| 页面任务 | 通常需要同页核对的内容 |
|---|---|
| 招生结果 | 目标、实际、差额、学段或渠道构成、关键转化率及口径、主要原因 |
| 费用偏差 | 预算、实际、差额、主要科目、一次性/持续性影响及措施 |
| 学情分析 | 测评范围、人数、标准、分布、能力项、匿名证据、支持安排 |
| 方案选择 | 同一组比较维度、推荐依据、放弃什么、投入、条件与节点 |
| 活动执行 | 对象、批次、时间、地点、任务、承接与责任；必要费用与材料 |
| 操作交接 | 正常步骤、岗位接口、异常、使用材料及完成标准 |

不以字数定义高密度。完整论证需要一段说明、一个比较表和一幅流程图时应保留；一项普通指标没有独立分析时放回主表，不扩成一张大数字页。大面积空白、三个数字、同义口号和氛围照不能代替证据。表和说明能在同页完成核对时，不拆成几页来回翻阅。

## 数据与口径

| 指标 | 必须分清 |
|---|---|
| 招生 | 人数/家庭数、去重规则、期间、学段，以及咨询、预约、实到、报名、录取、缴费的定义；漏斗需同一可追踪群体 |
| 学生规模 | 在籍/在校、统计时点、期间新增/转出/退费，期初与期末勾稽 |
| 教学 | 试卷范围与难度、评价标准、人数、缺考处理；分数与能力项分别表达，避免只看平均分 |
| 人员 | 实际岗位、工时或课时口径、现有能力与缺口、真实责任安排 |
| 财务 | 币种、期间、预算/实际/预测；收入与到账、支出与承诺、一次性与持续性成本 |
| 升学 | 届别、统计截止日、学生人数与 offer 份数、重复录取及适用课程 |

比较前对齐单位、时段、样本、范围和分母。数据冲突时说明差异并选定采用口径，不无声平均或挑较大数。核对分项合计、比率与百分点；同比、环比和累计不混用。原因依证据表达，预测保留关键假设，不能把资源投入直接折算成录取或成绩保证。

## 成品与底稿

内部决策及经营汇报由汇报人对数字负责。出处、原件页码、出具机构、计算与核验过程留在私有底稿；成品 PPT、PDF、一页纸的正文、表头、图注、页脚、备注和附页均不另列数据出处或制作记录。保留业务日期、单位、样本范围、约数、计划状态，以及实景或示意属性。用户明确要求的研究文献材料按该次用途处理。

公开模板与公开示例中的虚构数据必须可辨认，不能因遵守内部稿的简洁呈现而隐藏样例性质。正式使用时替换示例文字、图表数据、备注、旧日期和旧项目名。
