# 佳兆业规范的继承与华朗适配

华朗 v2.0 以当前佳兆业通用汇报 skill v3.7 的方法与验收要求为基础，整理日期为 2026 年 11 月 5 日。以下规则已固化在本技能中，使用者无需另行安装佳兆业 skill。公开包保留方法、华朗品牌模板和明确标注的示例，不收录其他业务的真实经营数据、客户资料或内部项目截图。

## 继承的公司规则

| 佳兆业规范 | 华朗落实位置 |
|---|---|
| 动笔前判断读者、议题由来、核心回答和页序 | `SKILL.md`、[内部汇报](internal-report.md) |
| 按主席、高管、业务口和对外对象的实际职责确定详略 | [内部汇报](internal-report.md#从读者职责确定内容) |
| 既有方案保留范围、场次、职责、费用与状态，不擅自改议题 | `SKILL.md`、[内部汇报](internal-report.md) |
| 经营判断由事实、同口径比较、归因、代价与条件支持 | [内部汇报](internal-report.md) |
| 普通正文短题名、正式概论、分项依据和主体图表 | `SKILL.md`、[文案](writing.md)、[视觉](design.md) |
| 有效信息密度，完整论证不拆提词卡，不用大字少字替代分析 | `SKILL.md`、[内部汇报](internal-report.md#普通页的完整回答)、[验收](review.md) |
| 黑色正文、明确重点、字号层级、原生表格与图表 | [视觉](design.md)；华朗内部使用既定黑字红重点，品牌换为紫金 |
| 业务配图、图文对应、实图/示意区分、图片实际检查 | [视觉](design.md#业务配图)、[验收](review.md) |
| 财务主表、流程、排程、时间轴、泳道和连续页构图变化 | [视觉](design.md)、[组件索引](component-index.md) |
| 日期、分母、口径、合计，实绩/计划/预测及批准状态 | [内部汇报](internal-report.md#数据与口径)、[文案](writing.md) |
| 内部成品不列出处、核验记录与制作过程，必要业务条件保留 | [内部汇报](internal-report.md#成品与底稿)、[验收](review.md) |
| 主席或最终决策者配独立一页纸、宋体母版、配套核对 | [一页纸](one-page.md) |
| 文案、排版、美化三遍审稿，回读实际文件 | [验收](review.md) |

## 华朗的专项适配

华朗保留原校徽、中英文字标、校园照片、画布和紫金识别，品牌颜色不机械沿用佳兆业橙色。内部汇报的论证、密度和阅读层级继续执行公司规范。招生、教学、课程、学生服务、预算和人员等议题使用本次真实字段，房地产货盘、户型和回款示例不转入学校材料。

学生课堂、复习备考、家长沟通及外部演讲需要更多图解、数据可视化和组件组合。减少散文叙述时，把关系转成图、比较转成表、步骤转成流程、证据转成批注，保留题干、条件、推理和必要信息。教学提问、语言支架及真实引用属于这些场景的有效内容，不能反向取消内部稿的正式概论与完整证据。

英文版是在对应场景基础上重写与重新排版。公司内部英文汇报仍保留经营逻辑和密度；英文课堂按语言学情提供支持，不把中英两套全文挤进同一版面。

## 后续更新时

佳兆业基础规范更新后，逐项比较本表对应规则，保留华朗特殊场景的差异；不要只复制新版入口或盲目同步品牌素材。更新会影响的参考、组件和验收规则，并通过实际内部样页及特殊场景样页检查。仅修改文字描述，未验证页面行为，不能视为完成设计改进。
