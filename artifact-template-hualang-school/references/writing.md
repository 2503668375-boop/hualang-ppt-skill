# 华朗文案与专业表达

起稿和交稿均读取本篇。按本次材料的文体写出自然、具体、完整的内容，再安排到页面。正式汇报保留专业程度与论证，课堂保留明确提问和操作，家长沟通用具体作品解释变化；不能把所有材料都写成制作说明、目的清单或步骤口播。

技能中的分类、计数、字段和检查问题供执行者组织工作，不自动成为成品的题名、栏目和正文。用户只要求维护技能时，按受影响规则试写、核对和修订，不额外生成介绍稿或汇报材料。

## 标题层级

封面默认只设一个主标题，署名与日期是元信息。副题需要独立范围或用户明确要求，不为“介绍/演示/版本”叠标题。页眉题名负责定位，正文概论负责统领。实质判断采用黑/深紫和清楚的主体层级，不能以避免重复标题为由压成灰小字；不再重复同义题名。小节标签按实际分组出现，课堂题号和设问保留。

## 标题、概论、依据和图注

- **题名**：普通内容页优先使用简短、具体的议题名称，例如“招生进度”“费用执行”“课程调整安排”。需要直接交代判断时可使用清楚短句；不为四、六、八字或句式整齐压缩必要含义。封面保留正式事项名称。
- **概论**：需要综合判断，且标题与主体不能直接传达时，再用一两句说明对象、结果、方向或安排。完整题目、原文、主图或操作对象已经清楚时可以省略，不为每页预留同样高度。概论由下文支持，不复述标题或预告栏目。
- **分项依据**：每段新增一个事实、条件、差异或动作。仅说明某个数据项的理由贴近该行；多项独立原因按事项分段。主张、证据和业务含义接得起来。
- **图注与表头**：写清对象、单位、时点、范围和必要资料属性。图注只描述能从图或数据核对的内容，照片不能证明未展示的付费、成绩改善或录取。
- **页底总结**：确实补充取舍、影响或行动时再加，不是每页固定组件。题名、概论、正文和页底不复述同一句结论。

## 写清结果、原因、取舍和动作

完整分析的展开方法见[内容深化](content-depth.md)。围绕本次事项写成可独立读懂的回答，说明事实与判断怎样相连；内容需要时保留完整段落、原文、比较、过程与条件。短标签用于导航，不能代替解释。数量变化可以说明规模、进度或差异，原因、效果和建议还要有对应依据；教学步骤有名称不等于已经展开推理，作品有评价不等于已经展示变化。

经营结果要有实际值、比较基准、差额、统计期和构成。只有“稳步推进、基本达成、成效显著”时，补具名结果或缩小表述。原因要对应观察和数据；“环境不好、家庭观望、资源不足”不足以完成归因。

方案围绕实际选择说明依据、代价与实施条件，有真实备选项才展开取舍。既定安排按原状态说明，告知材料可直接写事实和办理信息，不为凑完整结构增加方案或审批。需要落实的动作保留实际责任主体、对象、完成物和日期；未提供的岗位、期限和状态不补造。

| 原表述 | 修改方向 |
|---|---|
| “强化家校协同，提升教育成效” | 按已有安排写清谁以什么频率沟通哪类问题、形成什么记录与后续动作 |
| “招生取得显著成效” | 交代本期人数、目标、差额、阶段转化和统计范围，再判断影响 |
| “持续优化教学质量” | 交代要改哪类教学任务、针对何种学习表现、如何观察或复测 |
| “开放日全面赋能招生” | 说明面向哪些家庭、帮助其解决什么选择、后续由谁跟进什么行为 |
| “四部教学法，全面提升理解” | 给出具体题目、关键推理及理由，再用独立作答观察学生是否理解；无结果材料时不写成效 |
| “三次修改，能力明显进步” | 展示同一作品的实际前后版本，批注指向修改处，并说明仍未解决的问题；版本数与材料一致 |

上述为写作方法，不表示学校已有这些做法。只能依本次材料填实。

## 去除空话与机械结构

看到“加强、优化、赋能、提升、打造、闭环、抓手、协同”等词，先检查删去修饰后还剩下什么业务信息。删掉整句不影响判断或操作，就删。换一个项目名仍能套用的泛话，应补事实、差异或具体动作。

只预告下文或复述标题的“本文将、以下是、本页主要说明、后续页面展示”等文档自述应删去；句子直接说本次事项。连接词承担实际归纳、因果、转折或限定时保留，不能见到“因此、综上、首先”就删。制作底稿中的“证据、策略、结论”等标签不直接充当观众页的小标题。

不用“不是……而是……”式故作翻转。每段写有区别的内容，不把同一意思分别改称目的、价值、方法和成效反复展开。真实活动目的和教学目标可以说明；“本次有三个目的”后只有“提升、加强、优化”等泛话时，回到实际问题、对象和安排，不把它换成另一套更短的标签。

“八套方案、四部方法、三重保障”等计数包装须核对对象是否实际存在、数量是否影响使用、各项是否有独立内容。即使数目对得上，没有解释作用的计数仍可省略。真实人数、费用、题号、课时、阶段和必要清单正常保留；不为凑数拆分、合并或另造名称。

正式汇报的题名、概论和正文直接陈述情况、依据和安排，避免用“先看什么、再分析什么、最后形成什么”预告写作过程。真实时序、实验步骤、教学指令和操作培训按过程写清，必要时自然使用顺序词；不可为了避词打乱依赖或删去操作。机械排比、固定三点、四句对仗与重复栏目按其实际信息判断，不按项目数判错。

封尾前的内容页回到本次判断、必要条件或实际安排，不突然上升为时代、未来或宏大口号；告知类材料不强加后续行动。成效强度与已有证据相称，“显著、大幅、精准、有效”等用于确定效果时须有相应依据；正常专业术语和准确引文不因含这些词而改坏。

## 用同一材料写成完整句段

以下均为原创模拟材料，用于校准表达。给定材料是改写边界，不能把示例中的人物、数字或安排迁入真实稿件。各例承担不同工作，不构成通用段落模板。

**管理复盘**

给定材料：本年度招生计划550人、实际500人，上年实际420人，统计口径相同；没有分学段、渠道和家庭去向记录。

不宜：“本次汇报有三个目的：摸清现状、找准问题、明确方向。先看增长，再分析缺口，最后提升招生效能。”

可用：“本年度招生500人，较上年增加80人，仍低于计划50人。规模增长与目标未完成同时存在。现有资料仅有总量，尚不能判断缺口来自哪些学段或渠道，也不足以归因于推广投入。”

这里补出的80人、50人来自给定数字的直接计算，未新增原因或承诺。图表若已完整显示总量，正文可减少重复数字，重点解释两种比较为何同时成立。

**课堂说明**

给定材料：学生已学分数意义；一根3/4米彩带平均分成2段，要求用图解释每段长度。完整单位为1米。

不宜：“本课通过三步探究实现三个目标：理解概念、掌握方法、发展思维。”

可用：“图中的完整1米保持不变。把每个1/4再分成两个相等的小格，每格就是1/8米，3/4米也就表示6个1/8米。六个小格平均分成两份，每份有三个，所以每段长3/8米。”

作答指令可写：“在图上标出每一份，并解释为什么原来的每个1/4还可以继续分。”解释与指令各有作用；不能只换掉“三步”而仍不展示分数单位的变化。

**家长反馈**

给定材料：同一阅读任务的初稿只写“他很关心同学”；教师提示引用原文后，孩子在修订稿加入“他把伞递给同桌”，仍未说明这句话如何支持判断。尚无独立完成的新作答。

不宜：“本次反馈有三个重点：肯定进步、明确不足、家校协同。先看变化，再给建议，形成成长闭环。”

可用：“这次修订中，孩子在教师提示后补上了‘他把伞递给同桌’这一原文依据。作答比初稿具体，但还没有解释这个动作怎样支持‘关心同学’的判断，也暂不能说明他已能独立完成分析。家庭共读时可请他补一句理由，并指回原文核对。”

反馈保留了“得到提示”和“尚无独立作答”的限制，家庭动作明确是建议。没有补写“自己淋雨”“仅有一把伞”等原文未给的情节。

## 确定程度与数字

| 类型 | 表达要求 |
|---|---|
| 实际 | 写清截至何时、什么对象、完成什么；不能把预约写实到、通知写录取 |
| 目标或已定安排 | 保留计划、版本、适用期间与真实批准状态 |
| 预测或测算 | 保留假设、范围和条件，不写成确定业绩 |
| 建议 | 有依据、对象、资源和作用机制，不冒充已执行 |
| 资料不足 | 只有影响判断的条件在相关处说明一次，其余核验记录留底稿 |

金额统一为元、万元等同一量级，单位放表头；同一列小数位一致。百分比变化与百分点变化分开，分子和分母保持对应。日期同稿统一一种格式，业务日期与资料检索日分开。数字、单位、姓名、课程名不拆成误读的换行。

模拟数据、原创个案和拟议安排的性质写在相应图表标题、图注或案例主体近旁；续页、缩略图和跨稿复用仍保留性质，截取主对象后应可辨认。前一页的统注不能代替案例所在页的标识，也不要求每个数字重复标注。模拟学校用“示例学校”等明确称谓，不与“本校”、真实照片和实际日期拼接成已发生的校情。总体人数只支持总体比较，不能据此补造个体转变、错误题型、责任或日期。个体的一次作答用“这次独立写出……”等表述限定观察范围；“已掌握、形成习惯”等稳定能力判断须有相应连续或跨任务观察。

承担结论、因果或承诺的句子应能指向具体数据、材料或已完成操作；找不到依据时补证或收窄表述。“全部、唯一、自动、不会、直接可用”等绝对说法与因果推断尤其要核对。比如“后排看不清导致报名流失”需要实际观察，只有字号问题时只说明可读性风险。改句保留事实、否定、范围、比较对象、归因、条件、期间和已定状态；不能把“可能”改成“确定”，或用新细节让句子显得具体。

## 介绍工具与方法时的中文

说明用户交什么、具体怎样处理、最后得到什么。比如“附上月报，说明汇报给谁、要解决什么问题”，比“建立输入机制，实现高效协同”更清楚。解释思考步骤时，用本次具体问题和页面局部说明，不只放“判断、证据、行动”三个名词。

制作术语落到听众能理解的具体对象和动作；确需术语，用一个实际局部解释，不连续用术语解释术语。版式数量、脚本名、像素、网格和门禁名称属于制作信息，只有读者需要据此维护或操作时才展开，不能代替学校材料的实际内容。只在一处完整说明同一个方法，其余场景通过成果体现差别，不能换句话重复原则。

工具说明中的输入、处理、输出是主题内容，可以写；普通业务稿的制作过程仍留在底稿。不要反复说本技能专业、高效、成熟或通过审美检查。能力与校验范围按实际执行表述：原生对象支持编辑，不自动证明关联数字会更新；调用页面组件不等于执行整稿复算；静态预览不等于完成放映。能做什么应由实际页面和操作说明体现，没有实际测量不承诺节省百分比。

## 题名改写与核对

| 不采用 | 采用 | 其余信息位置 |
|---|---|---|
| 从自己的材料开始 | 提供资料与用途 | 材料与完整请求放正文 |
| 它具体处理哪些制作困难 | 常见材料问题 | 困难与处理动作逐项对应 |
| Skill怎样决定讲什么、怎样分到每页 | 资料取舍与页序 | 思考结构与依据放图解 |
| 课堂：先明确任务，再展开解释与反馈 | 课堂教学 | 题干、提问与反馈进主体 |
| 排版怎样帮助读者找到信息 | 页面主次与阅读 | 实际图文、表格与批注说明规则 |
| 拿到文件后，怎样检查和修改 | 审查修改 | 具体检查与修改示例放正文 |
| 第一次制作，可以直接照这段请求发送 | 首次制作 | 完整调用请求放正文 |

这些只示范如何把口播题名改为定位短语，不是所有汇报的固定目录。实际题名还须指向本次具体事项，不能整稿只剩“内容组织、实施路径、成果价值”等泛词。自动题名超过12个语义字位时复核是否夹入了概论；必要专名不因凑字被改写。题名长度以准确定位为准，不按字数对齐，不强行改坏学科术语。逐条读出最终题名，不能只验证标题没有越界。

“从……开始”等句式由人工判断是否指向具体对象或真实过程，优先采用清楚的议题名称。脚本只提示复核，不把句式等同于空话，也不能自动确认题名有信息量；用户给定正式题名仍保留并记录例外。

## 全文复读

起稿完成后连读完整内容，排版后从最后保存文件再读标题、概论、正文、表头、图注、标签和结尾。看句子是否直接说清本次事项，段落是否提供独立信息，解释能否接到材料，前后页是否沿同一问题推进。完整、通顺的专业段落可以保留，不为追求组件变化切碎；需要保留的比较、推理和条件不因去套话变成薄页。

对照原材料核实改写是否新增、遗漏或强化信息。删去一段后若只少了预告、同义赞美或重复结论，可删；若少了依据、条件、反例或可执行安排，应恢复或换位置。关键词提示、句长、字数下降和检查脚本均不能替代这一通读，也不证明所谓“AI味已消失”。
