# 页面结构：角色、证据与行动

本篇补充管理汇报的逐页策划与新增版式，教学、家长沟通和演讲仍按各自使用单元组织。一个页面应有清楚的主要任务；任务所需的材料、解释和条件可以组成一个完整阅读单元，不强制每页三段，也不把一个问题拆成多页口号。

## 0. 记录页面作用

逐页底稿写清以下问题，可用对应字段记录；短篇和已有稿件可直接依据实际内容检查，无须为了补字段重做素材。

| 字段 | 作用 | 检查方式 |
|---|---|---|
| `role` | 管理页可选 opening / context / diagnosis / evidence / options / execution / decision / closing / appendix | 角色符合真实用途，不要求全部出现 |
| `reader_question` | 读者带着什么问题进入本页 | 主对象与解释能够回答 |
| `new_information` | 新增的事实、解释、比较、方案、安排或必要操作 | 删除该页是否损失理解或使用所需内容 |
| `context` | 观众需要的主体、期间、单位、范围和事实状态 | 计划、实绩、预测和拟议分清 |
| `source` / `table.source` | 原始依据的追溯记录 | 管理汇报仅留独立底稿；教学、学术、对外引用按用途呈现 |

管理分析可从结果与差距推进到解释、取舍和落实，顺序随本次问题调整。开场不必重复所有结论；收束只整合真正需要确认的事项或下一步，不把已定活动改成待审批方案。长明细可置附录，内部出处、计算及核验过程不得借附录、页脚、备注进入观众文件。

课堂以完整对象、推理、尝试与反馈推进；教师教案以任务、预期回应及调整推进；家长材料以作品、具体变化与支持推进；演讲以主张和相邻证据推进。角色名称、固定页序和管理栏位不替代这些场景结构。

## 1. 按需要选择判断、依据和推论

| 内容职责 | 字段 | 适用写法 |
|---|---|---|
| 统领判断 | `lead` | 用一两句说明本页结果、比较含义或核心主张；任务和主对象已能统领时可以省略 |
| 补充解释 | `basis` | 补足影响判断的事实、比较基准、业务条件和解释；图表已充分说明的内容不重复 |
| 实质推论 | `action` | 写由证据支持的动作、代价、后果或待明确条件；没有真实安排时不编责任与日期 |

三种职责可以由主图、表格、局部批注和正文共同承担，不要求每页另立三个面板。判断和依据须同口径。数字旁保留必要单位、期间、分母及模拟属性；公式、输入、原始出处和校验过程放入 `calculations`、`source_notes` 或其他独立底稿。内部 `basis` 不填写原件路径、文件页码、出具机构或计算核验记录。

## 2. 各版式承担的阅读动作

- `table`：按对象与字段交叉查阅；完整行列承担依据，必要解释贴近相关项，`basis` / `action` 可在末页补充。
- `metrics`：突出少量关键数值，同时保留单位、范围、比较基准和实际含义；无独立分析时并回相关主表。
- `bars`：在共同尺度上比较，直接标对象、单位与差额；正文补意义与边界，避免复述高低顺序。
- `timeline`：按真实日期或阶段查看推进，任务、交付物与复核相邻；未定日期保持未定。
- `comparison`：以共同维度呈现差异，保留条件与代价，区域随内容负载安排。
- `positioning`：两个数值轴分别标清单位与范围，直接标注对象；两轴可以采用不同量纲，不能混淆尺度。
- `waterfall`：起点、可加减分项与终点能够勾稽；计划、推算与实际状态分别标注。
- `trend`：连续期间与同口径系列展示变化，保留尺度、转折与适用边界。
- `diagnostic`：事实、解释假设及验证动作对应；含义针对实际受影响对象，不能全部套为家庭问题。
- `targets`：当前值、拟议目标、差额和核定条件对应；比例保留分母，人数与百分点分开。
- `conversion`：同一去重对象按真实阶段跟踪，写清定义、基线与责任；未知基线不伪造转化率。
- `swimlane`：真实期间、责任方、跨期任务与交付物对应；先后和依赖不可凭版式虚构。
- `decision`：只服务真实审议，保留建议、理由、代价及已有责任条件；超量事项按完整事项续页。
- `statement` / `image`：用于主张、场景、作品或必要转场；远距主视觉可简洁，论据在本页或相邻页可辨认。内部分析不能仅靠主张页代替论证。

版式的具体字段与容量见[页面规格](deck-spec.md)。复杂学科对象或超出通用版式的图文需要按[生产流程](production.md)定制，不删掉必要内容迁就组件。

## 3. 内容充实与空间分配

- 管理留阅页先保留判断所需的证据、比较、解释和条件。表格少于四行、指标只有三四项均不能单独判为不足，须看其实际信息与独立分析价值。
- 图表不必占满下半页。少量对象缩到标签仍清楚的尺度，将相关解释、对照或条件放近；无独立价值的短页可合并。
- 课堂作答、实验观察、完整原文、作品及远距主视觉有各自的空间需要；合理留白保留，不按统一像素或覆盖率补字。
- 内容过密时先删复述、合并标签、调整主次与分区，再按完整阅读或推理单元续页，不靠整体缩字压入。
- 实看字形、层级、单位邻接与阅读路径。参考字数和面积只帮助起排，不构成逐页密度下限。

## 4. 文案复核

“赋能、抓手、闭环、链路、颗粒度、组合拳、护城河、底层逻辑、顶层设计、打法”等常见套话用于提示人工复核。删去修饰后没有具体信息，应改成对象、事实或动作；真实学科术语、正式专名及必须准确保留的引文不因命中词语而删改。

抽象名词不能替代解释，但不要求每句配数字。定性材料可用具体案例、行为、条件或作品支撑。文案规则见[写作规范](writing.md)。

## 5. 整稿内容关系与节奏

构建器对较长内部汇报提供风险提示：正文达到八页时检查内容关系种类、表格占比，以及连续四页的版式关系。少于六类、表格超过45%、连续四个独立输入页少于三类，均用于定位需要观察的页面，不是强制替换版式的配额。

看实际连续4–8页与整稿联排，判断主对象、尺度、阅读路径是否由内容推动。换标题、换色、左右镜像、把表格改为等宽卡片不计为实质变化。多个独立议题仍持续逐块读字时应重排；同字段续表、同口径并行核对和同题推理可以保留稳定位置，并在底稿记录其作用。不要将正文伪装成 `appendix` 绕开观察。

主题统一靠核心问题与证据承接，视觉统一靠品牌、字阶、对齐和颜色职责；主体轮廓随材料变化。开场和收束各完成不同工作，不复制同一套主张和行动表。

`strict_quality` 的检查范围以构建报告为准。内容与节奏提示须结合实页处理，自动通过不证明内容充分或审美通过；计算错误无论开关取值都必须修正。

## 6. 派生指标比较语义

顶层 `calculations` 每项填写 `comparison_id / subject / baseline / perspective / period / unit / formula / inputs / expected / tolerance`。公式只使用支持的安全运算，预期值与容差按指标精度设置；底稿记录来源与实际舍入口径，不能用扩大容差掩盖错误。

同一比较保持主体、基线、期间和单位一致。价格差、单生变化与学校总量变化分别登记；家庭成本与学校收入的损益视角分清。计算正确但比较对象或损益方向错误，仍按内容错误处理。登记与公式复算不能替代人工核对实际页面数值及其语义。

## 7. 封尾与最终自检

原始封尾底图、培养目标“华夏俊采，朗若星辰”及场合结束语按[固定首尾](cover-layout.md)和样式契约执行。长结束语需在安全区内调整换行并检查实际页面，不能为固定坐标截断。

逐页核对：读者需要什么、具体材料在哪、必要比较和条件是否齐全、相邻页新增什么。再检查整稿主题、最弱代表页及实际文件，按[成品验收](review.md)分别判断内容、表达与场景、视觉和文件。制作记录、路径、算法与排版自评不进入观众材料。
