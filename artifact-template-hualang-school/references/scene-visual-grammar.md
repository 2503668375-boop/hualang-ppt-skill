# 场景视觉语法：密度、字阶、图文比与组件

页面的视觉差异由三件事决定：谁在看、离屏幕多远、看完要不要自己再读一遍。读者身份决定内容和证据类型；观看距离与留阅需求决定字号、字数、图片面积和留白。换读者只改措辞，字号和图文比不变，页面仍然是一种样子。

常规页沿用品牌框架，远距出血页按下述例外处理：近白底 `#FDFDFE`、页眉题名 x48/y30、校徽 x1093/y25、金线 y86、正文区 x48–1232 / y112–650、12 栏步进 100px（栏宽 84、间距 16）。以下是框架之内怎么排。

## 一、先定档位：三档视觉密度

同一主题做成礼堂宣讲和经营留阅，内容组织、文字负载和字号应随使用条件变化。动手排版前先选档，以下参数用作起排参考；字数、面积、要点和对象数量不作为逐页必须达成的配额。

| 参数 | 留阅档 | 近距档 | 远距档 |
|---|---|---|---|
| 使用条件 | 会后自阅、邮件送达、审议前预读 | 会议室或小场投影，5 米内 | 礼堂、体育馆、开放日舞台，10–20 米 |
| 典型材料 | 经营汇报、教案、练习讲义、家长资料 | 校务会投影、教研说课、班级家长会、学生课堂 | 招生宣讲、对外演讲、开学典礼、发布会 |
| 每页正文 | 180–320 字 | 80–160 字 | 30–80 字 |
| 每页要点 | 3–5 条 | 2–3 条 | 1 条 |
| 概论字号 | 33px | 42px | 64px |
| 小标题 | 26px | 32px | 44px |
| 正文 | 21px | 26px | 34px |
| 标注／条件 | 17px | 21px | 26px |
| 注释／口径 | 14px | 17px | 20px |
| 概论 : 正文 | 1.57 | 1.62 | 1.88 |
| 图／表占正文区 | 25–45% | 30–50% | 55–100% |
| 色面占正文区 | 8–22% | 15–35% | 25–55% |
| 内容覆盖率 | 55–70% | 50–62% | 35–50% |
| 每页对象数 | 4–8 | 3–5 | 2–4 |
| 停留时间 | 30 秒–3 分钟 | 30 秒–2 分钟 | 5–15 秒 |

三档的核心字号以约 1.2 倍以上级差区分层级。跨度从 14 到 64，比例 4.6 倍；留阅档内部跨度 33:14 = 2.4 倍。按实际屏幕、内容和字体调整时，保留可辨认的主次与阅读距离，不为守档牺牲完整材料和可读性。

**档位不随场景自动推导，随使用条件判定。** 招生材料印成手册给家长带走，是留阅档；同一批内容在开放日讲台上放，是远距档。一份材料同时承担两种用途时，做成两版，不折中。

## 二、再定主体：七个落位

主体指这一页最该被看见的具体对象：一张费用表、一段原文、一个函数图、一张课堂实拍。落位决定主体放在哪、占多大，其余材料跟着主体走。

正文区 12 栏，栏宽 84、间距 16、步进 100。主要分区优先参考 x = 48 + 100n，并保持相关内容共享对齐线；非等宽布局、分区内文字、表格单元格、图表节点和批注按内容定位，允许内缩与局部偏移。色面块与色面带内距可从 24 起排。

| 落位 | 坐标 | 主体与说明的关系 | 适用 |
|---|---|---|---|
| A 通栏主对象＋底注带 | 主体 y112–460；说明带 y478–650 | 主体横贯 1184，说明在下方整行，与主体同宽 | 留阅档的宽表、长原文、趋势图 |
| B 左主右释 | 主体 x48–632（6 栏）；解释 x664–1232（5.5 栏） | 主体占左半，解释贴右侧同一基线 | 留阅档的占比对照、教案环节表 |
| C 左窄主张＋右宽证据 | 主张区 x48–432（4 栏）满高，深紫底白字；证据 x448–1232（8 栏） | 一句主张独立成块，证据在右侧铺开 | 近距档的家长页、学生课堂 |
| D 整页出血＋压字 | 图为 x0–1280 / y0–720 满版；文字左边界 x148 | 图铺满整页，文字压在深色遮罩上；无页眉、无金线、无近白边 | 远距档的招生实景、开放日、演讲主视觉 |
| E 上主张＋下三格 | 主张 y112–230；三格 y262–600，各 384 宽、间距 16 | 一句主张在上，三个并列对象在下 | 远距档的课程特色、体验步骤 |
| F 中心＋外围 | 中心 (640, 390) 半径 90–110；外围 4–6 格 | 中心是共同对象，外围是分项说明 | 支持分工、课程结构、归因 |
| G 双栏对照 | 1–6 栏 / 7–12 栏 | 两侧同字段、同尺度、同基线 | 前后作品、方案对照、正反例 |

落位按内容关系选，不按页序轮换，不设全稿版型数量或相邻页变化配额。独立内容应有适合其对象的阅读结构；同一题干、推理单元、数据或续表可以连续复用稳定布局与坐标。

### 整页出血：对外专用

远距档的实景页铺满整张画布，不留白边。品牌框架在出血页上让位给画面，处理方式固定为四条：

| 项 | 出血页 | 说明 |
|---|---|---|
| 页眉题名 | 不设 | 本页主张承担题名；要保留定位时用 20px 白字 70% 压在主张上方，不与校徽同侧 |
| 金线 | 不贯穿 | 需要分隔时用 64 宽金色短线，只放在文字列内 |
| 校徽 | 金色版，压在文字侧上方 | 宽 132，x148 / y44；深色版在画面上看不清 |
| 页码 | 移到文字列左下 x148 / y677，白色 | 右下角常压住画面亮部或人物 |

遮罩：文字侧从 0.90 起，48% 处降到 0.40，64% 归零，右半画面保持原亮度。硬边色块会毁掉整页质感。

裁切：满版比例 16:9，按焦点裁保住人物与主体。原图带水印、台标或无关边缘时，从该侧整条裁掉；正式使用换授权原图，不用带来源标注的新闻配图当主视觉。

用量随叙事安排：出血页承担现场、主张或成果节点；需要比较、查询或恢复定位时回到带页眉的页面。连续使用时检查事件与论据是否推进，不设统一比例或连续页数配额。

出血只给远距档。留阅页把整页图当主体，等于用一张照片替代比较、明细和条件；近距页在教室投影里满版图会挤掉学生要反复看的题干。

## 三、按场景定做法

### 校领导与校务管理 · 默认留阅档

主体是同一口径的比较表或趋势图，可从正文区 30–45% 起排，完整明细按需要扩大。概论写这一页的结论，可从 33px 黑色、与表格相隔 16px 起排。差额列、单位、统计期贴着对应数值。深紫面优先承担表头或明确的信息分组，不以固定面积限制必要证据。

留在页面上的：目标与实际、差额构成、原因证据、落实条件。移到附件的：测算过程、口径定义、方法论。

常见失败：把校园照当主体配两句结论；同一组数据换张图再讲一遍；每页都是"题名＋灰字＋三个等宽块"。

### 教师备课与说课 · 默认留阅档

主体是环节表或原文，可从 30–50% 起排。表格可按环节／任务与材料／预期回应／判别与处理组织；需要时间、资源等字段时按负载增列或拆页。表内从 19px 起排，行高按内容计算，详见[表格系统](table-system-v11.md)，不缩字容纳过量内容。

说课投影改近距档：正文从 26px 起排，按讲解重点精简环节表；完整任务和预期回应保留在配套教案或承接页，不能只依赖未记录的口头补充。

常见失败：只写"导入—新授—练习"三个标签；时间分配写在表外；预期回应写成"学生可能不理解"。

### 学生课堂 · 近距档

主体是学科对象，可从 30–50% 起排；长题干、原文和复杂图形按学习需要扩大。任务带可参考 x48–1232 / y112–196、白字 26px，内容较长时增加高度或改为开放排版；图形、原文和推理相邻，不能为固定区域截短对象。

长原文、复杂装置图可降到留阅档密度，但正文字号不低于 24px。答案与任务分态，初态留白。

常见失败：把一道短题的题干、答案摆进两个框；函数图没有对称轴和关键点坐标；解释文字挤在 17px 的注释层。

### 练习与复习 · 留阅档

主体是题组，占比 25–40%。成组短题按方法或条件分组，组与组之间留 32px，组内 16px。追问和判定要点贴着对应题目，不集中放在页底。

常见失败：只换数字凑题数；六道题字号相同、没有难度递进；答案集中列在右下角。

### 家长沟通 · 近距档（现场）／留阅档（办理页）

现场页可用落位 C：左侧深紫块放一句判断，字号按近距档与实际负载设置；右侧放真实作品或原文，可从 45–55% 起排。也可按作品方向和批注需要采用其他落位。前后对照保持同尺度、同字段，改动处用少量红色标出具体词句。

办理页回到留阅档：课程、费用、时间、材料用原生表格，表内从 19px 起排，行高按内容计算，字段完整可查。

常见失败：只有宣传照和结论；把班级均值写成孩子的进步；家庭支持只写"加强监督"。

### 招生与对外演讲 · 远距档

主体是实景照片、作品或一个决定性数字，可从 55%–100% 起排；全幅照片页按 100% 计，走整页出血规格，不留白边。主张从 64px 起排，优先短句，保留判断成立所需条件。三格版适合真实并列内容，可从标题 44px、说明 26px 起排；不为字数配额删去必要信息。

深紫满色面可以承载主张，面积随内容安排。金线以外不加无关装饰，不叠阴影；图片出血页可使用保证文字对比的渐变遮罩。

常见失败：沿用内部报告的"题名＋概论＋三条分析"贯穿全稿；用建筑照证明教学成效；条件与办理信息缩成 17px 小字。

## 四、组件形态：统一起点

白底会放大无意的差异。同类组件沿用统一工艺值，学科对象、表格负载和语义分组需要变化时按实际功能调整。

| 项 | 值 | 说明 |
|---|---|---|
| 圆角 | 0 | 品牌是金线加锐角斜切，圆角与它冲突 |
| 描边 | 1px `#D8D8D8` | 深紫面上不加描边 |
| 阴影 | 无 | 全篇禁用 |
| 表格 | 行高与列宽按内容计算 | V11 以[表格系统](table-system-v11.md)的六类样式为准，表头、分隔线及 matrix 轻竖线按阅读任务设置 |
| 标签高度 | 26，内距 10，字号 17 | 直角，深紫或浅紫底 |
| 图标 | 线性，24px 图标配 2px 线宽 | 圆头端点统一，禁 emoji |

数字用等宽字形，单位紧随数字，差额与所属指标共基线。重点红 `#B4232C` 克制用于决定性差额、关键条件或当前步骤，避免满页争抢；分析图形用深蓝 `#1B385B`；浅紫 `#F0ECF5` 只把互相解释的材料收成一组。

## 五、白底上的视觉重心

白底没有色块兜底，重心靠四件事建立，按此顺序尝试：

1. **清楚的主焦点。** 每页先确定主要阅读对象，其他内容与之形成层级；需要同尺度比较的双方可以并列，避免无关对象争抢注意力。
2. **靠稀疏衬托。** 想让一块数据被看见，在它四周多留 1.5–2 倍空白，不加框、不加底。这是白底最省的手法。
3. **共享对齐线。** 题名、概论、主体、批注至少共享一条左边界。空白被对齐线框成规则形状，页面才不显得散。
4. **视线路径。** 结论落在上部或左侧起点，证据在中部，行动或条件在右下收束。避免四角均匀铺满。

细线 `#D8D8D8` 只用来分隔不同性质的材料，不用来给每块内容加框。距离已能表达分组时省线。

## 六、验收：五个体检

| 检查 | 做法 | 不合格的表现 |
|---|---|---|
| 眯眼 | 缩到 10% 看 | 分不出第一眼、第二眼、第三眼 |
| 认档 | 遮住场景名，只看字号与图文比 | 猜不出这是哪一档 |
| 信息负载 | 对照档位和实际使用动作 | 阅读距离下看不清，或完整材料与判断条件被删减 |
| 网格 | 看主要分区与相关材料的对齐 | 缺少共享对齐线、无意偏移；不因区内节点偏离主网格判错 |
| 一句话 | 读概论能否独立成立 | 概论是"背景、分析、策略"这类栏目名 |

出现实质阅读问题时回到档位与落位重排；仅超出参考字数或面积范围不自动判为不合格。

上述数值是起排参考；公开设计原则与经验区间用于理解主次和可读性，不构成普遍配额：留白 30%–40%、内容区占页面 60%–70%、字号层级比不低于 1.2、主标题对正文 1.5–2 倍、中文正文行高 1.6–1.8、单页要点不超过 5 条。正式交付前按真实投影条件复核一次：屏幕尺寸、房间纵深、投影亮度会推翻字号结论。
