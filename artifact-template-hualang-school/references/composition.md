# 从内容关系到整页构图

用于起稿和视觉修改。先按本页最重要的观看动作分配空间，再摆入元素。组件是证据的组织方式，不是预先画好的空框。

先识别顺序、归属、协作、比较、汇聚或分流，再选轮廓与摆法。方块、圆、色面、线条和开放文字都可使用；各自承担分组、重点、连接或材料展示。去掉方块后逐段加短线、通栏线和引线，同样会形成重复骨架。接近、对齐和共同区域已经说明关系时，可以省去线条。整页示意、适用条件与组合见[版式图谱](layout-atlas.md)。

## 五个尺度同时设计

| 尺度 | 具体决策 | 实页检查 |
|---|---|---|
| 整稿 | 各页新增什么答案、依据或操作；哪些内容确需连续观看 | 删除一页是否丢失必要信息；联排节奏来自内容推进，连续同构有教学或比较理由 |
| 整页 | 主体是什么，需要多大才能看清；阅读入口在哪里 | 缩略图仍能分清主次，放大后没有大片无作用的空白 |
| 分区 | 题干与解答、图像与证据、数字与条件怎样相邻 | 比较项共享基线；说明靠近对象；分区边界由关系决定 |
| 组件 | 表、图、批注、公式、照片组、路径分别解决哪个任务 | 不能用“放了三块卡片”回答组件选择问题 |
| 字与细节 | 数字/单位、变量/上下标、行距/段距、图注/主体的层级 | 后排能辨认关键字；断行有语义；没有孤字和被拆开的单位 |

## 可用的编排骨架

1280×720画布可用48px边距、24px栏间距、12栏网格起稿；它是对齐辅助，不要求每页露出格子。固定封面沿用原模板。普通页页眉与校徽稳定，正文可选择下列空间关系。

- **主证据＋边注**：约8栏给图/表/作品，余下4栏解释差异或条件。边注和其所解释的行、点、部位同高。适合数据判断、作品分析。
- **题干带＋推导舞台**：上部完整题干，下部按“公式推导＋函数/几何”分区；短题没有图时给两题独立区域。每道题内部的条件、问题、作答空间成组。
- **不对称照片组**：一张承担主要叙事，另外一至两张补充具体细节；用共同边线与图注建立秩序，文字放稳定留白。适合校园体验与对外介绍。
- **数字主场＋口径**：一个重要数值或一组可比数值占主体，紧邻单位、期间与含义。比较关系通过原生条形/点线图表达，不能用装饰圆环暗示比例。
- **原文＋贴边批注**：长文、史料、英文段落有行号，批注指向句段。文本必须可读，不把完整截图缩成装饰。
- **路径＋条件**：先识别并行选择和先后过程，再画路线。招生选择、实施进程、分类讨论各有自己的逻辑，不能通用三步箭头。
- **中心＋支持分布**：中心放具体对象或任务，外围安排真实支持者、资源或维度，关系词贴近连接。外围可用短说明、作品、照片局部或指标，按信息负载分配尺寸；长分析放在邻近证据区，不挤进小圆。只有真实循环才闭环。
- **包含＋层级**：用嵌套区域、缩进或分支说明学校、学段、项目的归属。上层概念与下层实例层级清楚，区域大小不暗示未经数据支持的规模比例；较长条件在所属层级旁展开。
- **汇聚／分流**：多项输入共同形成一个结果，或一个入口通向不同选择；节点写清输入、处理、出口与条件。并列事项不凭视觉平衡画成因果，交叉太多时分层或改泳道。
- **递进＋阶段证据**：沿实际推进方向布置阶段，阶段中的材料、解释和结果就近成组。只有时间或数值决定位置时才按相应尺度定位；普通叙述的阅读顺序不伪装为精确进度。

这些比例可以随实际材料改变。不要按页码轮流套版，也不以图片率、组件数或留白率作为完成标准。

一页先建立一个主构图，局部组件共同回答本页问题。例如中心关系配一处成果证据、主照片配局部放大、共轴比较配异常说明。不同组件沿同一阅读路径组织，字体角色、色彩含义、图像处理与间距保持一致；不把独立小图拼满页面。内部留阅保留解释和条件，课堂保留对象与推理，现场讲述按可见距离安排负载。

内部报告的整页选择与旧稿转换见[内容与版式选择](report-layouts.md)。阅读密度可以由完整主图、直接标签、沿对象对齐的解释段落和必要条件共同承担；不按统一字数分装成四块。概论之后优先展开一个足以支撑判断的主体，次级说明按影响分配空间，不要求等宽等高。

## 图文组织的实际动作

1. 写出照片要说明的对象，再决定全幅、横跨或局部。人物目光和动作尽量朝向版心，手部、实验器具、作品内容不被压字。
2. 一组照片用主图解释场景、次图解释动作或结果。三张同义建筑照不构成丰富叙事。
3. 图注说明观众应观察的细节；与正文重复时删去其一。长说明移到图旁空白，避免跨整页找对应。
4. 对比图保证相同尺度、方向、时间条件。图片背后的宽边框、彩块、阴影若不帮助分组就去掉。
5. 用黑色正文、少量重点色、字重、字号、距离和必要色面形成层级。金色留给短线、定位和深底强调；不靠处处加粗、每段编号或标签小胶囊制造层级。

## 重新审查旧版的典型失误

- 每页都放题名、概论、三栏小字：将主体还给实际图表、题目或图片，只保留有信息增量的解释。
- 教学一律大照片＋问句：先判断学科对象；数学需要公式/图形/推理，史料需要文本证据，实验需要装置与变量。
- 图片和文字各占一半却互不解释：按真实对应关系重排，必要时用局部批注。
- 为填满空白增加口号：重新分配主体尺寸；必要留白用于答案揭示或演讲停顿时保留。
- 看缩略图整齐就宣布通过：另看全尺寸页面和实际动画初始态，发现视觉重心、公式断行和答案泄露。
- 不同色块、分栏和组件名被误当成丰富排版：检查实页是否出现真正承载信息的成果、原文、数值、图形或关系，且有清楚的主次。仅去掉色块或改标签不能关闭问题；纯文字概览可保留，但不能成为全稿唯一表达。
- 先用截图预告、后用整页示例讲同一内容：没有新增任务时集中为一次完整解释；章节导航或教学复现确有使用价值时保留，并缩到所需范围。

## 相邻页审查

逐页底稿用一行记录“具体关系—主对象—主要组件—新增作用”，例如“前后比较—两次匿名作答—共面作品与就近批注—定位理由补充”。支撑、包含、分流、递进、比较、主证据等名称只作索引；实际关系句须说出对象及联系，不向观众展示这张制作清单。

缩略图先遮住页标题，保留图内标签、条件和关系词，看能否辨认关系与主对象，再将相邻独立议题的轮廓对看。相邻独立议题仅换标题，仍反复以等分条目或相同文字分区组织，未呈现各自实际关系时，须重排或合并；必要查数表、完整原文或充分文字论证不能为换轮廓而拆坏。最后回到实际尺寸检查信息和可读性，缩略图不能替代实页阅读。

用户明确指定组件次数、文字分行页数或相邻骨架限制时，列为本次任务约束，按实际页面逐项清点并遵守，不用换名称、去边框或左右镜像绕过。同页重复的同类组件按占用页登记，品牌固定项与正文主体分开说明；具体计数范围沿用用户要求。用户未指定时，以连续重复触发复核，不将某份介绍稿的次数上限推广为所有报告、课堂和长篇的固定配额。若约束与必须稳定的题干、坐标或连续对照发生实质冲突，先利用可变区域重排，仍无法兼顾时明确冲突，不擅自豁免。

主体关系成立后，按[微观精修](design.md#微观精修)统一同类文字、组内外间距、线条语法、标注衔接和视觉分量。丰富版式与精细完成是两个检查面；不继续堆组件来掩盖细节不齐。

长稿和教学序列必须执行[长篇编排](longform-layout.md)。重复骨架或ABAB轮换触发内容与实页复核；同题推理、必要对照和持续阅读可稳定题域。先判断重复是否帮助理解，再决定合并或重排，不为通过标签检查打散内容。换色和左右镜像不证明主体变化。
