# 主对象、网格与信息负载

本参考用于把已经确定的内容结构排成可读页面。读者任务与证据顺序先按[场景设计](scene-layouts.md)确定；品牌边界、概论层级与字级按[视觉规范](design.md)执行。正文近白底保留，具体证据、照片、模型和有功能的紫色面可以跨栏组织。设计网站的实页依据见[排版研究](layout-research-v10.md)。

## 起排前确定三个角色

- **主对象**：本页最值得被看见的具体材料，如完整费用比较、决定解法的图形、原文及争议词句、前后作答、一个真实校园活动。它必须能被读、看、比、推或查，不能只有“能力、成果、方法”等泛词。
- **解释**：帮助读者完成动作的理由、批注、差额、方法、对照或反馈，贴近所解释的对象。
- **条件**：影响判断或作答的范围、单位、统计期、限制与事实属性，靠近所属证据；必要条件保持正常可读尺度。

主判断或正式概论属于正文第一层，用清楚的字重、颜色与空间承载。模拟性质、统计期和来源说明属于元信息。不能把两者合并成每页自动出现的灰色小字条，也不要求所有页面都有概论。

逐页底稿只需说清：“读者要做什么；主对象是什么；本页新增什么；为什么需要这些解释和条件。”先把材料展开到足够完成任务，再分配页面；无材料支撑时缩小结论。

## 网格用来建立联系

沿用模板安全区，先确定主对象的可读尺寸，再用对齐网格安排附近材料。可用12栏作为起排工具，跨栏对象、不同宽度和局部嵌套均可采用，不把整页先等分成若干文字区。

| 当前需要 | 起排动作 | 实页要看见什么 |
|---|---|---|
| 同口径数值比较 | 固定共同尺度与列序，把主图、差额和相关解释沿相同基线组织 | 值、单位、期间和比较基准可直接查到；解释不漂在远端 |
| 作品或原文解释 | 给原文、作品足够宽度；批注与对应行、词句或部位同高 | 读者能指到依据；短初稿与长修订稿按负载分配空间 |
| 公式、图形与推理 | 完整题域保持稳定，图形和理由靠近相应条件或步骤 | 从题意到表示、到推理、到结论的联系可以跟随 |
| 过程或空间路径 | 阶段中的材料、动作、结果成组；地点或时间有实际尺度时采用该尺度 | 先后、并行和归属没有被混画；每段有具体对象 |
| 多字段交叉查阅 | 按读者要查的维度建立行列，列宽随实际内容调整 | 行列具有真实比较作用，字段、单位和口径完整 |
| 一幅主照片与若干细节 | 主图保留动作或空间，细节图与图注共用边线 | 照片有不同的信息作用，关键人、物与作品不被裁坏 |
| 支持、归属或多路分流 | 按真实关系与负载安排节点，长说明放在邻近区域 | 每个出口可追到入口，关系词和连接落到可见对象 |

组内距离应明显小于组间距离；相互解释的材料共用基线或邻接关系。留白用于分组、呼吸、观察、独立作答与揭示。无作用的空廊先收拢，再把空间交给具体材料；不能用细线跨过大片空白来假装建立联系。

## 视觉分量来自内容作用

同一页要能分清“先看什么、再看什么、核对什么”。面积、字级、字重、颜色和位置一起决定分量，具体数值、作品、原文或模型可以明显大于导航标题。泛议题和空泛口号不占据最大展示尺度。

**有功能的色面可以形成主体。** 紫色区可承载主判断、完整任务、关键证据或阶段关系；浅紫区可把相互解释的材料收在一起。色面宽高随内容负载调整，正文仍保持清楚的黑字或深底白字层级。近白底上的大图、函数图、实验装置、作品或数值系统也可以承担主要视觉分量，不为凑色块再加一套框。

**开放排布仍需成组与主次。** 去掉边框后，几组小字均匀散在四角，或每段加一条短线，仍需重排。让一个足以支撑本页任务的对象连贯展开，解释跟随对象，次级材料依其作用安排。卡片适合真正独立、并列且负载接近的项目；表格适合查阅；二者均按内容使用。

照片与图形跨栏时，页眉、校徽和安全区继续保留。图文不能互相压住关键证据；人物目光、手部动作、器材与作品优先保持可辨认。对照照片和图形保留可比的尺度、方向与条件。图注说明应观察什么，避免重复正文。

## 不同任务采用不同主体

以下是材料选择的起点，不是按页码轮换的固定版型。

| 对象与用途 | 有效主体与阅读路径 | 容易失效的处理 |
|---|---|---|
| 管理判断 | 正式概论统领同口径比较；明细、差额、原因/取舍与条件就近展开 | 大图只配两句释义，或把相同数据换图再讲一次 |
| 教师备课 | 学习目标与活动、预期作答、观察证据和调整相互对应；活动按真实教学推进 | 只有“导入—新授—练习”几个标签，缺教师可执行的提问与反馈 |
| 数学与理科课堂 | 完整题目或对象、准确表示、关键理由、方法边界与独立任务形成学习单元 | 只放公式和答案，或把普通例题拆成多张低信息页 |
| 文本与人文课堂 | 可读原文/材料、词句证据、解释链与比较任务相邻 | 用泛化三步和大照片替代材料分析，批注指不到原句 |
| 复习与检测 | 题组围绕条件、表示、方法或情境递进；作答与反馈可回到相应题域 | 只换数字凑题数，或为统一大字号删题干条件 |
| 家长反馈 | 真实或明确标识的作品、变化、解释、仍需支持处与家庭行动形成对应 | 只有宣传性照片和结论，把群体统计写成孩子表现 |
| 招生与开放日 | 真实体验、可验证特色、课程/选择条件和下一步分工；照片、作品或空间成为主体 | 全稿套管理指标页，或全是大图短句而缺少选择条件 |

完整课件按学习单元核查容量，见[教学深度](teaching-depth.md)与[教学设计](teaching-design.md)。一页常规例题能容纳完整题干、图形、推理及关联变式时保持同屏；长题按真正的推理边界续页。初始态可为作答留白，完整末态仍需足够解释。课堂、教案、练习与管理材料不共用同一负载标准。

## 从草图到实际页面

1. **先排主对象。** 在安全区内给它足以读清内容的面积，再安排解释与条件。主对象无法独立辨认时先解决尺度或内容组织。
2. **确定阅读入口。** 管理页可以从主判断进入证据；课堂可以从完整任务进入对象与推理；家长可以从作品变化进入解释。概论、任务和元信息分别安排，不自动堆在同一条顶部说明带。
3. **收紧对应关系。** 批注贴近词句、差额贴近数值、理由贴近步骤、图注贴近图。连接须落到可见端口；接近或对齐已经足够时省线。
4. **分配剩余空间。** 依据实际负载确定节点、段落、图表及色面的宽高。短内容不拖长色尾，长内容不被塞进小圆或窄槽；先删除同义复述，再判断是否需续页。
5. **检查细节。** 数字与单位共用基线，公式与变量准确，字级角色一致，首末行余量稳定。具体标准见[微观精修](design.md#组件与微观完成)。

## 整稿与实页复核

- **缩略联排**：第一眼是否落到有内容的对象；连续独立议题是否反复靠同款分栏小字组织；作品、图、表、原文和模型的轮廓是否随材料改变。不同版型名称、换色、镜像或去框不能代替观察。
- **实际尺寸**：主判断清楚可见，必要材料可读；表图有足够的信息与比较基准；解释、条件、批注和连接能够直接对应。发现大片空白时先查材料是否展开充分，再调整主体尺寸。
- **遮名试读**：遮去场景标签后，仍能从主体看出管理比较、教师活动、学生推理、家长作品或招生体验。只改变字号、称呼、颜色和`purpose`参数不算通过。
- **删除试读**：删去一页是否会失去必要判断、证据、推理或独立操作；同一素材再次出现是否增加了比较、理由或任务。复习、同题推理和稳定坐标确有作用时保留必要复现。
- **教学试读**：拿到该学习单元，教师能否讲解关键理由，学生能否独立作答并得到相应反馈；题目、图片和答案齐全仍须检查这些联系。

连续同构触发复核，保留同题推理、同尺度比较与持续阅读需要的稳定区域，不设所有任务统一的组件次数或版型配额。用户明确指定次数、相邻页和分行限制时，按实际对象清点；与必须稳定的题域发生冲突时先重排可变区域，仍无法兼顾再说明冲突。

用户否定视觉后撤回旧结论。整改保留同材料前后实页，指出主判断如何恢复层级、哪项证据被放大、什么关系更易跟随、教学内容补足了什么。不能删去难排材料、换一份容易素材或仅重跑自动检查来证明改善。长篇序列另按[长篇编排](longform-layout.md)核查整稿内容推进。
