# 高中分学科设计

根据年级、教材模块、必修/选择性必修、复习阶段及当前任务决定深度。高考真题保留实际卷别/年份与原题条件，未核验来源的自拟题只标原创。下表是规则索引；成品默认以学科对象和小组件展开完整推理，表格只用于确需行列交叉的多字段查阅或同口径数值，见[教学设计](teaching-design.md#学科对象与小组件优先)。

| 学科/任务 | 教案重点 | 页面主体和排版 | 完整性检查 |
|---|---|---|---|
| 数学：函数/导数/不等式 | 定义域、参数范围、关键转化、分类依据、边界检验 | 题干紧凑置顶，代数推导与函数图相邻；可保留完整多问解答与方法注 | 图式一致；恒成立/存在性不混，等号与端点交代 |
| 数学：解析/立体几何 | 图形关系、坐标/向量选择、计算与几何意义 | 图形固定一侧，推导按设问，辅助线和变量稳定 | 图中对象不消失；坐标、方向、垂直/平行成立条件完整 |
| 数学：概率统计 | 随机变量/事件、模型假设、分布、计算、解释 | 树图/分布表/统计图与计算并置 | 样本、独立性、条件概率、期望含义清楚 |
| 语文：文本群/文学/论述 | 核心问题、证据链、手法与效果、不同解释、表达迁移 | 可读原文或双文本、行号、分析批注；结构图服务论证 | 不只列手法名称；论点由具体语句和语境支撑 |
| 语文：写作 | 题意、材料关系、论证结构、例证、反驳与修订 | 材料—论点—段落示例—评价并置 | 作文框架不替代实际段落；修改有具体位置与理由 |
| 英语：语篇/写作/续写 | 语篇结构、推断依据、语言选择、连贯、评价标准 | 原文、情节/论证关系、证据批注和产出示范 | 保留语境，不把语言训练压成词表；双语按需支架 |
| 物理：动力学/场/电路 | 研究对象、过程分段、模型假设、物理规律、结果检验 | 情景图、受力/等效图、方程、数值与单位同屏 | 正方向、相互作用、适用条件、量纲与极端情况 |
| 化学：平衡/电化学/有机/实验 | 守恒、微观机制、条件变化、证据、误差/安全 | 条件/数据、反应式/装置、推理链与实验评价对应 | 配平、状态、电子转移、平衡条件、限量判断 |
| 生物：遗传/调节/生态/实验 | 模型、机制、变量控制、数据处理、证据边界 | 遗传图/机制图/实验设计/数据图与解释 | 相关与因果分开，样本/重复/对照、统计表述准确 |
| 历史 | 时空背景、史料性质、观点比较、证据解释与论证 | 同主题多份短史料、来源提示、时间轴/地图及证据连线或完整论述；确需多字段查阅时再用证据表 | 来源/立场/范围不能省；避免史料摘录与结论脱节 |
| 地理 | 多要素机制、尺度、区域比较、过程与人地关系 | 地图/剖面/曲线、条件标注、机制链或区域同尺度比较 | 图例单位、区域范围、条件变化与因果链清楚 |
| 思想政治 | 概念适用、事实材料、观点论证、矛盾与边界 | 案例事实与理论依据同域，论证和反例/限制明确 | 不把主张当证据，不编造政策事实或绝对因果 |
| 信息技术/通用技术 | 问题定义、设计方案、算法/结构、测试与迭代 | 需求、关键实现、测试数据与改进对照 | 代码或流程能运行/解释，技术判断有测试依据 |
| 体育/艺术 | 技术要点、策略/创作意图、练习与评价 | 视频关键帧、动作/谱例/作品局部、反馈标准 | 不用装饰大图代替分析，安全和资源条件保留 |

高中完整解法允许一定信息密度。按“同页是否能完成一次推理或比较”决定拆页，不能把一题拆成只有一行的大字号页面。分类讨论过长时保留公共题干与图形坐标，按分支续页。

## 综合程度来自推理关系

高中课件不能只把初中同款卡片中的词替换为更难术语。先确定本课需建立的结构与关键转化，再选择可支撑它的完整材料。

| 学科组 | 可执行的深度展开 | 独立产出与反馈 |
|---|---|---|
| 数学 | 比较方法成立条件，推导分类分界，检验量词、等号、端点和退化情形；模型说明可行域及整数限制 | 改条件而非只换数，要求说明选法与边界；漏分支、错量词、模型超界分别给重试 |
| 语文/英语 | 文本证据→语词/结构作用→有范围的解释，比较不同读法；写作给完整论证/叙事片段及修订理由 | 学生写一个实际分析段或修改段；反馈定位证据不足、解释跳跃、连贯或语言选择 |
| 物理 | 研究对象→过程/受力或等效模型→规律及适用条件→方程→结果解释；对比另一建模选择 | 新情境先画模型再列式；反馈区分对象选择、过程划分、符号和规律适用错误 |
| 化学 | 在守恒约束下联系宏观证据、微观过程与符号，讨论条件改变与机制解释；实验方案考虑干扰/误差 | 要求由数据作判断并给依据，或比较两方案；不能只背结论与反应式 |
| 生物 | 机制模型与实验数据相互检验，区分必要/充分、相关/因果，考虑对照、重复及替代解释 | 设计追加验证或修订过强结论；反馈具体指向变量、证据和推断范围 |
| 历史/地理/政治 | 多材料围绕同一问题比较，保留时空/尺度/立场，建立带条件的论证或机制链 | 输出含材料依据、解释和边界的段落；指出事实错误、证据脱节或单一因果 |
| 技术/信息与艺体 | 需求/意图→方案/表达选择→测试或作品证据→比较与迭代 | 提交可观察产物及选择理由，使用一致标准评价并修订，避免空泛“创新性” |

难点材料允许跨页保留共同图形和坐标；变版式不能打断同一条推理。概念索引、方法比较、完整例题、错解诊断和迁移检测承担不同任务，不能全部做成知识点摘要。可用[教学深度示例](teaching-depth.md)校准参数问题、文本分析和实验评价的展开程度。
