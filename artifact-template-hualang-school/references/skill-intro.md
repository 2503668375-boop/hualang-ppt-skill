# 工具介绍与使用培训

本参考用于介绍这项技能或培训实际使用者。学校经营汇报、家长材料和课堂教学继续使用各自规则；介绍稿中的例子用于证明方法，不扩成完整课程或经营方案。

## 先确定听众要得到什么

| 使用目的 | 看完应能回答或完成 | 主体内容 |
|---|---|---|
| 初次了解、判断是否适用 | 我的哪项任务可以交给它；要交什么；成品长什么样；怎样开始 | 使用范围、一例可见成品、短请求与实际入口 |
| 内部使用培训 | 能独立完成一次提交、核对和修改；知道缺材料时怎样处理 | 实际材料与成品、关键取舍、一次具体修改、可操作的练习 |
| 专业制作或维护培训 | 能完成指定工具操作或修订规则 | 对应操作与文件、失败情形和结果核对；按本次岗位要求展开 |

用户列出的必答事项优先。初次了解可从含固定首尾的5—6页估算；内部使用培训可从8—12页估算。它们是容量起点，不能由页数替代覆盖、可读性和操作完成；用户指定页数时沿用指定要求。新增一页须增加答案、证据或独立操作，不能靠拆章节延长。

下面是可调整的页序示例，既不要求全部采用，也不规定其他任务的页数：

- **6页初次介绍**：固定封面 → 适用任务与对应成品 → 一次具体材料的处理和可见结果 → 首次请求与附件 → 获取、修改及影响使用的条件 → 固定封尾。
- **10页使用培训**：固定封面 → 适用任务 → 案例原材料与待解决问题 → 处理后的实际成品及取舍 → 另一使用对象的实际局部 → 一次明确修改及结果 → 提交材料与首次操作 → 使用练习及核对方法 → 可用入口与必要条件 → 固定封尾。无第二场景或专业操作需求时合并相关页，不补泛泛规范。

固定品牌、色值、对象坐标、检查脚本与完整制作规则放在技能包。听众需要据此操作时，才展示对应的具体环节。介绍“可编辑”应让人看到能改的表格、图形或文字局部；介绍“分步讲解”应展示实际初态与末态，不能以组件清单代替成果。

## 用成品证明能力

至少有一处可辨认的实际产出：打开已有PPT中的适合局部，或用本次材料真实生成一页。必要时放大核心区域，让读者能看见题目、原文、图表、作品或具体处理结果。只写“最后得到三份材料”“这里放曲线、表格和分式”，仍属于制作计划。

实际产出可以使用原创题例、虚构案例或模拟数据，明确其性质即可；不要求为介绍技能索取学校内部数据。**文件确已做出**与**案例事实真实发生**分别判断。候选素材见[样张索引](sample-index.md)，先按要证明的能力选择局部，再核对其内容与当前规则。

每个案例指出三件事：材料里的具体问题，结果中可定位的改动，这项改动帮助谁完成什么。短介绍集中解释关键一例；培训按需要增加不同场景或实际修改。不把样张数量、图片占比或六类用途全部演示作为配额。

同一素材在不同页出现时，简记每次新增作用。若P4已给出比例、差额和结论，P5仅换成条形图再说一次，就应合并或让其中一页专门回答另一问题。需要比较时保留共同基准，连续操作可保留稳定对象；不能为去重删掉理解所需的条件。

## 先审材料能支持哪种成品

总体数据、个体记录和学习任务不是同一种材料。仅有“同班50人，前测32人、后测39人达标”，可比较64%与78%、净差7人、提高14个百分点及后测仍有11人未达标；它不能识别哪7名学生改善、每个孩子会做什么、典型错误或措施因果。

- 管理示例可把总体变化、判断边界和需补的诊断资料放在同一阅读单元。缺少责任与复核日期时，保持待补或明确为拟议，不能写成已落实。
- 家长示例若要说明个体变化，需匿名作答或个人反馈依据。缺材料时说明需补什么，或另用有标注的原创个案，不能将群体均值改写成孩子事实。
- 课堂示例需要完整题目或原文、条件、推理及独立任务。没有这些材料时，可以说明所需输入，不能声称已由总体达标数形成课件。

展示“三种成品”时，三处都应让人看见可辨认的成品局部；若只是说明差异，题名与承诺相应收窄为“场景处理差异”，不要以三段设想冒充三份成果。必要的模拟标识靠近数据或案例主体，裁出该局部仍能辨认性质。

## 让介绍内容便于使用

用途表用“我要做什么—交什么材料—拿到什么”说明能力。包内参考文件名和目录只在安装、维护或专业操作确有需要时出现。对新使用者给实际可用的获取路径，对已安装者给最短调用方式；一次修改写明页码或对象和目标，并体现关联数据的同步核对。

用时、节省工时、使用成效和版本对比按任务需要加入。没有测量记录，不编造效率数字，也不必单独加一页“尚未统计”。用户需要版本变化时，选与其工作相关的改动，用可核对的前后局部或行为说明；单列新增规则名称不能证明改进。

现场介绍与留阅说明可采用不同负载。长入口、安装步骤或详细边界可以单独附使用说明，保持观众材料的主线。不要机械将拥挤页拆成两页：先去同义复述、内部术语与无关过程，再判断是否确需独立操作页。坐标、字号与空白位置的调整依据实际文件和观看距离，不能直接套另一份稿子的测量值。

## 交付前试读

由未参与制作的人或制作者隔开原提纲，先看成品，再对照任务：能否说出适用任务、必需输入、实际结果与开始方式？介绍中的主要能力是否有可见对象支持？能否指出一项具体修改怎样完成？

再做删除测试与实页检查：跨页重复有没有新增作用；缩略图中的主对象是否多为真实成果，还是仍在连续阅读文字分区；放大后材料、条件与标识是否可读。必要表格与文字概览可以保留，不为“图形更多”将清楚的信息强改成装饰图。

最终文件、真实渲染、结构镜像、应用放映与实际使用分别说明。样张存在、自动检查通过或审查记录齐全，不等于已完成视觉与现场核验；具体路径见[成品验收](review.md)。
