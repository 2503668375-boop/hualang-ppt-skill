# 课堂、家长沟通与外部演讲

所有场景共用[华朗视觉规范](design.md)的色值、字族、图片与表格规则。场景改变的是听众任务、信息密度和构图。先判断材料是现场投影、课后留阅，还是两者兼有；已知用途直接执行。研究依据与适用边界见[研究依据](research-basis.md)。

<a id="课堂教学"></a>

## 课堂教学：让学生有东西可观察、有任务可完成

先写学生在这一段结束时要会做什么，再安排示范与练习。屏幕保留学生需要反复查看的题干、条件、文本、图示与关键推理；教师口述负责解释和追问。不要把“培养核心素养、激发学习兴趣”当作教学页的主要内容。

| 学习任务 | 实际布局 | 内容检查 |
|---|---|---|
| 看懂概念 | 主图占主体；定义紧邻对象；例与反例同尺度并列 | 成立条件、单位、变量和边界完整；图能指向具体概念 |
| 阅读与取证 | 左侧或通栏保留必要原文；证据直接高亮；短批注贴在对应句旁 | 原文不随意删改；引文与判断之间有解释；不能只用“观点—证据”空框 |
| 推演方法 | 题干和图保持位置；步骤在稳定区域依次出现；当前一步有一致提示 | 每一步有依据；不让学生同时寻找条件、追动画、抄全部答案 |
| 比较与辨析 | 两份解法、作品或实验条件等尺寸并列；差异标在原对象上 | 比较维度一致；指出具体差异及其影响，不能只写“好/不好” |
| 解释关系 | 原生概念图、数值坐标图、机制图或实验装置；标签靠近对象 | 连线方向与关系正确；坐标、尺度、变量与因果不混淆 |
| 独立练习 | 题目、必要材料与作答要求占主体；留出作答或讨论空间 | 学生知道要写/说/画什么；完整答案在后续页或教师稿 |
| 反馈与迁移 | 匿名错例＋局部批注；修正后作品或变式题放在相邻页 | 说明错在哪里、怎样改、如何自检；反馈能回到学习目标 |

**分步的理由是学习节奏。** 示例、尝试、反馈可以跨相邻页，原始材料的位置保持稳定。静态课件优先用连续页表达状态；使用动画时同时检查放映顺序及 PDF 导出，不能让答案提前暴露或把关键步骤导出丢失。题干、公式、必要原文过长时，按理解单元分段或配置材料页，不能为了少字删掉条件。

**图片必须承担教学功能。** 科学页使用可识别的装置和变量，几何页让标注贴近边与角，阅读页展示具体文本与作品。图片、箭头和颜色提示要帮助定位对象；无关校园照或卡通装饰不能冒充图解。涉及学科色义时保留必要颜色，同时用标签或线型帮助辨认。

### 复习、备考与教研

复习围绕“错误表现—依据—修正—变式—复测”组织。把“粗心”落实为漏读条件、单位错误、推理缺环等可检查行为。不同试卷的分数比较交代范围、难度和评分口径；总分差不自动等于能力提升。使用匿名错例与汇总分布，避免公开个人敏感信息或用羞辱性排名讲课。

教师教学示范、共同备课、培训演练采用上述课堂布局，并保留作业样本、提问方式、评价标准及观察到的学生反应。教学质量审议、资源申请、管理复盘则按[内部汇报](internal-report.md)保留数据、比较、费用与责任。教研材料不能只剩政策摘抄、理论术语和活动照片。

<a id="家长沟通"></a>

## 家长会与招生说明：现场能跟上，留阅能办事

先回答家长真正关心的问题：课程适合谁，孩子会做什么，学习支持怎样发生，家庭如何配合，费用和时间有什么条件，下一步在哪里办理。理念用课程安排、真实作品和具体做法说明。

### 现场讲述页

以可辨认的真实课堂、学习作品和清楚的路径为主体，主句短而具体。可以采用大图和大字，但需让图像证明或解释本页内容。常用布局：

- **作品对照**：两份匿名作品等尺寸并排，在原文旁标“有判断但缺依据”“加入文本证据并解释联系”等具体变化；交代任务与评价标准。
- **课程体验**：一张课堂活动主图＋一个问题或短句；用一至两处批注指出学生实际做什么。建筑照片只交代场所。
- **支持路径**：学生、教师、家庭三方在同一时间轴或责任图上说明动作、反馈与复盘。不能把“加强监督”作为家庭唯一任务。
- **路线选择**：两至三条路线采用相同维度比较，突出适用条件与下一步；现场表格以远处可读为准。

### 留阅与办理页

保留家长需要查阅的课程、费用、时间、材料、条件和联系方式。用原生表格、流程、日期表或简短问答，优先保证准确可查。现场展示与留阅并存时，讲述页聚焦问题与证据，信息页承载办理细节；用户未要求另一份文件时，可放在同一文件的明确位置，不机械加交付物。

课程、收费、奖学金、招生条件和日期以当期材料为准。升学数据区分人数与录取份数，说明届别、截止时间和重复录取口径；个人案例不能变成普遍保证。生成照片、虚构作品、示意校园不得冒充华朗实况。

## 外部演讲：用一页一个焦点配合讲述

舞台演讲可以连续采用大字页、整幅照片页和单图表页；这些是适合远距观看的主力页型。先确立听众关心的问题与主张，再用案例和证据推进。不要沿用内部材料的“标题＋概论＋多条分析”结构贯穿舞台稿，也不要把所有讲稿搬到屏幕上。

| 讲述目的 | 推荐构图 | 边界 |
|---|---|---|
| 提出问题或核心主张 | 一至两行大字；可配一张有含义的图 | 主句说清具体观点；避免“赋能未来”等泛泛口号 |
| 让观众看见对象 | 一张主图占大部分画面，短句放在自然留白或稳定遮罩上 | 图像清晰、有正确出处；文字不压住关键证据 |
| 展示变化 | 同尺度前后对照或一条趋势图，重点直接标注 | 基期、样本和口径可核对；主图不塞多个无关结论 |
| 解释如何发生 | 简化但准确的机制图、三步过程或作品批注 | 保留解释所需的关系与条件；复杂过程按讲述分段 |
| 给出决定性证据 | 一个数字与比较基准，或一个清楚图表 | 不能只有孤立数字；必要分母、单位、时期不丢失 |
| 引导后续行动 | 一个明确行动、时间与入口；必要时加简短流程 | 不杜撰联系方式或承诺，不把办理详情缩成小字 |

在现场需要逐项比较的内容仍可用可读的表格；详细政策、研究和预算另安排材料页或讲义。页数由讲述与互动决定，不能硬套“每分钟一页”。字号先按[视觉规范](design.md)取值，再从实际投影距离检查；实际未排练时如实说明。深浅底切换遵循共同视觉规则，不逐页换主题。

## 场景规则服从本次主题

本规范决定课堂、家长或演讲成品如何表达。用户要求介绍这些场景的制作方法时，页内示例只用来解释相应方法，主线仍是用户要求的介绍。具体课程与业务主题不能由模板示例代替本次资料决定。

普通业务与教学成品避免制作自述；工具介绍或方法培训本来就需要说明输入、处理与输出，可以用实际局部页面解释，并说明使用动作。按[从任务到页面](workflow.md)和[验收](review.md)核对主题及用途。
