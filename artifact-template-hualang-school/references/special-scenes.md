# 教育与展示的特殊优化

本篇在公司通用要求之上处理学生、家长和外部听众的特殊观看任务。图表化的目标是把关系、过程、证据和选择看清楚，减少散文说明的负担。不能只删文字、放大字号，留下几个标签和空白。

## 课堂：把知识关系画出来

先确定学生需要完成的可观察表现，再组织概念、例子、推理、练习和反馈。一个学习任务可以在同页包含图像、条件、例题和检验题；只有推理需要分步、答案暂不揭示或现场确实读不清时才拆页。学科结构优先，不把所有课程套成相同目录。

| 任务 | 优先组件 | 必须保留 |
|---|---|---|
| 建立概念 | 概念图、图文对应、例与反例、特征矩阵 | 定义、成立条件、单位、变量、边界和关键标签 |
| 解释关系 | 数值坐标图、机制图、因果或条件链、同尺度对照 | 方向、对应关系、证据支持程度；相关不冒充因果 |
| 展示推理 | 分步例题、图上批注、实验记录、文本证据标注 | 每一步的依据与必要计算，长题干完整 |
| 独立练习 | 分组任务卡、半完成示例、变式题、作答区域 | 明确动作和提交结果，题目与答案区分 |
| 检查理解 | 提取题、解释型问题、迁移题、出口题 | 学生自己形成答案，不能只看屏幕抄写 |
| 反馈改进 | 错因矩阵、两种解法对照、修改前后作品 | 为什么错、怎样改、如何自检 |

减少文字时先把长解释转换为贴近对象的标注、步骤、表格或图示；删除重复叙述。题干、公式、原文、成立条件和推理依据属于必要信息，不能为追求“少字”删去。讲解留给教师口述，屏幕保留学生需要反复观察的内容。需要字幕、关键词或释义支持时按学情保留。

初中可更多使用具体例子、标签与句式支架，高中保留严谨的学科推理与条件讨论；不能仅凭年级推定能力。研究支持例题与练习交替、图文就近结合、间隔复习、提取和解释型问题，但效果依赖内容与实施。来源见[研究参考](evidence-and-school.md#教育与演示研究)。

## 复习、备考与复读

围绕错误表现、诊断依据、策略、变式练习和复测组织同页或相邻页。把“粗心”细化为漏读条件、单位转换、推理缺环等可检查行为。可以用“题型／错误表现／原因证据／修正方法／检验题”矩阵，也可以把批注直接贴到解题步骤。

保持学术难度与尊重。集体课使用匿名错例与汇总分布，不公开学生姓名、心理与家庭信息，不以羞辱性排名或保证提分组织材料。不同试卷比较要说明范围、难度和评分口径，不把两次总分差直接写成学习提升。

教师提示和标准答案可放备注；学生可见页按课堂顺序呈现。静态 PDF 要能读到所需过程，动画版检查导出是否遗漏答案、步骤或遮挡状态。用户只要课件时不默认扩展为另一整套讲义。

## 教师教研的两类任务

教学质量审议、资源申请和管理复盘按[内部汇报](internal-report.md)保留正式概论、数据与论证。教学示范、共同备课和培训演练采用课堂组件，但仍保留匿名作业、提问方式、评价标准与学生反应等证据。

一段完整教研可包括问题证据、课例拆解、两种做法比较、共同演练、反馈及课堂应用。用“学生能代入但不能解释变量关系”等真实问题起稿，区分观察、原因假设和已证实事实。不要只有政策摘抄、理论术语和成果照片，没有可复用做法。

## 家长沟通与招生说明

按家长的具体选择组织：课程适合谁，学习与生活如何安排，学校提供什么支持，家庭怎样配合，后续在哪里沟通。理念通过课程安排、真实学习作品、教师做法与评价路径说明。

| 家长需要理解什么 | 合适组件 | 同页应交代 |
|---|---|---|
| 课程和发展路线 | 课程路径图、条件分支、同维度比较表 | 适用学生、学习要求、实际选择条件与下一步 |
| 学习进展 | 匿名分布、能力矩阵、前后作品批注 | 样本与标准、已看到的进步、仍需支持的具体点 |
| 支持如何发生 | 学生—教师—家庭责任图、反馈时间轴 | 各方做什么、怎样联系、何时复盘 |
| 入学与申请 | 办理流程、材料清单、日期表、问答区 | 当期要求、截止时间、条件与联系途径 |
| 活动参观 | 场地图片批注、路线与活动时间表 | 在哪里、体验什么、家庭能据此判断什么 |

少用专业缩写和大段校方口号，保留费用、条件、时间等家庭真正需要的字段。把“加强监督”改成适合家庭实际的行动，如约定学习时段、请孩子解释方法、反馈一个困难。保持积极、具体、双向沟通，不默认把教学责任转给家长。

课程、收费、奖学金、招生条件和日期以当期材料为准。升学案例注明届别、人数或录取份数、统计截止与重复录取口径。个人案例不代表普遍结果，不能转为录取或成绩保证。真实学生资料和照片按使用范围处理，不能用合成通知、生成学生或虚构作品伪装校情。

## 对外演讲与展示

围绕一个听众关心的问题展开各讲述单元，主张由案例与证据支撑。可采用主图＋数据标注、案例前后对照、机制图、时间轴或关键数字与构成。几项关系能用图说清时减少旁边散文；事实不足时不扩大主张。

开场可以用问题、场景或清楚主句，主体必须有内容。舞台上需要短暂聚焦的单句页可以偶尔使用，不能连篇作为整套报告默认页型。复杂方法、必要比较和条件仍可保留一页完整图解或表格。页数按实际讲述与互动安排，不按固定“每分钟一页”硬算。

照片要对应所讲对象。校园图可交代场所，作品和课堂片段可展示学习过程；建筑照片不能证明教学成效。公开学术材料按需要列作者、年份及必要出处，详细引用可放备注或参考文献。学校内部经营细节不因演讲场景自动公开。

## 特殊场景的验收重点

读者是否能沿图、表、步骤或标注完成理解，还是仍需要读旁边长段文字？删去文字后，条件、关系和证据是否仍完整？组件是否帮助比较和行动，还是只添了方框？课堂目标是否有对应练习，家长是否能找到自身相关信息，演讲主张是否有具体支撑？

表格用于可比字段，图解用于结构和关系，照片用于认识对象，任务卡用于独立任务。按内容选择并组合，不规定每页必须包含某种组件，也不把“组件丰富”解释为整页卡片墙。
