# 图片、证据与留位

先确定图片在本页承担什么，再找图或留位。图片是内容的一部分：有些页需要场景、动作、作品或空间证据，有些页的主对象就是原文、公式、数据或关系，不为增加图数挤掉这些对象。

## 按信息作用选图

| 需要观众看懂什么 | 优先对象 | 配图后仍须保留 |
|---|---|---|
| 实际发生了什么 | 同一事件的场景主图、动作近景、产出局部 | 时点、对象与图像能证明的范围；一张参与照不能证明学习效果 |
| 作品怎样变化 | 同一任务的匿名初稿、修改稿及批注 | 完整题目/评价条件、可辨认词句、差异解释；前后保持可比尺度 |
| 结构、机制或推理 | 原生关系图、装置图、函数/几何图或有针对性的示意 | 条件、方向、变量、比例与论证；装饰插画不替代准确学科图 |
| 数值差异或趋势 | 原生图表与直接标签 | 单位、分母、期间、共同尺度及结论边界；不把图表截图当作必须修改的数据对象 |
| 校园空间与体验 | 已有授权场景图，必要时配动作/作品补证 | 真实空间与活动安排分清，不能从建筑照片推导课程实施或学习成效 |
| 演讲主题与现场感 | 一张能解释主句的主图，配必要局部 | 完整讲述单元的事实与条件；不反复用校园外观照替代所有主题 |

优先用用户素材与已核实且允许使用的原片。既有素材先看图与[来源记录](../assets/media-sources.md)，不把历史照片写成当期事件。需要示意时可用生成图并清楚标识，不能替代真实师生、活动或作品证据。现有素材不合题时，宁可保留明确图位，不用无关图片填满。

## 图与文字共同设计

- 主图负责本页最重要的观察，次图只补不同信息。可以主次照片、全景与局部、前后作品、图旁短文或原文批注；不预设“左文右图”或每页三图。
- 先确定应保留的人物动作、作品内容、建筑边界及原署名，再定横竖比例和裁切。标题/色块不压住关键证据；图注在图外或真正稳定的留白区。
- 需要比较时保持尺度、方向与观看条件。不同长宽比的原片可用不同大小区域，不能为整齐裁掉内容。
- 复杂解释贴近相应部位；远距讲述短，留阅说明可展开。图片很大而正文只有泛话时，补能从图观察到的事实或收紧图片，不能只增加形容词。

## 缺图时怎样留位

用户允许留位，或现有素材不足时，可交付清楚标识的留位版。每个图位至少有：所需主体、图片用途或应保留的关键内容、明确的“待补图片”状态。图位的实际宽高、横竖比例、裁切方式、来源/授权/匿名要求记录在独立配图清单，不把像素坐标或技术日志写到观众页面。

页面上的说明写成“学生讨论近景”“保留书本与交流动作”“同一作业初稿和修订，匿名”，避免笼统的“此处放图”。原文、题目、数据与判断条件先做完整，不能以图片留位代替本应写出的内容；缺失图片是核心证据时，相应事实结论保持待核，不把留位当作已有证据。

`imageSlot`创建可编辑形状图位，返回`objects/frame/fit`。它与图片使用相同坐标，可按原框置入素材，再移除图位对象并复看裁切。它不是PowerPoint自带的一键替图占位符，也不会自动识别照片焦点。参数见[制作API](production-api.md#图片留位)。

## 补图后的局部复查

核对素材是否与清单同题、性质是否准确、裁切是否保留关键内容和署名，以及图注是否仍成立。替换为真实作品或活动后，相关转录文字、数据、判断与建议也按实物复核，不能只补图而保留虚构结论。移除该图位的“待补图片”文字，不删除其它未补图位；来源记录与匿名要求同步核对。只复看该图位及受影响文字；补图改变全页重心时再看相邻页。

交付说明区分已配图、待补图及示意图。用户要求的留位版可作为本次成品交付，但不能称素材已经齐全或直接用于正式对外发布。完整新稿的正常成品不应无说明地遗留图位。
