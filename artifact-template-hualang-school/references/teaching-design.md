# 教案、课堂与练习的设计

## 先分清产物

**教师教案**服务备课与实施：学情、目标、重难点、前置知识、具体教学活动、预期学生回应、追问/反馈、分层支持、评价、资源与时间。每个目标都能从活动与评价找到证据。“讲解知识点”“学生讨论”不足以说明怎样教，应写出实际问题/材料、学生动作、预期表现和下一步处理。

**学生课件**服务观察、思考、推理、练习与反馈。保留学生需要看的原文、题干、图形、关键过程和结论条件。教师完整话术、课堂组织与教学反思放独立教案或教师备注；学生理解必需的解释不能全部藏进备注。**说课/教研**还要说明安排依据、预期证据和调整办法。不要把三者只改标题就互相交付。

教案按用户指定形式输出。复杂课时允许总览加材料/例题详页，不强制一页放下整节课。教案与课件共用题目、目标和编号，分别安排密度与阅读顺序。

## 先核材料，再设计教学

用户给的教案案例、题解、百科摘录与原文引用也可能有错。按[内容准确性检查](content-accuracy.md)在起稿前核输入、交付前回读最终成品；能重算的独立求解，需外部证据的核权威原始资料。错误、争议和未核实内容分开处理；有问题必须向用户提醒并给修正建议，不能仅留内部记录。影响正确性且未解的内容不作为学生确定知识或标准答案，也不能称课堂可用。保留原材料与更正对应，不默默改题或篡改事实。

## 从学习障碍组织内容

先读取[初中](junior-subjects.md)、[高中](senior-subjects.md)或[国际课程](international-subjects.md)的相关学科，再列本次学生真正需要跨过的障碍。前置知识已掌握则压缩复述；未知时用短诊断取得证据，不把“基础薄弱”当成事实。

起稿至少能回答：学生现在会什么；本课需要形成什么新关系/方法；哪份材料或哪次推理能建立它；学生独立做什么才能证明理解；错误发生后怎样反馈。该对应关系留在制作底稿或教师材料，不给学生增加一套流程说明页。

| 设计动作 | 有效内容 | 常见失效与修正 |
|---|---|---|
| 建立认识 | 由有代表性的例子、数据、原文或现象引出差异，说明概念的必要性 | 定义后直接背诵：补比较对象、正反例或适用条件 |
| 展开解释 | 交代关键转化为什么成立；把证据与解释、模型与假设相邻安排 | 只呈现步骤或结论：补推理桥梁，避免教师口头补齐全部逻辑 |
| 比较边界 | 改一个关键条件，比较方法、结论或证据强度 | 只换数字重复计算：改范围、假设、语境或材料关系 |
| 独立迁移 | 撤去部分支架，换表示、情境或组合条件，保留必要作答时间 | 立即给完整答案：先明确产出，再按推理单元揭示反馈 |
| 诊断再教 | 预设可识别的错因，给对应追问、补充材料或重试任务 | 仅标“错/再想想”：指出错误位置、原因与检验办法 |

这些动作按教学需要组合，不要求每页或每课机械出现五栏。新授、复习、实验、文本研读、讲评课的组织不同；同一目标中的材料、解释、比较和反馈应形成连续关系。具体推理深度及跨学科例子见[教学深度与密度](teaching-depth.md)。

## 学科对象与小组件优先

成品默认围绕原文、图形、实验装置、公式推导、作品或真实数据组织，用小组件承载步骤与理由、条件分支、例反例、图旁批注、练习与反馈。组件之间的邻接、顺序和连线承担关系；不要把全部内容放进同尺寸卡片。

**表格只在必要时使用**：需要读者沿行列交叉查阅多个对象的相同字段，或逐项核对同口径数值时，才保留可编辑表格。数值表、实验原始记录、概率分布和确有查阅用途的课时/评价记录可采用表格；即使属于这些类型，也先判断行列是否真正帮助读者完成任务。普通推导、教学过程、文本分析、错误解释和反馈优先用对应组件，不自动制成表格。

教案的环节可沿时间轴分组，每组把“任务—预期回应—反馈”就近安排；推导用编号步骤与依据旁注；分类用分支条件与相应结论；例反例用共同题干及关键差异；文本保留完整节选并就近批注。需要比较时保持可比字段和尺度，不等于必须画成表格。去掉格线、保留相同整齐行列并堆文字，仍是表格式组织，不能算完成调整。

使用组件后仍保留全部条件、关键推理和评价依据，不靠删内容制造疏朗，也不设表格数量配额。本参考的Markdown索引表用于查阅规则，不是要求将相应内容照搬成PPT表格。

## 一页放多少

以下是1280×720页面的设计起点，按真实题长、公式高度、图形与观看距离调整，不是题量配额。

| 页面任务 | 常见可容纳内容 | 拆分信号 |
|---|---|---|
| 教师课时总览 | 1课时目标/学情＋4—6个环节的实际活动、预期回应和评价组件 | 具体材料和反馈被压成口号；总览外加难点详页 |
| 初中概念/常规例题 | 1个概念或例题＋图/式/语言联系＋1—2个短练习 | 同时引入多个新概念，或图内标注无法看清 |
| 高中计算/证明 | 1道多问例题的完整关键解答、条件/分类依据和方法比较 | 必须删条件、分支或跨页找图才容得下；按关键转化续页 |
| 双题比较 | 2个可同屏核对的对象/题目，保留共同点、差异及依据 | 任一对象需要独立大图或长推导；保留比较结论再续页 |
| 随堂短练习 | 2—4题，简短选择/判断可更多；有明确作答要求和反馈 | 题干/选项挤压，或全显答案导致关键信息不可读 |
| 语文/英语阅读 | 一段必要上下文＋2—3个递进任务、证据与分析 | 原文须缩成图片，或删去理解依据；按自然段/问题链续页 |
| 实验/理科模型 | 装置/模型＋变量/数据＋解释或评价任务 | 装置、单位、对照、误差或证据关系无法同屏核对 |
| 国际论述/数据回应 | 材料单元＋证据＋分析/评价及必要条件 | 指令、限制、案例应用或论证链被删去 |

容量以**答案全显末态**判断，但密度也包括学生需完成的阅读、运算、观察和表达负载。任务页的合理作答区、实验观察或作品主图可以留白；不能仅用字数或占满页面判定质量。若末态只剩标题、两句常识和一个空泛口号，优先补实质解释或合并相关页。一个数学例题约6—12行关键推理只是常见范围，不能用行数充当完整证明。

正文保持可投影字号；通过删重复、压缩装饰、调整题域、表图互译和就近批注提高有效密度。不能靠缩字、堆更难题、增加动画或机械增页制造深度。先安排完整末态，再规划揭示；题干、图形、变量和材料位置稳定。

## 可执行教案与课堂反馈

教案优先按时间顺序或材料/例题组织环节组件，将任务、预期回应与反馈就近对应；只有确需交叉查阅多环节的同类字段时才用课时活动表。每个关键环节写出实际材料/设问、预计学生产出、判定依据，以及未达到时的处理。教学时间按已知课时安排；时间含独立思考、实验操作、交流、转场与反馈，不能把全部分钟用于教师讲解。未知课时可标示计划假设，不称实授结果。

分层以当前任务证据为依据，调整提示、材料量、步骤支架或挑战条件，不给学生贴固定能力标签。基础任务保留核心目标，进阶任务增加解释/条件变化，挑战任务要求迁移或评价；不必每一页都列三档。教师教案交代支架何时撤去。

讲评先呈现代表性解法/回应，再让学生定位差异，最后给修订或重试。检测不能只重复刚示范的同一数字；至少在本次关键目标上提供独立作答证据。离堂任务宜短且能区分核心误区，答案与判定依据留教师材料或按需揭示。

## 在理解受益处主动用动画

当前模型、工具和交付格式支持时，主动在图形/条件变化、数学参数、物理分段、实验机制、文本证据和错解反馈等节点使用动画，按[教学动画](teaching-animation.md)选择实际可实现的方式。动画要对应观察、停顿、提问与反馈，优先可编辑原生对象；不只添加文字飞入，不强制每段动画。题干、坐标与变量稳定，完整末态密度不降低，初态/关键中间态/末态实看。能力不足时给静态分步并说明，不声称未支持的平滑变形或未做的应用兼容测试。

## 连续课时与验收

整套教学按[长篇编排](longform-layout.md)组织知识关系、课时、题组和反馈。目标可观察、材料完整、解释有依据、练习有递进、评价能诊断、错因有处理、时间可执行；其中任何一项不能仅凭出现相应标题判定通过。先独立校核题解与材料，再看最终文件、实际页面及揭示状态。完整教案不等于全部投影，静态渲染也不等于真实授课验证。
