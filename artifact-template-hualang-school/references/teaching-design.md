# 教案、课堂与练习的设计

## 先分清产物

**教师教案**服务备课与实施：学情、目标、重难点、前置知识、具体教学活动、预期学生回应、追问/反馈、分层支持、评价、资源与时间。每个目标都要能从活动与评价中找到证据。“讲解知识点”“学生讨论”不足以说明怎样教，应写出实际问题/材料、学生要做的动作和判定表现的标准。

**学生课件**服务观察、思考、推理、练习与反馈。保留学生需要看的原文、题干、图形和过程；教师备课细节移入备注或独立教案。**说课/教研**还要解释为什么这样安排及怎样观察效果。不要把三者只改个标题就互相交付。

教案可按用户指定形式输出。完整课时教案通常有课时概况和活动设计，复杂材料另页展开；不强制一页放下整节课。PPT形式的教案可一页呈现课时总览，后面按教学难点给材料、例题与评价详页。

## 学段和学科先行

先读取[初中](junior-subjects.md)、[高中](senior-subjects.md)或[国际课程](international-subjects.md)的相关行，落实到具体学科对象。年级、课程、课型、学生基础会改变解释深度与页面，不凭“教育”二字套一张照片。

同一章节可有概念建立、例题讲解、实验探究、复习整理、随堂练习和检测反馈。页面必须对应当前任务，允许同页存在知识联系、完整例题、方法与短变式。

## 一页放多少

以下是1280×720页面的设计起点，必须按真实题长、公式高度、图形与观看距离调整，不是题量配额。

| 页面任务 | 常见可容纳内容 | 拆分信号 |
|---|---|---|
| 教师课时总览 | 1课时目标/学情＋4—6个环节的活动与评价表 | 活动只剩口号，具体材料或预期回应被删掉 |
| 初中概念/常规例题 | 1个概念或例题＋图/式联系＋1—2个短练习 | 新概念太多、图内标注看不清，或例题/练习承担不同目标 |
| 高中常规计算/证明 | 1道多问例题＋完整关键解答（常约6—12行）＋方法/条件 | 证明必须省略条件、分支或跨页找图，才需要按逻辑续页 |
| 双题比较 | 2道可在同屏完成方法对照的题，分别保留解答区 | 任一题需要完整大图或长推导，优先拆成独立题域/续页 |
| 随堂短练习 | 2—4题；很短的选择/判断可更多 | 题干/选项拥挤、没有作答要求，或需要同时出现大量答案 |
| 语文/英语阅读 | 1段可读原文＋2—3个任务/证据批注 | 文本必须缩成图片或删去理解所需上下文 |
| 实验/理科模型 | 1个装置/模型＋变量/数据＋解释任务 | 装置、单位、条件或证据关系无法同屏对照 |
| 国际论述/数据回应 | 1个材料单元＋数据/证据＋作答结构与评估要求 | 指令词、限制作答条件或论证链被删去 |

容量以**答案全显末态**判断。初始态应有明确学习任务、必要图形/材料及合适作答区域；留白来自等待推理，不靠空白制造所谓高级感。短题可以合并，完整例题不为统一大字号强行拆页。

## 三种可执行教案组织

- **课时活动表**：环节与时间／实际教师任务／学生预期回应／评价与调整。目标、前置知识和资源在表前简列。适合常规备课。
- **材料驱动教案**：原文、史料、案例、实验或数据占主体，旁注目标、追问、可能误区与反馈。适合文本研读与探究。
- **例题驱动教案**：题干与解法完整，旁列关键转化、预期错解、追问和同方法变式。适合数学与理科复习。

教学时间按用户课时或合理示例标明；示例45分钟不能成为所有学校的固定课时。分层支持可以调整提示、材料或挑战，不把学生贴为固定能力类别。

## 学科备课验收

目标可观察；活动有具体材料；学生回应可预期；评价能检验目标；重难点通过安排处理；题目与答案正确；资源与时间可执行。检查“教什么、学生做什么、怎样知道学会了”能否一一对应。教案内容完整不等于全部投影给学生。

## 连续课时与页数

整套教学按[长篇编排](longform-layout.md)分配课时、完整例题、题组和反馈；本轮须用连续单元验证容量及邻页变化。先看答案全显末态，相关短题与方法尽量同页。常规45分钟复习课可从8—14页有效教学页起排，页数随材料与练习时长调整，不以页数作为质量目标。
