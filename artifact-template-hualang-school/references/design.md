# 华朗视觉与组件规范

## 品牌与内容层级

保留原模板的 16:9 画布、校徽、中英文校名、校园照片及紫金识别。新版的深紫、香槟金和暖白用于稳定品牌，内部正文继续按公司材料组织。留白用于分隔证据组，字号用于建立层级；不能以大片空白和每页少量文字代替高质量排版。

| 角色 | 色值 | 用法 |
|---|---|---|
| 华朗主紫 | `#403653` | 封面、页眉、章节和品牌元素；教育展示可作主图表色 |
| 华朗次紫 | `#655878` | 教育展示的次级分组与系列 |
| 香槟金 | `#BCA36D` | 少量品牌线条、深紫底强调及装饰，不承担浅底小字 |
| 暖纸白 | `#FAF8F3` | 普通内容背景；密集表格也可用白底 |
| 内部正文黑 | `#000000` / `#212121` | 标题、正文、一般数字、图注、单位及图例 |
| 内部重点红 | `#C00000` | 内部概论关键句、异常数字、推荐与决策重点；同稿保持一致 |
| 辅助深蓝 | `#1B2A4E` | 少量分组、总计或图表辅助系列，不替代黑色正文 |
| 辅助灰与细线 | `#595959` / `#D9D2C7` | 次要说明、基准系列与分隔 |

学校紫金识别与正文强调分工清楚。内部稿不把大段正文染紫，不混用红、紫、金、蓝分别强调同一层级。教育展示一般采用紫色主强调及少量金色，错误与正确、实际与计划等区别同时给文字或线型。校徽内部颜色、字形和比例保留原资产，不重新描绘。

## 画布和字体

原模板等效画布 1280×720，13⅓×7.5 英寸。沿用页眉、标识、左右边距和标题区域；内容区可依阅读任务改变构图。左右边距可从 0.4—0.55 英寸起调，顶部从 0.25—0.4 英寸起调，按本次模板实际检查。封面必须能读出题名、汇报人/授课者和日期，各字段有层级与间距。

中文以 PingFang SC 为当前主字体，英文以 Arial 为主。Windows 缺少苹方时可用已安装的微软雅黑或思源黑体替换，并重新验证换行、数字与符号；不能承诺替换后布局不变。一份 PPT 不混用多个中文正文字体。Word 一页纸使用宋体。

### 内部阅读型材料

| 层级 | 起始范围 | 判断 |
|---|---|---|
| 题名 | 20—24 pt | 保持公司短题名与华朗页首位置，不把题名放大为主视觉 |
| 概论 | 15—18 pt | 可以完整表达判断或安排，不机械压为一句短口号 |
| 正文 | 12—14 pt | 容纳完整分析，行距约 1.25—1.45 倍 |
| 表格 | 10.5—12.5 pt | 按列数、字段与阅读方式调整，不缩成截图 |
| 图注 | 9—10 pt | 对象、日期、单位、范围及示意性质 |
| 页码 | 8.5—9.5 pt | 辅助定位，不抢注意 |

这是佳兆业阅读型汇报的字号起点，华朗继承。需要远距投影时可将正文提高至约 16—20 pt，并按真实阅读困难重组；不能把所有内部稿都固定为 20—24 pt 正文，迫使一项完整论证拆成多张提词卡。

### 课堂、家长和对外投影

字号随屏幕、教室后排和现场距离调整。主信息可从 20—28 pt 起调，章节与演讲主句可更大；题干、引文、表格、公式与图注应按内容完整性安排。需要 26—30 pt 主文字时，只提高承担主要观看任务的部分，不把整页所有文字统一放大。长材料细读或复杂比较可使用阅读页、讲义或分层呈现，不删掉决定理解的条件。

上述范围都是排版经验，不是学习效果定律。实际页面和用户阅读端优先。

## 内部正文构图

普通页从左上题名读到概论，再向下找到支持它的证据。依据可分段，也可贴在图表对应部位。标题与概论保持稳定；主体不固定为“左图右文”或同样几张卡片。

| 阅读任务 | 组件组合 | 应能直接看清 |
|---|---|---|
| 查经营结果 | 通栏指标主表＋异常行注释＋必要趋势或构成图 | 目标、实际、差额、原因及下一步 |
| 找转化障碍 | 同群体流程或漏斗＋各阶段表＋原因与动作对应 | 哪一步流失，分母是什么，拟作用于哪一步 |
| 对账和预算 | 财务主表＋差额归因；有可勾稽数据时用桥接图 | 科目、期间、预算、实际、差额与合计关系 |
| 比较方案 | 同维度矩阵＋投入构成＋推荐依据和条件 | 每种方案解决什么、代价与资源要求 |
| 看跨期协作 | 节点横轴＋渠道、活动、拓客等泳道 | 在同一时间列能读到当期各项任务 |
| 看学情 | 分布图＋能力项矩阵＋匿名学习证据＋支持安排 | 总体变化、结构短板、证据与措施对应 |
| 看对象与实施 | 实图或平面批注＋活动流程／任务表＋责任 | 在哪里做、谁做、关键接口与完成标准 |

同字段比较页保留尺度、列序和颜色；不同任务页要改变证据的组织方式。图表、表格、批注和示意图可以同页组合，但每个组件都应回答一个具体追问。避免把长段内容全部装进等宽卡片，或单纯左右对调来假装版式变化。

## 表格和数据图表

表格保留影响判断的全部字段。文本左对齐、数字右对齐，同列小数位一致，合计用字重或细横线区分。单位进列名，统计期和范围放在相关位置。内部常用浅暖灰或浅紫灰表头配黑字，少用大面积深色表头与重网格。

表格用于查数和同字段比较，趋势用折线，分类对比用条形，分布用柱形或分组图。构成图注明总体，百分比标明分母；缺少可比条件不能强画同尺度比较。条形图一般从零开始；截断坐标须有明确理由和标示。不存在新增贡献时不绘制桥接图，更不能为了视觉效果把分类数据伪造成因果链。

原生图表须保留系列、标签、坐标、单位、日期和可编辑数据。主要数字用直接标签减少往返图例，重点系列用本稿强调色、基准用灰。含多阶段的招生漏斗确认群体可追踪且逐级包含，无法满足时改阶段数量表。教学函数使用数值坐标轴，按实际变量与范围绘制，不能用分类轴造成截距或距离误读。

## 流程、排程和关系图

流程节点表达实际动作与条件，连接线对应真实依赖；并行工作用泳道或矩阵。时间轴按真实日期比例排布，只有阶段次序时等距列阶段，不捏造日期和时长。跨期招生计划的节点、传播、活动与家庭拓展共用横轴，读者沿同一列能看出怎样配合。

步骤图、决策树、课程路径、能力矩阵、案例对照和例题批注保留可编辑文字、节点与线。任务卡适用于独立练习或分组任务；公司分析页无需把每条理由做成卡片。关系简单时，用表格、并列块和清楚的标签即可，不绕弯连线。

## 业务配图

各内部业务条线同样要按本题安排必要图片展示。图片帮助识别校园空间、教学与服务过程、操作对象或拟议效果。纯查数页可以只用表；整稿只有文字和数字时，要检查是否遗漏本应呈现的对象、过程和方案变化。

逐页在底稿记清图片讲什么、从哪来、放在哪里、读者应看清什么。优先本次资料与有权使用的实图；真实业绩、人员、缺陷、合同与系统状态用相应原始记录，不能由生成图补作凭证。缺实图而需说明拟议过程时，可用原生流程或准确标注的示意图。生成场景按真实岗位、动作、器具和空间制作，成品注明示意属性，并实际检查细节。

校园背景用于场所识别，学习作品用于说明学习过程，流程图用于解释责任与交接。不要让建筑照片代替学习成效证据。裁切不损失关键标注、尺寸、图例和主体；多人照片、学生作品按公开范围处理。公开引用需要许可与署名时按来源要求执行。

## 文字、对齐和可读性

内部正文通常左对齐，宽栏适合连贯论证，短并列事实可双栏。不要把长分析切成三列细长碎句。段内行距与段间留白分工明确，不靠全角空格和空回车定位。

核查孤字、行首标点、单位和日期拆分。英文在语义单元处断行，不把短介词或姓名单独留行。金色浅底小字对比不足，改黑色或深色。可借普通文本 4.5:1、大文字 3:1 检查对比，但网页标准不能代替现场投影测试。重要图像应有可理解的说明，颜色以外仍能识别状态。

高端感来自稳定的品牌、精确的对齐、清楚的信息层级和与内容匹配的组件。减少金属质感、重阴影、复杂渐变与无功能纹理。过密先去复述、分组或拆独立问题；过疏先补必要依据或合并。
