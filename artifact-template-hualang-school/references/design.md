# 视觉、密度与色彩

华朗的原始封面、校徽、紫金品牌和原封尾保持稳定。正文样式按读者、内容负载和观看距离选择。内部审议、教师教案、学生课堂与招生演讲使用不同的信息组织与字号起点。

## 颜色角色

| 角色 | 色值 | 用途 |
|---|---|---|
| 正文黑 | `#222222` | 普通正文、题干、公式、数值、表格和图注 |
| 辅助灰 | `#666666` | 次级解释、口径、基准系列 |
| 重点红 | `#B4232C` | 关键差额、核心结论、易错点或当前推理步骤；按页选少量对象 |
| 分析深蓝 | `#1B385B` | 图表主系列、模型、方法或结构；不把全部正文换蓝 |
| 品牌紫 | `#403653` | 页标题、任务带、方法提示、步骤编号、表头与品牌；正文仍黑色 |
| 香槟金 | `#BCA36D` | 品牌细线、定位、深底强调，不作浅底小字 |
| 白/浅紫 | `#FDFDFE` / `#F0ECF5` | 内容底色、任务/方法分区；白底保留呼吸空间 |

先决定强调对象，再上色。同页同一种颜色含义一致，关键状态也用文字/位置区分。数学普通式子黑色，关键转化或最终结论可用红；函数/几何主线可用深蓝，辅助线灰。实验/地图/生物结构需要多色时按学科语义编码并给图例，不为了品牌统一删掉必要颜色。

## 字号与层级

画布1280×720，对应13⅓×7.5英寸。制作库使用CSS像素：24px=18pt。中文默认苹方，缺失时统一选择实际可用的微软雅黑/思源黑体；数学字体另核实。不要混淆px与pt导致字号放大。

| 用途 | 页标题 | 正文起点 | 公式/表格 | 页面任务 |
|---|---|---|---|---|
| 内部阅读审议 | 20—24pt | 14—16pt | 表格12—15pt | 同屏保留概论、依据、图表及落实条件 |
| 教师教案/备课 | 20—23pt | 14—16pt | 流程表13—15pt | 目标、学情、活动、预期回应与评价可查阅 |
| 学生课堂讲解 | 21—25pt | 18—21pt | 公式18—23pt | 一项完整学习任务及关键推理；重点局部放大 |
| 练习/复习题组 | 20—24pt | 17—20pt | 条件与图上标注同等可读 | 短题成组、长题按题域展开，答案按需揭示 |
| 家长现场/招生 | 24—30pt | 20—25pt | 核心数字32—48pt | 图像、作品、数字与适用条件 |
| 舞台演讲 | 主句48—72pt | 22—28pt | 按视距放大 | 单一主张或图像关系，详稿另行安排 |

这些是起排区间，不是硬性科学阈值。远距会场、教室投影、近距离电子屏与打印阅读分别验收；内容长先组织与重排，必要时续页，不把全稿做成一页一句。完整推理能容纳时，不为了维持30pt正文拆成数页。页脚可小，必要题干和条件不可降成页脚。

## 标题只承担一次导航

封面默认一个主标题，署名与日期为元信息。内容页保留一个明确页标题；内部概论位于标题下方，以正文层级表达判断。不要再叠“本页主题＋同义大口号＋小节总标题”。分组标题仅在内容确有并列关系时使用，字号接近正文，靠字重/间距区分。演讲已有主句时可以不另设场景题名。

## 版面和图表

左右边距48px，内容通常从y=112到y=650。标题区紧凑，留足主体空间。内部报告可用上概论、下主表/主图、就近解释与底部落实；教案以课时安排与评价表为主；课堂按题干、推导、图形及反馈组织；对外根据素材选主次照片、数字关系或主句。

- 表格用原生对象，紫色白字或浅紫深紫字表头、黑色表身、必要横线、数值右对齐；重点行用字重或浅底，异常单元格才用强调色。列宽按字段长度分配，保留单位与口径。
- 数据图保留数值轴、期间、分母、范围与来源中的不确定性。基准灰、本期/主系列深蓝，重点差额可红。函数必须为XY数值坐标，曲线来自真实公式；不得用分类轴。
- 图片、图纸和作品说明具体对象/证据，标注靠近对应位置。主要信息给主图，补充细节用小图；不要用装饰照片挤掉推理和管理条件。
- 同一页/同组比较共享尺度与对齐线。图注和标题不重复，主体不能依赖跨页来回查数。

真实校园与学生资料使用已授权素材，生成图清楚标示情境属性。学校实绩、课程、日期与收费等按当期材料核实。最终按实际用途查看页面及全部教学状态，不能用“没有溢出”代替可用性判断。


## 教学组件与整体美观

使用组件是为了标明读者动作：任务带容纳完整问题；推导区保留等式与理由；方法条提炼可迁移方法；变式区与主例保持关联；文本批注指向原句；实验表与图共享变量；教师教案按活动与评价组织。不要把每段话都装进相同卡片，也不要退回一整页无分区黑字。

紫色用于稳定导航与这些组件的标题/边界/浅底，黑色承担持续阅读。红色只点亮一两个关键判断或错误，答案不必整段通红。首屏、当前步骤和末态均应有清楚的焦点。

全稿先检查用途与证据，再检查重复的标题/构图，最后逐页看对齐、字距、段距、图像裁切和颜色面积。封面将汇报人与时间作为同一组元信息放在左下安全区，不能只按坐标填字而忽略斜切边界。

## 对外组件的紫色层级

对外演讲与开放活动允许紫色框架、重点色块、数字旗标和关系组件形成明显视觉主体；底色仍近白。详见[外宣组件](external-visual.md)。紫色承担结构与重点，避免只在小标题加紫、其余仍是通用大字版。
