# 深大主题色样例与华朗应用

用户要求研究深圳大学模板怎样用荔红形成丰富的组件和版式，再根据华朗紫重新设计。研究对象是公开预览，未确认其中商业平台标注的“官方”身份。借鉴颜色与信息结构的组合方法，不复制深大校徽、照片或模板源文件。

## 实际观察

- [广州校园发布的深大系列预览](https://www.sohu.com/a/551408496_239689)：圆形编号、图标说明、主次图片组、跨区标题带、数据组件和并列结构，贯穿同一主题色。
- [51PPT的深大宣传模板预览](https://www.51pptmoban.com/zhuti/3863.html)：照片与色带、版块与标题的关系。平台自称“官方”，本次不据此认证。
- [40页深大学术模板预览](https://pptku.org/ppt/1935)：树形关系、曲线路径、层级、蜂窝节点、比较和图表。仅学习对应信息结构，图片和版式资产不进入华朗成品。
- [深大官方标识应用页](https://www1.szu.edu.cn/images/szu_logo/)用于区分官方标识资料与第三方模板；本次不使用深大标识。

## 华朗的落实方式

1. 常规正文固定左标题、右校徽、金色分隔线与近白底，默认使用 `addPage`。远距实景主视觉按现行[出血规则](scene-visual-grammar.md#整页出血对外专用)处理，不将此例外扩大到近距和留阅。
2. 以华朗紫及同色系深浅形成层级，普通文字黑色。颜色同时进入编号、线性图标、标题条、图片色标、关系线、数据和路径。
3. 按本页内容选择图文拼版、蜂窝关系与旁注、图标标题与比较矩阵、活动主次图片、数据与交流事项、曲线阶段路径。不是把组件机械轮流用一遍。
4. 按用途检查完整单元：内部留阅将判断所需材料、解释和条件同屏对照；课堂保留稳定对象与完整末态，允许独立作答及分步揭示；现场讲述由主图、主句和近邻证据承接。家长成果将数据、作品及支持对应起来，招生说明保留影响选择的条件。
5. 逐页看实际文件，联排检查主体构图。只有颜色统一、对象数量多或文件检查通过，不能证明审美或内容通过。

## 已实现的原生组件

`schoolIcon` 提供阅读、人物、目标、地球、图表、毕业、工作、日历和科学九类线性图标；与 `numberBadge`、`iconLabel`、`photoLabel`、`pointBand` 组合。原有原生表格、图表、关系线、分式与揭示机制继续使用。图标、文字和关系图都可编辑。

`sectionRule`、`addCanvas`、`addStage` 是局部设计工具，不作为华朗常规正文入口。只有本次任务明确需要独立无页眉片段时才改变页眉，不要求用户重复确认已经给定的用途。
