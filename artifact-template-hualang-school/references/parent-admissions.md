# 家长、招生与对外表达

按受众正在判断的问题组织材料。招生演讲需要呈现学校体验、课程选择与可信证据；日常家长会需要学习反馈和家庭行动。二者不共享一套固定照片＋三条说明。

## 用途与观看节奏

| 用途 | 关键内容 | 适合的版面 |
|---|---|---|
| 招生开放日 | 校园体验、课程与培养、适合谁、如何进一步了解 | 主次照片组、数字页、课程路径、参观安排 |
| 家长会 | 本班学习证据、变化、问题、学校支持、家庭行动 | 匿名作品对照、同口径数据、支持过程、行动清单 |
| 学校对外演讲 | 一个持续展开的主题、具体人物/作品/活动、必要证据 | 大图/大字、照片序列、单一数据关系、收束主句 |
| 家长留阅材料 | 完整课程条件、费用、日期与办理方式 | 清楚的比较表、问答与办理信息，不机械放大图片 |

## 照片组的叙事

主图让人了解“在什么地方做什么”，次图补“如何做”和“产出了什么”。一张图的观察价值大时可以单图，多图有不同证据角色时可采用一大两小、不对称跨栏或三联序列。按内容选择，不能为凑图数复制同一张照片。

标题与照片组共享对齐线；图注贴近照片；大字放在稳定留白或独立底区。照片可以出血，关键人脸、动作、作品与校徽不被遮住。学校实景、实际师生和作品优先使用已授权原件。生成情境图清楚标“AI情境示意”，不得配真实升学数字暗示其为证据。

## 数字的表达

一页优先突出本次判断真正需要的1—3项数字。数字旁同时给单位、期间、群体和含义；有变化就给同口径基准。照片可解释对象，但不证明效果。不同分母的数据不拼成占比，人数与录取通知份数不混用。学校统计期和正式出处可简洁保留；没有数据时用实际过程/作品展示，不能编造就业、升学、获奖与师资数字。

## 内容层次

- 招生：先让家长看见具体教育体验，再解释课程选择与支持，证据支撑重要主张，最后给真实咨询/参观路径。
- 家长会：先用可核验的学习证据界定问题，解释学校做什么和家庭可做什么；个体成绩不公开比较。
- 对外演讲：允许主图、数字、大字、作品连续组合；每页让讲述前进一步。避免一页只有口号却没有相邻证据，或连续所有页都使用校园建筑照。
