# 华朗学校材料设计

交付应让校领导能判断、教师能实施、学生能学习、家长能理解、招生对象能选择。技能的价值由真实材料处理后的实际页面体现。保持华朗独立身份、原始首尾及左题右徽金线框架；正文底为近白，主体可以使用有功能的紫色面、图表、图形和真实图像，不能把品牌框架当成完整设计。

首次接手时先读[上手](references/getting-started.md)，确认本机可用的制作环境与文件落位；其余情况直接进入下面的内容结构。

## 1. 先写本次成品的内容结构

沿用已给用途、材料、署名、日期、形式和页数，不重复询问。缺失项只有影响事实、题解或采用时才追问。先判断材料能支持什么，再写核心回答。

常规整稿依次完成：读取主题/内容/附件 → 判定主场景与观看条件 → 写出页序和逐页核心回答 → 按[页面规格](references/deck-spec.md)生成 `deck-spec.json` → 调用 `scripts/hualang_build.py` → 检查构建报告和最终文件。只有主题且允许补资料时，先研究并记录来源；缺少学校实绩、个体表现、课程范围或当期政策时保留明确待补项，不编造完整事实。

| 成品对象 | 整份材料如何推进 | 页面必须让人看到什么 | 默认视觉档 | 专项 |
|---|---|---|---|---|
| 校务决策与内部汇报 | 结果及差距→构成与解释→比较取舍→落实条件 | 同口径事实、差额、完整依据和条件 | 留阅 | [内部汇报](references/internal-report.md) |
| 教师教案与说课 | 学习障碍→目标判据→任务序列→预期回应→评价调整 | 可执行活动、预期作答、错误后的处理 | 留阅；说课投影转近距 | [教学设计](references/teaching-design.md) |
| 学生课堂 | 完整对象→表示联系→分段推理→条件变化→独立作答→反馈 | 题目/原文/图形及能跟随的知识形成过程 | 近距 | [教学深度](references/teaching-depth.md) |
| 练习复习与检测 | 方法或条件分组→示范比较→独立题组→诊断迁移 | 完整题组、作答空间、独立答案与判据 | 留阅；投影可近距 | [数学](references/math-teaching.md)及对应学科 |
| 个体家长成长反馈 | 作品/记录→具体变化→仍有困难→家庭动作→复核 | 孩子的实际证据及可执行支持，保留确定程度 | 近距 | [家长与招生](references/parent-admissions.md) |
| 班级家长会与家校协同 | 共同目标→班级安排→家校分工→统一节点→沟通渠道 | 班级范围、政策适用、家庭动作和办理信息 | 近距；带走手册转留阅 | [家长与招生](references/parent-admissions.md) |
| 招生开放日与课程选择 | 教育命题→真实体验/成果→课程适配→当期条件→预约 | 场景、学习过程、作品与选择条件 | 远距；办理页近距/留阅 | [对外视觉](references/external-visual.md) |
| 公众成果发布与主题演讲 | 核心主张→人物/事件/作品→关键数据→机制→参与方式 | 单一记忆点、可核实证据与社会价值 | 远距 | [对外视觉](references/external-visual.md) |

完整路由、推荐页序和调研依据见[教育场景系统](references/scenario-system-v11.md)。这些是组织问题的方式，不是所有页面的固定栏目。只改称谓、字号、配色或`purpose`无法完成场景转换。用同一主题跨对象制作时，须分别重组内容和证据。

**对外实景页铺满画布，不留白边。** 远距档的招生、开放日、演讲主视觉走整页出血：图占 0,0,1280,720，不出页眉题名，金线不贯穿，校徽换金色版压在文字侧上方，页码移到文字列左下。留阅与近距页仍保留页眉框架。出血页用于需要现场感和集中观看的节点，按叙事节奏与定位需要安排，不给整稿设置统一数量配额。规格见[场景视觉语法](references/scene-visual-grammar.md#整页出血对外专用)。

**场景差异必须落在页面上，不只落在措辞上。** 起排可参考：留阅档每页 180–320 字、正文 21px、图表占 25–45%；近距档 80–160 字、正文 26px、图与表占 30–50%；远距档 30–80 字、正文 34px、主图或主对象占 55%–100%。这些参数用于按观看距离调整信息负载，不设字数、图片或面积配额；完整题干、纯数据页、作答区与续页按实际内容和可读性安排。对外材料沿用留阅档字数是常见失败：照礼堂或开放日的观看距离，后排读不到。档位由使用条件判定，招生手册给家长带走属于留阅，同一内容在讲台上属于远距，两种用途分别成稿。参数与七个落位见[场景视觉语法](references/scene-visual-grammar.md)。

## 2. 决定主对象及视觉分量

在排版前确定：本页核心判断/学习任务是什么，什么具体对象能支持它，读者需要比较、推理、观察还是作答。随后按[场景视觉语法](references/scene-visual-grammar.md)定视觉档位与落位，按[设计规范](references/design.md)定字阶、网格、留白与组件，按[排版研究与实页转化](references/layout-research-v10.md)选适合本次材料的结构。

**重心的建立顺序**：先给主对象足够面积，再用四周 1.5–2 倍空白把它托出来，最后才考虑色面。白底上靠加框加底强调，会把页面推向卡片堆。每页确定清楚的主阅读焦点，辅助内容形成层级；同尺度比较的双方可以并列，避免无关对象争抢注意力。

概论是统领性判断，口径说明是辅助资料。有实质判断的概论使用黑色或深紫、正常阅读对比与主体以上层级，可在正文中占重要位置；不能统一压成灰色小字。模拟属性、统计期、图注等才使用辅助层级。任务或主对象已承担统领时不另加概论。具体字号、关系和示例见[设计规范](references/design.md)及[文案](references/writing.md)。

正文底保持近白。大色面应组织内容、建立视觉锚点或呈现照片/数据关系；图表给共同尺度，图形给出条件关系，原文配近邻批注，作品保持前后可比。采用色面、照片或图形后仍要保留实质解释。文字分两栏、三组、四格，以及去框后开放分行，本质上仍可能是同一套逐段读字；不能用版型名称和组件数量证明设计。

图像按证据、解释、场景或作品选用真实适用素材；无素材且允许留位时，按[图片与留位](references/image-planning.md)记录主体与用途，不用空图框或无关图装饰。纯数据和数学页可以不用照片，依靠实际坐标、公式、图形、比较与信息层级形成主体。

## 3. 内容容量随使用单元确定

管理页保留判断所需的比较、原因及取舍；教案和课堂分别设计，不能把两份材料各缩成半页充当教学成果。教学能力须用完整学习单元验证：保留对象、知识联系、推理理由、条件/反例、独立任务和错误反馈；短例子只证明其局部能力。按[教学设计](references/teaching-design.md)判断应同屏、合并还是续页，不能用大字、空白或答案揭示掩盖教学负载不足。明示独立作答的学生材料，要在实际文件中把任务与答案分态、分答题页或分教师/学生材料，不能同屏给出后只写“教师控制时机”。

初中读[初中分学科](references/junior-subjects.md)，高中读[高中分学科](references/senior-subjects.md)，国际高中读[国际课程](references/international-subjects.md)；三者的学科与版式对照见[学科版式索引](references/subject-layouts.md)，英文与双语材料另读[英文与双语](references/bilingual.md)。根据教材、课程体系、层级、考试年和学生基础选取相关参考；英文翻译不能代替课程设计。数学另外核对[数学专项](references/math-teaching.md)，长稿按[连续单元](references/longform-layout.md)安排。只加载本次学段、学科和形式。

资料已定、拟议、实绩、预测和模拟保持原状态。能重算的关系主动重算；用户材料中的知识、题解、数据和引文也按[内容正确性](references/content-accuracy.md)核对。影响正确性的疑点未解决，说明具体位置与影响，不称可直接正式采用。

## 4. 制作可修改的成品

常规整稿使用 `scripts/hualang_build.py` 统一编排，按[页面规格](references/deck-spec.md)调用。构建器提供 statement / comparison / table / metrics / bars / timeline / process / activity / lesson / practice / evidence 等版式，自动保留首尾、处理分页、表格续页、答案反馈页和点击出现；`assets/examples/` 有八类场景的可运行输入。表格按[表格系统](references/table-system-v11.md)选择 editorial / comparison / matrix / schedule / rubric / checklist，列宽和行高随内容计算，禁止靠无限缩字挤压。

特殊学科图形、复杂图表或定制交互按[生产流程](references/production.md)选择底层精修通道，复用[制作API](references/production-api.md)与原始品牌资源。宿主没有 `@oai/artifact-tool` 时走[python-pptx 通道](references/python-production.md)。概论使用`lead`或其兼容入口`summary`，资料属性使用`contextLine`；不要自建把所有首句变灰的包装。文字、公式、表格、图表与关系图保持可编辑。

完整稿保留原始封面与封尾，封面一个正式题名、汇报人和日期；封尾培养目标准确为“华夏俊采，朗若星辰”，加适合场合的结束语。单页或局部正文按指定范围交付，不另加首尾。位置和原底图见[固定首尾](references/cover-layout.md)。

分步教学先排完整末态，再按推理单元登记揭示。当前格式能准确支持且有理解收益时，依[教学动画](references/teaching-animation.md)演示图形、参数或过程；初态、关键中态和末态都要清楚。静态分步、点击出现和连续运动分别说明，不承诺未验证的应用放映。

## 5. 先审设计和使用，再查技术细节

先看构建报告中的场景、分页和警告，再看联排与最弱代表页：概论是否统领，主体是否承载信息，不同对象是否有真实逻辑结构，教学单元是否有足够内容与独立作答证据，表格续页是否保持字段和口径。任一项不成立，返回内容和构图，不能先修断行后宣布视觉通过。

随后逐页查看实际保存文件的呈现，并按[成品审查](references/review.md)分别审内容、表达与场景、视觉、文件。记录及程序只绑定事实和证据，不认证审美。新稿的关键能力要有可辨认实际成品；介绍本技能时按[介绍与培训](references/skill-intro.md)讲清材料难题、具体处理、可见结果与使用条件，不能以功能描述、空白品牌页或“教学片段”标签充抵验证。

用户否定后撤回相关通过结论，保留原稿、检讨与同材料前后实页；缺陷没有在实际页面中改变，就不能关闭。完整新稿在条件可用时由未参与制作的人先看成品、再对照任务。未做的放映、投影和真实使用效果如实说明，独立AI观察不等于用户认可。

维护以仓库为源，按仓库`AGENTS.md`备份、修订、实际出品验证、同步安装版和已授权公开仓库。旧样张保留版本范围，不能因为存在于技能包就成为当前质量标准。
