# 华朗学校材料设计

材料要符合使用者的实际工作：管理层能了解情况并作出判断，教师能据此实施，学生能理解和作答，家长能看清孩子的表现与支持办法。华朗独立身份、原始首尾、正文品牌框架和原生可编辑对象保持不变。

**专业、自然的中文是每次制作的基本要求，与内容完整和版面质量同时执行。** 起稿时读取[文案与专业表达](references/writing.md)，交稿时回到最终文件逐句、逐段和连页复读。不得把内部制作方法、字段名、检查项和功能库存直接写成观众材料。删除“赋能”等词或把“先……再……”换个说法，不能解决只有栏目、没有实质内容的问题。

当前用户要求及已确认安排优先；只修改指定范围。首次接手时读[上手说明](references/getting-started.md)确认环境与资源，已经核验且未变化的条件可以沿用。

## 材料、用途与完整性

沿用已给主题、读者、场合、产物、页数、署名与日期。只追问会改变事实、题解、判断或交付的缺项；一般制作选择由助手完成，不要求用户回答固定问卷。已有安排保持已定状态，没有真实待决事项时不创造审批问题。只有主题且允许补资料时，围绕本次问题研究，区分公共背景与学校实际。

起稿依据是本次材料中的具体事实、原文、作品、题目和选项。把核心内容写成能读懂的完整回答，再分配页面和选择组件。每个重要判断有相应依据；原因、效果和建议各自保留成立条件。需要的比较、过程、反例或代价不能缩成标签，缺少依据也不能靠套话补齐。展开到足以支持本次使用为止，详见[内容深化](references/content-depth.md)与[内容策划](references/workflow.md)。

逐页策划可在底稿记录 `reader_question / new_information / role`，用于核对任务覆盖与内容增量，不是观众页的固定栏目。保留同题推理、完整题干、必要续表和稳定比较；合并重复结论，避免把同一意思分别改称“目的、价值、方法、成效”铺成多页。告知、分析、申请、复盘和操作培训按照各自任务展开，不能统一套成阶段流程。

| 本次用途 | 内容应支持的实际工作 | 主要参考 |
|---|---|---|
| 校务决策与内部汇报 | 核对结果和差距，理解解释，比较投入与取舍，明确真实落实条件 | [内部汇报](references/internal-report.md) |
| 教师教案与说课 | 找到完整学习材料、具体任务、预期回应和错误后的处理 | [教学设计](references/teaching-design.md) |
| 学生课堂 | 对题目、原文或图形进行观察、推理、作答并理解反馈 | [教学深度](references/teaching-depth.md) |
| 练习复习与检测 | 独立完成完整题目，按答案与判据订正，并辨认方法适用条件 | [数学](references/math-teaching.md)及对应学科 |
| 个体家长反馈 | 从实际作品或记录看清变化、困难与家庭支持办法 | [家长与招生](references/parent-admissions.md) |
| 班级家长会 | 理解班级情况、学校安排、家校分工和必要办理信息 | [家长与招生](references/parent-admissions.md) |
| 招生开放日与课程选择 | 了解真实体验、作品与课程差异，以及当期适用条件和咨询方式 | [对外视觉](references/external-visual.md) |
| 公众成果发布与主题演讲 | 跟随一个主题理解人物、事件、作品和主张依据 | [对外视觉](references/external-visual.md) |

完整场景分流见[教育场景系统](references/scenario-system-v11.md)。换受众时重组内容和所需证据；改称谓、字号或配色不能完成场景转换。同一主题不必共用页序，也不要求某种场景必须使用指定版式名。

初中、高中和国际高中分别读[初中学科](references/junior-subjects.md)、[高中学科](references/senior-subjects.md)、[国际课程](references/international-subjects.md)。按教材版本、课程层级、考试年、学生基础及本次形式选用，其他索引见[学科版式](references/subject-layouts.md)；双语材料读[英文与双语](references/bilingual.md)，长稿读[连续单元](references/longform-layout.md)。不把翻译、一道浅题或活动名称当作教学设计。

## 专业表达与内容核对

标题交代具体议题，概论在需要统领判断时说明本页的结果、含义或安排，正文用材料把它讲清。段落之间应有实际的信息联系；不要求每页都出现目的、步骤、证据和行动，也不要求并列项目等量、等长。已有完整题目、主图或清楚任务时，可以省去概论。

数字用于真实规模、比较、课时、题号与必要清单。用“几套方法、几个目的、几重保障”替代具体内容的表述需要重写；真实顺序、实验步骤与教学指令仍按实际过程表达。去掉空话后，要保留原有事实、条件、否定、确定程度、比较对象和已定状态，不能把文案改短的同时改坏含义。

用户材料、旧稿和示例均按[内容准确性](references/content-accuracy.md)核对。能独立求解、计算和推导的主动完成；需要外部事实支持的核适用原始资料。派生比例、差额等写入底稿 `calculations`，记录比较主体、基准、视角、期间、单位、公式与输入。结果一致也要核对它能否支持当前解释。

内部原始出处、计算和制作记录留在独立底稿，不进入正文、页脚、附页或备注；观众需要的期间、单位、范围、模拟性质和业务条件保留。教学、学术或对外引用按实际场景保留必要出处。事实、推断、预测、建议及模拟材料不能混写；影响正确性的问题未解决时说明位置与影响，不称已可正式采用。

## 页面设计

以本页材料及其关系决定主对象、空间和阅读顺序。主比较与解释、原文与批注、题干与必要推理应能就近核对；同一阅读单元可以包含多个相互支持的对象。组件服务内容，等宽卡片、去框分栏、镜像和换颜色都可能保留相同的文字堆砌。

正文底保持近白；常规页保留左题右徽与金线。正文、公式和普通数值以黑色为主，少量红色强调，深蓝用于分析，紫色用于品牌层级及有作用的色面。概论用黑色或深紫与清楚层级，不统一压成灰色小字。模拟属性、图注、期间等才用辅助层级。规格见[设计规范](references/design.md)。

观看条件决定信息负载。留阅稿保留阅读和判断需要的内容，近距课堂突出对象与任务，远距演讲以可辨认的主张和证据展开；字数、面积和字阶参数只是起排参考，不能变成凑数配额。远距招生或演讲的实景主视觉可以整页出血，用金色校徽和独立主张；常规说明页恢复品牌页眉，细则见[场景视觉语法](references/scene-visual-grammar.md)。

构图选择见[构图库](references/layout-atlas.md)、[材料组件](references/material-components.md)和[排版研究](references/layout-research-v10.md)。真实图像按证据、解释、场景或作品使用；缺图时按[图片与留位](references/image-planning.md)说明需要的素材，不把空图框或无关照片当作完成。纯数据和数学材料可以用原生图表与图形承担主体。

教学保留完整学习单元中的对象、必要知识联系、推理理由、条件比较、独立任务和反馈；不机械拼成固定栏目。独立作答与答案在实际文件中分态、分答题页或分教师与学生材料。合理作答留白保留，静态页、点击出现与连续运动分别说明，动画设计见[教学动画](references/teaching-animation.md)。

## 制作与交付检查

常规整稿按[页面规格](references/deck-spec.md)组织内容并调用 `scripts/hualang_build.py`。表格按[表格系统](references/table-system-v11.md)计算列宽、行高与续页，保留原生文字、图表和关系节点。特殊对象用[生产流程](references/production.md)中的底层精修通道；缺少原生运行库时用[Python 通道](references/python-production.md)，不临时改交一组整页图片。

完整稿保留原始封面与封尾；封面为正式题名、真实署名与日期，封尾培养目标为“华夏俊采，朗若星辰”，结束语符合场合。只要求单页或局部内容时不另加首尾，详见[固定首尾](references/cover-layout.md)。

文案在排版前复读完整内容，排版后从最终文件再次核对。检查包括标题与段落是否说清实际事项、结论与依据是否相符、句段是否重复或套用机械结构、关联页是否承接；同时核对改写是否遗漏独立信息。没有检出关键词问题，不能据此认定表达合格。[文案参考](references/writing.md)给出专业稿的完整改写示范。

整稿入口自动回读最终PPT；底层稿也运行 `scripts/audit_content_claims.py 成品.pptx --out 文案复读.json`。它只定位候选问题，不认证自然度或内容完整。随后按[成品审查](references/review.md)分别判断内容、表达与场景、视觉、文件，记录放在独立底稿。实际页面必须来自最后保存文件的演示引擎导出；结构镜像不能证明字体、换行和放映效果。

用户指出的问题须在相应规则、工具或成品中修复，相关旧通过结论撤回。检查范围随改动确定：文案方法可用新材料试写及前后对照验证，排版或渲染变更再检查受影响实页。用户只要求维护技能时不额外制作介绍或汇报材料。复杂修订可由未参与制作的人独立试用，观察具体缺项，不以AI一致意见或组件数量代替质量判断。未做的跨模型生成、应用放映、投影及实际教学效果如实保留。

维护以仓库为源，按仓库 `AGENTS.md` 备份、修订、验证和同步安装版；公开更新遵守用户已明确的授权范围。旧样张保留版本及适用边界，技术样例不自动成为文案范本，见[样张索引](references/sample-index.md)。
