# 华朗学校汇报与教学制作

目标是让材料在真实使用现场可用。**先修订/选择本次适用的方法，再据此制作；介绍PPT只是方法的演示与验证，不能反过来定义技能。** 页数、字体和构图来自内容负载与读者动作，不把所有材料做成大字提词页。

## 1. 确定本次产物

沿用用户已给的要求，确认读者、用途、材料、必须保留的事实与交付形式。学校的主要教学范围为初中、高中和国际高中。教学还要确认学科、章节、年级、课型、教材/课程体系、课时与学习基础；只有缺失项会影响教学内容或答案时才追问。

| 用途 | 本页需要完成的工作 | 专项参考 |
|---|---|---|
| 内部经营、校务、教学质量或资源审议 | 用正式概论统领依据，保留比较、图表、原因、条件与实施 | [内部汇报](references/internal-report.md) |
| 教师教案、集体备课、说课 | 写出目标、学情、重难点、具体活动、预期回应、评价与调整 | [教案与课件](references/teaching-design.md) |
| 学生课堂讲解 | 完整题目/原文/对象、必要知识联系、推理、方法与反馈 | [教学设计](references/teaching-design.md)、对应学段 |
| 随堂练习、复习或检测 | 按难度与方法组织题组，保留条件与作答要求，答案可分步显示 | [数学与题库](references/math-teaching.md)、对应学科 |
| 家长会、招生说明、对外演讲 | 用可核实的照片、作品、数字与条件讲清教育体验和下一步 | [家长与招生](references/parent-admissions.md) |
| 工具介绍与岗位培训 | 说明使用输入、处理方法、产物及操作，实际案例证明能力 | [从任务到页面](references/workflow.md) |

**教案是给教师用的设计材料，课堂PPT是给学生看的学习材料。** 用户要教案时，按要求生成教案，不自动改成题目投影；只要文本、Word或PPT时沿用指定形式。两者同时需要时共享题目与目标，分别排版。

## 2. 按学段与学科细化教学

- 初中：读[初中分学科](references/junior-subjects.md)，兼顾概念建立、示范、基础应用和易错诊断。
- 高中：读[高中分学科](references/senior-subjects.md)，保留论证链、条件、模型、综合材料与方法迁移。
- 国际高中：读[国际课程分学科](references/international-subjects.md)，先定位实际课程、考试年和层级，再组织指令词、证据、论证及评分要求。英文翻译不等于国际课程设计。
- 数学题与题库另读[数学专项](references/math-teaching.md)；其他学科按[学科索引](references/subject-layouts.md)选具体对象。只加载本次需要的学段和学科，不把全套参考塞进每次课件。

先解题、读材料、确定目标与证据，再决定一页内容。一页放几题看题长、图形、解答及观看方式：短题可以组成题组；常规例题可以同页放完整解答和变式；长综合题按真正的推理边界续页。不可为了统一大字号把普通例题拆散，也不可为凑题数删条件。容量起点见[教学设计](references/teaching-design.md#一页放多少)。

## 3. 品牌、标题与颜色

**完整演示保留固定首尾。** 保留原始模板封面和最后一页，业务内容放在两者之间。用户明确只要单页或局部片段时，按指定页数交付正文，不额外增加首尾。原封尾不得换成自拟口号、“开始制作”或总结卡片。结论、行动或使用入口放在封尾前一页。详见[固定首尾](references/cover-layout.md)。

封面默认仅有一个主标题，另保留汇报人和时间。副题只在用户明确要求或确有独立范围说明时出现，不叠加“使用介绍/场景演示/版本”制造第二标题。普通内容页一个页标题；内部概论是正文层级的一两句判断，不能再做一个大标题。课堂题号、设问、学科小节是内容结构，不机械删除。

**正文、公式和普通数值默认黑色；紫色同时承担品牌与内容层级。** 页标题、任务带、方法提示、步骤编号和表头可以用紫色及浅紫底。重点使用克制红色，深蓝用于图表/模型或次级分析，灰色用于基准与辅助。不是每句话都上色，也不把每个小标题都当重点。学科中必要的多色编码须保持含义一致。内部报告的逻辑与密度参照成熟的公司汇报方法，学校事实、品牌与组织身份独立保留。

字体分级、场景字号和图表规则见[视觉规范](references/design.md)。用[构图方法](references/composition.md)组织整稿、整页、分区、组件与细节；标题、概论、依据、图注各有用途，见[文案规范](references/writing.md)。

## 4. 组织内容与制作

先写核心回答，再为每页确定具体问题、支撑材料和需要的主体对象。内部概论应能追到同口径事实、比较与条件；教学目标应能追到实际任务和评价；招生主张应能追到真实过程、作品或数字。已定、拟议、实际和预测保持原状态，资料不足时缩小结论。

按[生产流程](references/production.md)使用现有运行环境与品牌辅助库。新版工具按用途提供字号起点、黑色正文、教案/数学/照片分区，并自动保留固定封尾。公式、表格、数据图与需修改的图形保持可编辑。图文位置由对应关系决定，不能只换主题色或把每个场景做成同款两栏。

解答与批注按推理单元登记点击揭示。**先排完整末态，确保内容完整且同页能对照，再设置隐藏与出现。** 初始态留白应服务作答与后续推理，不作为信息容量不足的借口。图形、变量和题干位置保持稳定。

## 5. 实际验收与维护

按[验收规则](references/review.md)检查：

1. 任务与学科：本次要的是教案、课堂、内部汇报还是对外表达；每个学习目标有活动与评价，公式/原文/条件完整。
2. 信息容量：完整解答、比较和实施条件能否同屏核对；删去无信息增量的标题、口号和重复说明；不靠全页放大字号撑满。
3. 页面与颜色：逐页看实际渲染，正文黑色、重点可辨，图文对应，数字与标签清楚；不同场景肉眼可辨。
4. 首尾与文件：固定封面三字段、封尾原资产及正文题名回读通过；原生对象、页序、动画初始/中间/末态和链接有效；封面署名与日期在同一安全区，避免接缝和主体遮挡。

检查记录留底稿。应用内放映未完成时如实说明；导出成功、结构通过或自评不能证明现场可用。修复后只复查受影响部分，全局样式变化才看全稿。

优化技能时以仓库为维护源，按 `AGENTS.md` 备份旧版、修改规则和工具、用实际材料验证后同步安装版与已授权仓库。修改学科规则后，介绍PPT必须由新版规则生成，示例不得冒充学校实绩或官方真题。
