# 华朗学校汇报制作

**交付目标：用户提供内容、材料和要求后，完成主题准确、论证充分、适合使用现场的可编辑 PPT。** 模板、图片和案例服务本次任务。模板自带的文字与示例不决定主题，不能把介绍工具的任务改成课程或业务案例集。

## 1. 任务与材料

动笔前在私有底稿答清四件事：**给谁看、为什么做、具体报什么、怎么分到各页。** 直接沿用用户已给的信息，不把这一步变成一轮问卷。

将用户明确要求列为本次必答项，包括主题、产物、读者、使用方式、必须讲清的问题和不能改变的事实。对照材料提取真正需要的数字、原文、方案状态与图像；冲突或缺口只在会改变判断时追问。能够先做的部分继续做。

先写这份材料的核心回答，再为每页写“回答哪个本次问题／这页给出的答案／靠什么材料或例子讲清／用什么形式呈现”。页序由问题及材料决定，不套固定章数、页数和通用栏目。完整做法与不同任务示例见[从任务到页面](references/workflow.md)。

**主题检查在排版之前。** 连读页名和答案，必须是在回答用户的问题。举例时说清它证明哪项能力或判断；例子不能连续展开成另一份课件或方案，挤掉用户真正要讲的内容。六项要求就核对六项；没有提出的栏目不机械增加。

## 2. 内容与场景

| 本次用途 | 需要交代的内容 | 按需读取 |
|---|---|---|
| 内部经营、校务会、专项申请、教学质量审议 | 现状与影响、判断与依据、方案取舍、投入及实施；已有方案保留原范围和状态 | [内部汇报](references/internal-report.md)、[文案](references/writing.md) |
| 课堂、复习、教学示范 | 学习任务、观察材料、推理示范、练习与反馈；题干和条件完整 | [课堂规范](references/special-scenes.md#课堂教学) |
| 家长会、招生说明 | 课程与支持方式、适用条件、家庭配合及实际下一步；分清现场讲述与留阅 | [家长规范](references/special-scenes.md#家长沟通) |
| 对外演讲 | 清楚主张、听得懂的案例与证据，配合现场节奏 | [演讲规范](references/special-scenes.md#对外演讲) |
| 工具介绍、岗位培训、使用说明 | 学员要会做什么、怎样操作、为什么这样处理、场景差异；按要求提供下载或办理入口 | [工作说明与培训](references/workflow.md#工作说明与培训) |
| 英文、双语 | 沿用对应用途的事实和逻辑，再重写语言与版面 | [双语规范](references/bilingual.md) |

教育专业性体现在真实学科任务、正确的概念关系、评价标准与学习过程。彩色卡片、校园照片或大字号本身不能证明教育专业性。内部阅读与远距演讲的信息密度可以不同，但都必须完成本次沟通任务。

## 3. 固定规范

**封面三字段必须齐全并在固定位置。** 主题位于左下紫色区，汇报人位于左下、汇报时间位于右下，使用明确字段标签。位置、字号和缺项处理见[固定封面](references/cover-layout.md)。

**普通页面题名统一为具体短语。** 通常采用四字、六字或八字，适用于内部稿、工具介绍、培训和家长材料。自动题名不用“怎样、如何、先……再……、然后”等口播或问句。课堂提问放主体任务区，演讲主句单独处理；用户明确给定的正式题名保留。所有场景都读取[文案规范](references/writing.md)。

所有场景共用深紫正文 `#403653`、紫灰辅助 `#70677F`、近白底 `#FDFDFE` 与少量香槟金 `#BCA36D`。紫底白字用于封面、章节或演讲重点。校徽和正式校名使用原资产，不重新绘制。字号、图像裁切、表格和图表规则见[视觉规范](references/design.md)。

[品牌底稿](assets/reference.pptx)只提供封面、页眉、校徽和画布；[原始文件](assets/source-original.pptx)保留不动。先读取 `artifact-template.json`，制作工作副本。介绍案例保存在仓库 demo，**不再充当每次制作的内容模板**。

选择版式时说明它如何帮助读者：查数用表，比较用同尺度图或矩阵，过程用步骤或排程，对象与操作用照片及就近批注。课堂按理解过程分步，演讲允许大字与单图。全稿不能把所有材料塞进同一种表格、卡片或两栏；也不以固定图片数量硬凑变化。四类可调用结构及实际样例见[场景版式](references/scene-layouts.md)，具体对象形式见[版式选用](references/component-index.md)。采用场景版式时查看对应实页，不能仅根据规则文字猜布局。

制作统一走[生产流程](references/production.md)：利用现有运行环境和品牌辅助库，复用页眉、字体、颜色与原生表格，不在每个任务重新搭工具。文字、表格、数据图和需要改动的关系图保持可编辑。完整材料直接推进制作；需要外部事实时才做与本题有关的调研，不能每次重跑行业研究。

## 4. 内容、排版与视觉审查

按照[成品验收](references/review.md)执行：

1. **验任务**：合上底稿，仅看成品，能否找到用户每项要求的实际答案？主题、用途或缺项不合格，先重写，不能靠换颜色补救。
2. **审文案**：判断有依据，对象、数字与状态准确；删掉无新增信息的套话，保留必要比较与条件。用读者听得懂、业务负责人会说的中文。
3. **审排版**：核对封面固定字段和题名清单，运行 `scripts/check_style_contract.py`；逐页看最终渲染，比较项靠近，图文对应，字体和标签可读，图轴、箭头、裁切、换行正确。
4. **审美化与文件**：联排核对实际主体对象与场景差异，比较文字、图表、图像和留白的组织；回读最终文件，确认原生对象、页序、下载入口及配套文件有效。

检查记录写明实际问题、修改和回看结果。导出成功、无溢出、另一个模型说“通过”或自评分均不能替代上述检查。修复后仅重查受影响部分；未做的 PowerPoint 放映测试如实说明。

下载、安装与首次调用说明按需读取[开始使用](references/getting-started.md)，普通制作任务无需重复安装。

## 5. 交付与后续修改

交付最终 PPT 及用户需要的预览；事实核验、源文件路径、制作记录与排版自评留在底稿。课堂答案、确有用途的教师提示与学术引用可保留。公开示例明确虚构性质，生成图标示示意，不冒充学校实绩。

后续反馈先判断改的是内容、事实、场景还是视觉，再改相关部分，核对关联数字与页面。只要一页纸时按[一页纸规范](references/one-page.md)办理，不强加 PPT；用户只要 PPT 时不额外交付。

[公开仓库](https://github.com/2503668375-boop/hualang-ppt-skill)是维护源。优化本技能时按仓库 `AGENTS.md` 保存旧版、完成实际制作测试后同步个人安装版与已授权远端。调研依据按需查[研究依据](references/research-basis.md)，学校事实按需查[学校资料](references/evidence-and-school.md)。
