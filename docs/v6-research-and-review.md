# 华朗V6调研与全局审查

## 本次用户要求

主要用于初中、高中与国际高中，教案必须分学科。教师教案、学生课堂、练习、内部审议与对外展示分别组织。保留紫金品牌，普通正文黑色，紫色搭配形成层级，重点少量强调。内部汇报沿用成熟的概论、依据、图表和条件管理方法。封面只有一个主标题，署名与时间放在一起，封尾恢复原模板。

## 实际查阅与可借鉴内容

- [Waterloo Planning a Lesson](https://uwaterloo.ca/centre-for-teaching-excellence/catalogs/tip-sheets/planning-lesson)：目标、学习活动、时间、反馈与评价按实际需要组织，明确不存在唯一正确模板。该来源支持按用途调整结构，不提供统一PPT字号或一页题数。
- [Cambridge IGCSE EAL教师资源节选](https://assets.cambridge.org/97810091/50071/excerpt/9781009150071_excerpt.pdf)：已读取可访问的模板文本，包含学习意图、成功标准、语言支持和时间；此次PDF本体下载遇到服务繁忙，未声称完成其实际页面视觉检查。
- [Cambridge C1教案](https://www.cambridgeenglish.org/Images/649844-c1-advanced-reading-and-use-of-english-part-2.pdf)：已下载并看第1—2页，教师过程与学生工作表相互引用，局部浅色带用于特定支持说明。用于借鉴字段和阅读组织，不照搬其A4版式到投影。
- [Cambridge TKT教案构成材料](https://www.cambridgeenglish.org/images/168890-tkt-module-2-identifying-the-different-components-of-a-lesson-plan.pdf)：已下载并看示例页，环节/时间、阶段目标、活动、互动与资源分工清楚。
- [CMU教学原则](https://www.cmu.edu/teaching/designteach/teach/)：学习目标、活动与评价需要对应；据此检查各学科教案的可实施性。
- [Northwestern品牌演示模板](https://www.northwestern.edu/brand/applying-the-brand/meetings-presentations/powerpoint-templates/)：已查看官方内页缩略图，品牌色可形成稳定的页面边界；仅借鉴角色分工，不复制其标识或紫色值。
- 佳兆业汇报技能中的起稿、密度、图文构图和连续三页实图：概论回到证据，表/桥接图/比较图随问题变化，普通正文克制，关键项强调。方法用于华朗内部报告，品牌与业务事实不混入。

## 根本问题与落地修订

| 问题 | 造成的结果 | skill与工具需要共同改变 |
|---|---|---|
| 只按“教育”选一个模板 | 学科题、教案、家长材料同构 | 学段×学科×用途路由，明确各类主体对象与评价 |
| 把品牌色当全文字色，随后又机械清空紫色 | 全紫无法区分重点，全黑缺少品牌层级 | 紫色导航/组件，黑色阅读，红色重点，蓝色分析的稳定角色 |
| 缺少真正的教学组件 | 题目与长解释散放，像黑字提纲 | 任务带、推导区、方法条、变式反馈、文本批注、实验表/图与教案活动区 |
| 大字号成为固定目标 | 常规题被拆碎，难以同屏对照 | 先排完整末态，再按视距调整；题量由题长/图形/解答决定 |
| 只在说明中提动画 | 静态图无法证明教学节奏 | 按对象写原生时间线，同时提供对应步骤预览，区分结构检查与应用放映 |
| 多层标题抢占空间 | 页面像口号加提纲 | 一页一个页标题，概论为正文判断，小节只在实际分组时出现 |
| 封面按机械坐标填字 | 日期碰斜切接缝，信息散落 | 汇报人与日期左下同组、分行左对齐，整页回看 |
| 自拟结束页替换原封尾 | 固定模板被破坏 | 自动保留原第5页封尾，结论和使用入口在其前面 |
| 用边界检查代替审美 | 表格自动增高、错行和空白失衡 | 校核真实行高/内边距，逐页看主体、色块、对齐、裁切、末态与整体节奏 |

具体颜色、字号和组件比例是结合用户要求的设计选择，不伪称为教育规范统一规定。学科资料继续按适用教材/考试年核验，示例只证明处理方法。
