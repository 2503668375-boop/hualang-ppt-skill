# V8.1 主体构图修订

## 本次修订的问题

原规则已反对等宽卡片，但“用小组件承载充分内容”的入口缺少完整管理报告实例；执行者容易将每个事实装入独立面板，变成上排指标下排两框、三列文字或四宫格。内容不少，主证据和真实关系却退到框内。

本次保留品牌、阅读密度和教学要求，将起稿顺序调整为“本页问题与回答—读者动作—主证据对象—空间—局部组件”。正文优先开放组织，图、材料和关系可以跨栏；解释按所指对象就近放置，不要求条目等宽等高。必要台账和多维查阅继续使用原生表格。

## 规则、工具和例子同时调整

- [内容与版式选择](../artifact-template-hualang-school/references/report-layouts.md)提供不同阅读任务的主体、说明位置、条件和旧稿转换例；内部汇报、组件索引、构图与验收均接入该参考。
- 辅助库新增四种开放组件和完整正文工作区；色块接口保留，但不作为整稿生成循环。原生文字、图表、表格、图形和固定首尾继续可编辑或可追溯。
- [序列检查](../artifact-template-hualang-school/scripts/audit_sequence.py)按成品对象提示近似几何、镜像与面板组；清单提供语义和保留理由，不能凭标签证明变化。整页图片内部、SmartArt内部和继承母版不在该检测范围。
- [12页模拟管理报告](../demo/report-layout-example.pptx)由独立执行者读新版规则与原始模拟材料制作，主体选择由执行者完成。包含完整比较、过程、关系、取舍与责任查阅，供查看连续页在有内容时能否形成变化。

## 取舍与边界

版式丰富不以每页不同、固定卡片率或版型数作为指标。同字段比较、续表与同题推理可以稳定位置；独立议题却反复逐块读字时，应重排主对象。去框后的等分文字网格仍须实看。图表必须有数据和口径，路径必须有真实依赖，时间轴必须有已给日期；没有证据时用清楚的文本材料，不为丰富而虚构。

本次未改写教学学科规则、首尾资产及学校事实。原始业务材料不进入公开仓库，公开验证使用清楚标明的模拟数字与拟议安排。静态渲染和结构检查不能证明PowerPoint放映或真实教学效果。
