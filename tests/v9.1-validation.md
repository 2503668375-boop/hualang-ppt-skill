# V9.1 场景内容与图文验证

用户已反馈V9排版明显改善，要求继续深化不同对象/场景的结构化内容与排版，主题突出、内容丰富，并允许配图或图片留位。本轮沿用V9品牌、视觉尺度和精修方式，扩充场景决策、图像作用及留位能力。

## 规则与实现

场景参考由主体清单改为“读者任务—核心回答—证据展开—阅读动作—图像作用”的路由；不固定页数、图数或每页栏目。管理总体数据、教师学情、个体作品与课堂文本分别需要对应输入，不能换标题互相替代。

新增image-planning参考，明确已有照片、作品、学科示意、数据图和留位的不同角色。imageSlot保持原生形状及文字，固定待补标识，返回objects/frame/fit；它不是PowerPoint原生的一键替图占位对象。自然换行和填入素材后的裁切仍需实看。

新增4项保存文件行为测试通过。横/竖留位、原位填图及文字可编辑均实际导出检查；10种无效输入在绘制前拒绝，没有残留对象。没有重复无关组件测试。

## 六场景实页

[8页可编辑样张](../artifact-template-hualang-school/assets/scene-design-v9.1.pptx)保留固定首尾，正文P2—7分别面向管理、教师、学生、家长、招生家庭及演讲听众。

| 页 | 内容组织与主对象 | 核对结果 |
|---|---|---|
| P2管理 | 8万元拟投入的3/5构成、馆藏/借阅口径、决策前明细 | 模拟属性明确；不从资源总量推断损坏或分类需求，比较与依据同屏 |
| P3备课 | 原创文本、目标/学情假设、18分钟活动与反馈 | 3+5+6+4=18分钟；预期安排没有写成真实课堂记录 |
| P4课堂 | 完整原文与任务，两处行动词及解释，追问依据强弱 | 两次原生揭示，初/中/末态分别检查；原文稳定，判断有词句依据 |
| P5家长 | 虚构初修稿、阶段反馈、家庭追问、匿名作品图位 | 修改了与修订内容矛盾的主句，收紧建议条；图位只收关键局部，换真实作品后文字与判断也须改 |
| P6招生 | 已有校园主图＋活动近景和作品局部留位 | 环境照片仅说明场所；另两图明确待补，未由建筑图推导学习成效；主句面向家庭体验而非制作术语 |
| P7演讲 | 一个突出的阅读主张与大幅讨论现场图位 | 以讲述单元设计负载；删除了并不存在的相邻证据页承诺，未将留位写成实况 |

由独立审查者查看六类正文，复核内容/图片与场景匹配；主制作者逐页查看并修正上述问题。最终PPTX保存后重新导入生成预览，PDF从最终文件导出；首尾、题名与文件对象另核。正文有1张已有校园品牌图，另有4个待补图位。独立配图清单记录比例、用途、来源与匿名要求。
