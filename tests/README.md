## 实测发现并改回技能的问题

- 介绍初稿的教学与排版示范只有结构说明。将“示范需实际呈现对象及处理结果”补入工作方法及验收，再改第6、10页，以同一题干和同一原文展示变化。独立审查者复看后确认具体对象、处理和事实对应。
- 演讲主图页默认副句偏小，修订辅助库字号与文本区；增加可选品牌底托以保证校徽对比。
- 不同字体环境需要改库副本，改为每份稿件独立的字体参数，并实际验证字体不串入另一份稿。
- 各执行者在实际页面中发现并修复孤字、文字靠近分隔线及断行问题，保留记录；没有把脚本结束当作完成。
