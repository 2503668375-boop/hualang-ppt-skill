# 三份独立材料的实际制作检验

本轮用不同的独立执行者读取新版技能与原始任务，实际生成PPT；执行者未读取旧案例、其他测试或主制作方的预期页面。以下材料均为虚构，供检查方法是否随任务工作。

| 原始请求 | 实际产物 | 核对重点 |
|---|---|---|
| [Skill介绍](fixtures/Skill介绍任务.txt) | [13页介绍](../demo/hualang-skill-introduction.pptx) | 使用输入与请求、具体痛点、思考结构、场景用法、版式局部、下载安装与再次调用均有实际答案 |
| [内部费用申请](fixtures/内部汇报材料.txt) | [5页内部稿](../demo/internal-report.pptx) | 两场安排及状态保留，32,300＋32,700＝65,000元；费用科目、责任及相对日期完整；校园图只说明环境 |
| [3分钟对外分享](fixtures/对外演讲材料.txt) | [4页演讲稿](../demo/external-speech.pptx) | 严格4页，主图占主体，主句及行动远距可辨；未照搬内部密表；生成图标明示意 |

## 实测发现并改回技能的问题

- 介绍初稿的教学与排版示范只有结构说明。将“示范需实际呈现对象及处理结果”补入工作方法及验收，再改第6、10页，以同一题干和同一原文展示变化。独立审查者复看后确认具体对象、处理和事实对应。
- 演讲主图页默认副句偏小，修订辅助库字号与文本区；增加可选品牌底托以保证校徽对比。
- 不同字体环境需要改库副本，改为每份稿件独立的字体参数，并实际验证字体不串入另一份稿。
- 各执行者在实际页面中发现并修复孤字、文字靠近分隔线及断行问题，保留记录；没有把脚本结束当作完成。

## 验证范围

已查看最终静态页面，回读PPT原生对象、页数和链接；内部费用合计另做逐项核对及原生表格算术检查。原始品牌文件保留，默认品牌底稿清除了具体案例主题。
