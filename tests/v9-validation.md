# V9 视觉系统整改与实际验证

## 纠正上一轮结论

用户明确否定V8.6九页介绍的视觉表现、小组件及长短位置。该稿原先“未发现必须修改项”的视觉结论撤回；内容核算、文件检查只保留各自已查范围，不能继续被用作视觉通过证据。旧文件保留，后续反馈和本轮整改另记。

失败机制：规则虽然要求语义和多样构图，实际只检查不同关系、原生对象和无越框；没有判断最强焦点是否有价值、实际字形和端口是否连贯、条带长度是否合理。组件固定标签列与偏移、自动最近点连接、中心端点默认退让又放大了这些问题。

## 实际修改

- 设计：视觉焦点与内容关系分别决定；关键数字、作品和公式可大于导航题名。按真实负载定组件宽高和组内/组间距离，避免泛词大圆、等重小标题、长空色尾和远端解释。
- 工具：任务带标签与正文共享内框并垂直居中；方法条默认720px，长标签显式宽度、余量/行高可调；批注默认对齐首行，有显式连接口、折线和左右朝向；中心连接默认两端无额外悬空间隙。
- 验收：视觉投诉须给同材料前后实页对照，记录具体缺陷和修正；用户否定会使旧视觉通过失效，AI独立审查与用户认可分开。

## 工具与变体验证

共27项受影响检查通过：新增组件细节7项，中心关系3项，开放组件9项，原生工具行为8项。没有机械重复不相关测试。

实际导出查看长标签、高单行、窄幅及两行标签、左/右批注五类变体；测试检查可编辑区域、保存后的原生对齐/端点、无效输入不残留半个组件。变体是排字与几何验证，不是整页审美样板。正文自然换行和与页面其它对象的碰撞仍需实页查看。

## 独立试作

另一执行者只收到当前技能和新的图书资源模拟材料，自行组织[单页结果](../demo/library-resource-v9.pptx)及[预览](../demo/library-resource-v9.png)。8万元的3/5构成比例准确，8,400册及12,600册次保持各自口径；没有据此推断损坏数量或分类需求，待补清单、报价与执行日期保留。数字与单位的实际位置修订后保存重渲染。

试作发现单页删首尾后仍显示02及不能再用writeDraft的问题，已补最短单页导出与页码处理参考。未增加不必要的整页生成接口。

## 边界

V9补齐了上轮没有落实的设计决策、具体组件能力和实际对照证据。尚未取得用户对新版视觉的确认；不能将本轮AI审查与软件检查称为用户认可。未做PowerPoint应用内放映、真实投影、完整课程教学或全部学科/全部材料负载的验证。修改后的默认尺寸、对齐、端点和过小区域报错行为会影响旧调用外观，复用旧生成器时应查看实际页面。
