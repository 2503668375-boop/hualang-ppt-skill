# V8.3 内容取舍、场景与验收机制

## 本轮范围

用户要求先优化技能，PPT稍后更新。本轮修改规则、制作入口、保存稿预览及验收工具；没有重制介绍PPT或将既有示例重新标为新版视觉通过。旧技能和仓库已在仓库外备份，品牌资产及演示文件保持原样。

## 发现与处理

- 内部留阅的充分展开要求在入口中被泛化到介绍、演讲和课堂；限定内容深化范围，按阅读/讲述单元判断完整性，并补足停止扩写与删除重复的条件。
- 默认report与固定概论容易经包装函数复制到全稿；新增混合场景逐页用途必填和单一场景默认用途。用途参数仅提供字号，不认证构图；逐页仍须说明主对象、读者动作与组件作用。
- writeDraft原先保存后渲染内存对象，与文档的保存稿重导入要求不一致；改为只读重导入，建立新预览目录及文件/图像摘要，状态始终待审。
- 原有结构检查的ok容易被误称质量通过；保留兼容字段，增加structure_valid、quality_verdict:not_assessed与人工视觉复核提示。新增四项审查记录一致性工具，任何待核、需要修改或未关闭问题均退回。

## 工具验证

- `test_review_gate.py`：15项行为测试。覆盖完整范围及局部范围、内容退回不能由文件通过抵消、未修问题、复查摘要不一致、漏页、重复、版本变化和输入保护。小型OOXML与PNG仅作记录逻辑夹具，不能验证页面美观。
- `test_rendered_pdf_audit.py`：11项测试。用临时小PDF验证字形跨页面/有色面板底边、背景与窄色条排除、公开容差、依赖缺失、输入保护及无可测字形页。工具仅测有限几何，不判断审美。
- `test_preview_contract.py`：5项原生行为测试。在内存验证混合场景漏用途拒绝、单一场景默认和覆盖；只预览既有原模板第2页，核源文件不变、实际图片及摘要、范围、待审状态、新目录及无效参数拒绝，没有导出新PPTX。
- `test_sequence_audit.py`：9项几何与兼容回归。结构正常仍明确不作质量判断，既有必要同构仍可由人工结合内容复核。

合计40项测试。命名、配置、包内引用与原始模板另核；具体执行结果以本轮运行记录为准。

## 既有失败页面反向审查

独立审查者只获得技能、原始任务与三张用户截图，没有收到制作方的通过意见。审查结论为需要修改：请求示例末行超出浅紫色面并碰线；安装请求末行超出色面；逻辑说明中的“卡片”被拆为孤行。文件及数字正常不抵消这些视觉问题；未从截图核验附件或整稿覆盖，也未假称这些项目通过。

另对既有候选PPT用另一导出器生成的诊断PDF作有限字形测量，未检出指定越框。这不推翻截图中实际问题：导出器的字体/换行结果可能不同，有限几何也不覆盖全部视觉缺陷。该结果没有被用来关闭用户所指问题，进一步明确了实际页面人工审查的必要性。

## 独立规则复核与限制

独立复核发现“旧图会被脚本识别”的表述超出能力，已改为版本/摘要一致性检查：脚本没有修复前图像历史，无法证明真实修改、图像内容与来源相符或观察真实。实际修复与视觉结果须看当前页面确认。

本轮证明的是规则范围、接口行为、记录拒收和有限测量的工作方式。未制作新版介绍PPT，未验证新版实际排版表现、PowerPoint放映、真实投影或教学效果；这些留待后续PPT任务按四项验收实际完成。
