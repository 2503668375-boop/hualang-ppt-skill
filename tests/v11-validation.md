# V11.0.1 发布前验证 · 2026-11-08

本次以用户提供的 V11.0 技能包为输入，在原有 V10 仓库上接入并修订，版本标为 V11.0.1。原始封面、封尾底稿、品牌校徽与参考模板逐项比对，保持原文件内容。

## 实际覆盖

八类场景及一组长表示例均实际构建为 PPTX：校务内部汇报、教案、学生课堂、练习、个体家长反馈、班级家长会、招生开放日、公众演讲及长表续页。三档样张另行构建。示例的模拟、原创、拟议与待补属性保留。

最终保存文件由 LibreOffice 打开并导出 PDF，再生成页面图检查；已加载所用中文字体。检查正文联排与问题页，核对首尾、表格、作答与反馈顺序。静态渲染不等于 Microsoft PowerPoint 播放验证。

## 发布前实际修复

- 主张、比较、指标、横条、证据和课堂条目超过当前版式容量时，明确报出页码与拆页建议，停止静默截断。
- 横条拒绝负值、非有限数值及不合理上限；带符号数据改用表格或带零基线的定制图表。
- 证据批注按完整条目续页，重复同一作品与口径；行动提示只出现在末页。单项过长时明确报错。
- 核对课堂提示与完整原文、独立任务的区域关系；远距主张按实际行数安排主体、说明及口径，修复实页遮挡。
- 修复留阅流程点击出现未进入末稿，以及近距/留阅图片主张页丢失图片的问题。
- 每个原生表格单元格显式声明不用的边线，避免演示引擎补出默认黑框；保留矩阵、重点列及合计的专用线条。
- 出血页例外要求齐边图片或深色面、原生主张大字及品牌标记。白色、透明、偏移背景不能绕过正文标题检查；该检查仍不认证校徽内容和视觉质量。
- 统一主要分区网格、动态表格行高、手册/讲台内容重组及结构镜像边界；排版参数作为设计起点。

## 检查入口

`tests/test_v11_builder.py` 核对实际保存后的内容保全、拒绝行为、证据续页、图片、原文/任务区、主张/说明区及揭示目标。`tests/test_style_contract.py` 增加出血候选的正负例。既有 JavaScript 默认字号检查随三档规范更新，显式覆盖行为继续核验。

仓库 `tests` 中全部 **111 项回归检查通过**，另有 `artifact-template-hualang-school/scripts/test_hualang_tables.py` 的 **14 项表格检查通过**。八类场景及长表共九组示例均成功构建，合计29页正文、47页含首尾的完整文件；另检查5页三档样张。包文件、JSON、技能入口字段和 Markdown 相对链接同时核对。

## 适用范围与未测条件

这些是场景、版式与工具行为样例，不证明所有输入都可自动获得成熟成品。复杂长文、特殊学科图形及超过当前版式的负载仍须内容重组和底层精修。个体家长示例保留待补学生作品的位置，不能当作真实学生成长证据；短课堂与练习例子不代表整课已完成。

未完成 Microsoft PowerPoint 应用内放映、现场投影、真实课堂或家长活动、全学段学科覆盖及教学效果测量。结构镜像只辅助核对内容和坐标，不证明最终字形、换行或播放。程序通过与 AI 审查均不代表用户审美认可。
